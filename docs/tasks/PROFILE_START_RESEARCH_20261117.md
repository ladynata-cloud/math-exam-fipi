# Исследование перед практикой в профиле START

- Дата: 17 ноября 2026 г.
- База: `b4c58e153fb6e4041c9bc69fb304f0de77582e98` после слияния #600.
- Ветка: `work/profile-start-research-20261117`.
- Уровень: `MEDIUM`.

В публичных уроках START с действующей интерактивной моделью ученик видит вопрос для прогноза и вход в исследование перед кнопками практики и справкой. Опыт доступен по запросу. У модели дана последовательность «предположите → измените → объясните».

Две демонстрации показывают действия с исходными моделями. В трапеции нужно провести диагональ и изменить высоту. В векторной модели нужно сдвинуть конец AB на клетку вправо. Кадры сняты с действующих SVG после указанных действий. Статические кадры, текст и кнопки управления доступны сразу после открытия демонстрации. Воспроизведение запускается отдельной кнопкой и прекращается после закрытия панели. В автономном START доступны тексты и интерактивные модели.

Учительские режимы доски, условия задач, проверка ответов, ключи сохранений и вторая часть сохраняют прежнее поведение. Кабинет, книга и синхронизация прогресса находятся вне этой задачи. Результат передаётся в Draft PR после слияния #600. Порядок выпуска согласуется с #647, #648 и H05.

## Приёмка

- На экране 320, 390 и 1280 px вход в исследование предшествует практике. Подсказки к отдельной задаче по-прежнему открываются по запросу после условия и рисунка.
- Изменённая модель и номер статического кадра сохраняются при закрытии и повторном открытии. Введённый ответ остаётся при открытии помощи и возвращении к задаче. Просмотр GIF сам по себе не открывает попытку.
- `PROFILE_MAIN_GEOMETRY_DISCLOSURE_BROWSER_OK`, профильные DOM и математические регрессии, проверка навигационного связывания и автономное открытие START. Изменение главной схемы сохранений отсутствует.

Внешний дизайн-разбор для локальной задачи не запрашивался. До выпуска сохраняется возможность откатить локальные коммиты. Риск каскада CSS и визуального переполнения проверяется на трёх ширинах. Риск нарушения автономной сборки проверяется повторной сборкой только START и сценарием `file://`.
