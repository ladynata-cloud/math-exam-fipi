## 1. Каталог типов

Обозначения «ходовой ли»: **A** — ядро линии, встречается постоянно; **B** — регулярно; **C** — редко/периферия.

### Группа I. Многогранники, прямой счёт

| # | Короткое имя | Тело | Что дано → что спрашивают | Ходовой |
|---|---|---|---|---|
| 1 | **Куб** | куб | ребро (или объём, или диагональ, или площадь поверхности) → любая другая из этих четырёх величин | **A** |
| 2 | **Прямоугольный параллелепипед** | прям. параллелепипед | три измерения (или часть из них + объём/диагональ) → объём, полная поверхность, диагональ | **A** |
| 3 | **Прямая / правильная призма** | треугольная, четырёхугольная, шестиугольная призма | сторона основания и высота → объём, боковая и полная поверхность | **A** |
| 4 | **Наклонная призма** | наклонная призма | площадь основания и высота (не боковое ребро!) → объём; боковая поверхность через периметр перпендикулярного сечения | **C** |
| 5 | **Обратная задача на многогранник** | любой из 1–3 | объём/площадь поверхности → ребро, высота, сторона основания | **B** |

| 8 | **Усечённая пирамида / усечённый конус** | усечённое тело | две площади оснований (или радиусы) + высота → объём | **C** |

## 2. Формулы, которые линия проверяет

Чек-лист для проверки покрытия не по типам задач, а по формульной базе.

### 2.1 Многогранники — объём
- Куб: `V = a³`
- Прямоугольный параллелепипед: `V = abc`
- Призма (прямая **и наклонная**): `V = S_осн · H`, где H — высота, а не боковое ребро
- Пирамида: `V = ⅓ · S_осн · h`
- Усечённая пирамида: `V = ⅓h(S₁ + √(S₁S₂) + S₂)`

### 2.2 Многогранники — поверхность и диагонали
- Куб: `S = 6a²`, диагональ `d = a√3`
- Прямоугольный параллелепипед: `S = 2(ab + bc + ac)`, диагональ `d = √(a² + b² + c²)`
- Прямая призма: `S_бок = P_осн · H`, `S_полн = S_бок + 2S_осн`
- Наклонная призма: `S_бок = P_перп.сечения · L_бок.ребра`
- Правильная пирамида: `S_бок = ½ · P_осн · m` (m — апофема), `S_полн = S_бок + S_осн`

### 2.3 Тела вращения — объём
- Цилиндр: `V = πR²h`
- Конус: `V = ⅓πR²h`
- Усечённый конус: `V = ⅓πH(R² + Rr + r²)`
- Шар: `V = (4/3)πR³`
- Шаровой сегмент: `V = πh²(R − h/3)` *(периферия)*

### 2.4 Тела вращения — поверхность
- Цилиндр: `S_бок = 2πRh`, `S_полн = 2πR(R + h)`
- Конус: `S_бок = πRl`, `S_полн = πR(R + l)`, образующая `l = √(R² + h²)`
- Развёртка конуса: длина дуги `= 2πR`, угол развёртки `α = 360°·R/l`
- Сфера: `S = 4πR²`

### 2.5 Подобие и масштаб — ядро линии
- Линейные размеры: `L₂ = k·L₁`
- Площади (любые — оснований, сечений, полной поверхности): `S₂ = k²·S₁`
- Объёмы: `V₂ = k³·V₁`
- Сечение ∥ основанию конуса/пирамиды на доле высоты `t` отсекает подобное тело с `k = t`: объём `t³` от исходного, объём усечённой части `(1 − t³)`
- Неравномерное масштабирование (R ×p, h ×q): `V₂/V₁ = p²q` для конуса и цилиндра

### 2.6 Планиметрические «подпорки», без которых линия не решается
- Площадь правильного треугольника: `S = (a²√3)/4`; высота `h = (a√3)/2`
- Площадь правильного шестиугольника: `S = (3a²√3)/2`
- Площадь треугольника: `S = ½ab·sin γ`, формула Герона `S = √(p(p−a)(p−b)(p−c))`
- Радиус описанной окружности: `R = abc/(4S)`; вписанной: `r = S/p`
- Теорема Пифагора и её пространственный аналог (диагональ параллелепипеда)
- Соотношения в прямоугольном треугольнике для углов 30/45/60°

## 3. Ловушки и типичные ошибки учеников по этой линии

**Из официальной аналитики ФИПИ** (методические рекомендации по математике, разбор результатов ЕГЭ):
- Главная причина потерь — **недостаток элементарного пространственного воображения**: ученик не может представить конфигурацию по рисунку.
- Вторая — **ошибки в вычислении величин, когда тело разбито на несколько частей** (составные многогранники, отсечения). ФИПИ прямо рекомендует учителям отрабатывать «правильность вычисления соответствующих величин, когда заданное тело разбито на несколько частей».
- Рекомендация ФИПИ: **органично включать повторение планиметрии в курс стереометрии** — планиметрический счёт и есть узкое место.
  https://doc.fipi.ru/ege/analiticheskie-i-metodicheskie-materialy/2024/ma_mr_2024.pdf

**Масштабирование — самая популярная ловушка:**
- Ученик считает, что при увеличении радиуса в 2 раза площадь круга тоже растёт в 2 раза. На деле — в 4 раза, а объём конуса при увеличении только радиуса в n раз — в n² раз.
- Приём против неё: **выписать формулу на черновик и подставить в неё множители явно**, отмечая, что на что умножено или поделено.
  https://maximumtest.ru/blog/post/tipichnye-oshibki-v-ege-po-profilnoy-matematike

**Призма и пирамида:**
- Путают **высоту тела и высоту основания** (особенно у правильной треугольной призмы и пирамиды: апофема ≠ высота ≠ боковое ребро).
- Применяют `S_бок = P·H` к **наклонной** призме — формула верна только для прямой; универсальна лишь `V = S_осн·H`.
- Считают, что перпендикулярное боковому ребру сечение наклонной призмы параллельно основанию — неверно.
- Забывают формулу площади правильного треугольника / шестиугольника и считают основание «на глаз».
  https://100points.ru/wiki/math/razbiraem-prizmu-formuly-i-sekrety-dlya-zadach-ege-3-i-14/

**Тела вращения:**
- Путают формулы **площадей поверхностей** (особенно шара и конуса) — их советуют не зубрить, а понимать происхождение.
- В конусе подставляют высоту вместо образующей в `S_бок = πRl`.

**Составные тела и отсечения:**

## 4. Чего не удалось достать

1. **Открытый банк ФИПИ напрямую** (https://fipi.ru/ege/otkrytyy-bank-zadaniy-ege) — интерфейс на JavaScript, содержимое по фильтру «задание 3» через выборку текста недоступно. Точного числа задач линии в банке и разбивки по подтемам из первоисточника получить не вышло.
2. **Каталог «Решу ЕГЭ» со статистикой решаемости** (https://ege.sdamgia.ru/test?a=catlistwstat , https://math-ege.sdamgia.ru/methodist?a=catalog) — страница отдаёт только навигацию; прямой запрос к домену отклонён прокси. Это был бы лучший источник процентов решаемости по каждому подтипу.
3. **YouTube-разборы с таймкодами** (`EMtamgDRTxQ`, `FN_uKR1snA8` — «Стереометрия все типы. 3 задание ЕГЭ профиль») — обе страницы вернули HTTP 429 (ограничение частоты запросов), описания и таймкоды прочитать не удалось. Перечень типов из них не учтён.
4. **Методические рекомендации ФИПИ 2026 г.** (https://vpr-ege.ru/z7/ma_mr.pdf) — закрыто robots.txt. Использована версия 2024 г.; свежих процентов решаемости именно за 2026 г. нет.
5. **Сборники Ященко / Лысенко / Мальцева — пооглавленная разбивка.** Страницы с разбором вариантов Ященко-2024/2026 (chemege.ru, egeresheniye.ru) вернули 403 либо отклонены прокси. Поэтому **нет независимой частотной статистики «сколько задач какого типа в 36 вариантах»** — частотная картина в разделе 0 опирается на один агрегатор (mathm.ru), подтверждённый только качественно.
6. **PDF-сводки формул и «задачи открытого банка ФИПИ»** с 4ege.ru (https://4ege.ru/matematika/71798-osnovnye-formuly-k-zadaniju-3-profilnogo-ege.html , https://4ege.ru/matematika/61387-zadanie-8-ege-po-matematike-stereometrija.html) — содержимое только во вложенных PDF, текст страниц пуст.
7. **ЯКласс, методическая рекомендация учителю по заданию 3** (https://www.yaklass.ru/.../prizma-piramida-tcilindr-konus-shar-zadanie-3-7321747/TeacherInfo) — 403, требуется вход в учительский аккаунт.
8. **Школково, подтемы раздела №3** (https://3.shkolkovo.online/catalog/7774) — список подтем подгружается скриптом, из текста страницы не извлекается.
