# Атанасян 8 класс: задачи повышенной трудности №824–841

Первый полный подраздел следующего блока: 18 задач к главе VI,
72 шага, 92 вида чертежей. Источник: предоставленное 14-е переработанное
издание 2023 года, печатные страницы 214–215, рисунок 274.

**Статус: авторский кандидат, не опубликован и не допущен независимым
проверяющим.** Существующие 1407 карточек и их записи проверки не изменены.
`authored.json` воспроизводится из `models_advanced8_824_841.py`.
Он содержит авторские решения, а не сканы или полный текст учебника.

Важные случаи: в №825 срезы не перекрываются благодаря положительности
шести длин; в №829 E может оказаться за C; в №832 проверены оба включения;
в №833 есть обратная теорема; в №834 исходный квадрат не образует нового
четырёхугольника; в №839 не предполагается остроугольность; в №840 есть
условие существования и исключён вырожденный результат.

В №839 подготовлен полностью объяснённый координатный способ. Для школьного
маршрута желательно дополнить его синтетическим доказательством перед
публикацией. Поворот в №835 объясняется через совмещение равных треугольников.
Это вопросы педагогической проверки, а не обещание полного допуска материала.

## Воспроизведение

```bash
python3 tools/geometry-textbook/models_advanced8_824_841.py --check
python3 tools/geometry-textbook/advanced8-824-841.test.py
python3 tools/geometry-textbook/build_advanced8_candidate.py --output /tmp/advanced8-review
```

Открывать `geometry-course/textbook/review.html` в полученной изолированной
копии: только этот вход явно разрешает просмотр `in-review`. Обычный вход
по-прежнему отказывает в открытии новых непроверенных карточек. Сборщик
запрещает вывод в репозиторий и перезапись существующего каталога.

16 автоматических проверок охватывают реестр, координатные утверждения,
несколько тысяч числовых случаев, отсутствие наложений плиток №826,
воспроизводимость и сохранение всех старых карточек. Они не заменяют
независимую проверку доказательств и педагогики.

Облачный workflow `atanasyan-advanced8.yml` проверяет все 92 вида при двух
ширинах, 36 полных проходов по новым карточкам, возврат из теории и старую
запись ученика в синтетическом хранилище. Итоги конкретного запуска,
ошибки и снимки нужно читать в соответствующем PR; наличие workflow
само по себе не означает успешный прогон.

Далее: завершить независимую содержательную и визуальную проверку,
подготовить отдельный допуск с привязкой к проверенным байтам и включить
в основной курс по действующей политике публикации. Следующий номер 842;
весь дополнительный блок 824–925 ещё не завершён.
