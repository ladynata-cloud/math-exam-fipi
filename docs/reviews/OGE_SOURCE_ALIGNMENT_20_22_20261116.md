# Приёмка авторских задач ОГЭ №20–22

Проверка по [конкретным позициям из источников](../../trainers/oge-sources/coverage-20-22.json) выполнена на утверждённом демо ФИПИ 2027, трёх просмотренных вариантах Ященко, открытом фрагменте Лысенко и одном варианте СтатГрада. Объём сверки ограничен этими позициями.

Для каждого решаются ОДЗ, знаки и скобки объединения. | Независимо проверены знаки и допустимость концов для 84 сочетаний параметров. В ранее существующих тренажёрах найдены типы для радикала с исходной ОДЗ, движения по кругу, движения с разными скоростями по двум половинам пути и кусочного графика с горизонтальным уровнем. Открытый фрагмент Лысенко подтвердил самостоятельные структуры, которые ещё требуют отдельных аналогов. Для них в карте стоят пометки `gap`.

Старые ID и схемы сохранений сохранены. Регрессии доски охватывают штатную передачу нового типа и восстановление между участниками в DOM. Точный обратный переход к базовым байтам проверяется отдельно, включая отклонение частично изменённых фрагментов. Закреплённые книжные материалы прежних редакций не изменены.

Три автономных HTML совпали с HTML внутри своих ZIP. В каждом ZIP остальные четыре элемента побайтно совпали с базой. CRC прошёл во всех трёх архивах.

## Границы приёмки

Браузерный прогон с системным Chromium был запущен, но остановился на создании процесса до открытия первой страницы из-за запрета на системный вызов `socket()`. Вёрстка в реальном браузере и проверки GitHub Actions должны подтверждаться отдельно. Публикация на сайте, испытание с учениками и проверка письменных решений преподавателем в отчёт не входят.
