# Дополнительные упражнения главы I, №212–214

Печатная с. 56, страница 57 файла выданного учебника Макарычева 2024 года, электронный ISBN 978-5-09-116445-9, SHA-256 `356695f0f11a489090ed72428320a6d6cc343747eec02968b716c2204caaced8`. Сверены две числовые дроби №212, формула и обе подстановки №213, все шесть знаменателей №214.
