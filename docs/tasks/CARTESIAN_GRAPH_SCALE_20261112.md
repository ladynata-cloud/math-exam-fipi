# Одинаковый масштаб осей X и Y в MathExam

## Задача

В упражнении «Формула по графику» в разделе «Навыки ОГЭ» единичный отрезок по X длиннее единичного отрезка по Y. Из-за этого прямая \(y=x-2\) выглядит почти горизонтальной. Владелец просит исправить этот рисунок и другие координатные графики с такой же проблемой.

- Ветка `codex/cartesian-graph-scale` от `main` `7ec45010426955193636bf3192db6cb0e30e0ba6`.
- Уровень проверки `MEDIUM`.
- Выпуск после применимых проверок по [действующему разрешению владельца](../OWNER_RELEASE_AUTHORIZATION.md).

## Приёмка

- На обычном графике один числовой шаг занимает одинаковое расстояние по обеим осям. Деления сетки используют общий шаг.
- В задании со скриншота прямая проходит через \((0;-2)\) и \((2;0)\) и поднимается под углом 45°. Выбор ответа доступен с клавиатуры и восстанавливается после перезагрузки.
- В отдельном упражнении «Координаты важнее угла» ученик видит подпись о разных шкалах. Варианты и сохранённые ответы используют прежние идентификаторы.
- Исправлены такие же преобразования в моделях ОГЭ, ЕГЭ, ВПР, школьной алгебры и колледжа. В упражнениях с постановкой точки используются те же координаты для отрисовки и клика.
- Для функций с быстрым ростом границы окна учитывают отмеченные точки и значимый для задания участок графика.
