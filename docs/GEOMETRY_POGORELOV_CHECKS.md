# Проверки курса pogorelov

Математические тождества новых семейств проверены отдельными формулами, формат ответа и последовательность карточек — для каждого узла. Полный браузерный маршрут: объяснение → модель → доказательство → разбор → самостоятельная задача → письменная работа → перезагрузка. Проверены мобильные страницы 360 px, локальное открытие, просмотр работ преподавателем и отсутствие JS-ошибок. После переноса последних исправлений общий проход повторяется.

Это не опыт реальных учащихся и не внешнее ревью. Отдельная задача на тему не равна всем упражнениям учебника. Источники — приватно предоставленные учебники; в репозиторий включены только библиографическая карта и авторские материалы, без PDF.
