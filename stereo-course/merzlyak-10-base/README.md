Отдельный курс по предоставленному учебнику Мерзляка, Номировского,
Полонского и Якира. Цель — все задачи, теория и индивидуальные модели.
Это первая подготовка; полный курс ещё не завершён и не опубликован.

## Как устроен материал

Крупная модель находится перед разбором. Шаги открываются постепенно,
предыдущие шаги и записи сохраняются. В доказательствах запись ученика
сохраняется для обсуждения, без ложной автоматической оценки правильности.
Используется существующий движок учебника Атанасяна с двумя изолированными
изменениями: `PDF = печатная страница + 1` и точный поиск номера `1.1`.
Другие курсы, кабинеты и сервер не меняются.
