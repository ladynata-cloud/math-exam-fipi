# Проверка дополнительных курсов из ОГЭ, базового и профильного ЕГЭ

Владелец поручил проверить ещё не просмотренные курсы по ссылкам из трёх экзаменационных направлений и внести учебные исправления. Для выпуска применяется [разрешение владельца](../OWNER_RELEASE_AUTHORIZATION.md).

## Как отбирались материалы

Исходные страницы — [ОГЭ](https://mathexam.space/oge/), [базовый ЕГЭ](https://mathexam.space/ege-baza/) и [профильный ЕГЭ](https://mathexam.space/ege-profil/). В область проверки входят отдельные учебные маршруты, явно названные на этих страницах, в том числе вход в учебники из меню базы и в практикумы через оглавление профиля. Охват прежних проверок сверялся по файлам и тематическим PR. Ссылка на пособие в каталоге сама по себе не означает, что по нему существует отдельный курс.

## Критерии учебной приёмки

- Из разбора Brilliant Local Extrema перенесён конкретный проверяемый вопрос. По одним нулям производной нельзя сосчитать экстремумы, если часть графиков касается оси. Число и объяснение независимо сверяются по значениям слева и справа.
- Из аудита моделей GeoGebra взята проверка особых значений одного параметра. Равенство на окружности, касание, нулевой и отрицательный пороги должны менять математический объект и ответ согласованно.
- По результатам проверки задач Образавра равносильные допустимые ответы должны давать один результат. Если задание проверяет именно форму записи, ученик должен понимать, что уже вычислил верно и какой шаг остался.
- Из изученных сценариев геймификации и практики мини-групп взята последовательность «попытка, помощь по запросу, исправление, новая задача». Просмотр решения и самостоятельная работа различаются в тех режимах, где ученик получает зачёт.

Содержательные изменения проверяются на обычном маршруте ученика и отдельными математическими примерами. Для изменённых скачиваемых тренажёров используется штатная сборка и проверка содержимого ZIP. Проверяются сохранённая работа, поведение повторного нажатия и узкий экран там, где менялся соответствующий интерфейс. Откат выполняется обычным revert коммита выпуска. Внешняя рецензия нового кода не заказывалась.

## Результаты

- **ОГЭ.** Доступны все 70 маршрутов ПредОГЭ. В информатике проверены все десять генераторов и отдельно подсчёт запусков программы с повторяющимися значениями. После ошибочного ответа сохраняется возможность новой попытки. Мини-вариант сохраняет введённое при переключении режима.
- **Базовый ЕГЭ.** Проверены 120 условий на перенос в процентах, 4500 генераций задач на работу и построения со строгими границами, кратным корнем и изолированной точкой. После изменения чертежа ученик видит, что его нужно проверить заново.
- **Школьные курсы.** Из каталога открываются Алимов и Никольский. Проверены их банки из 570 заданий и 1510 шагов. В общем курсе вероятности пройдены все 19 блоков. У шести моделей проверены привязка к содержанию, крайние значения и ответы. В 7 классе восстановлен переход с алгебры к геометрии. Для советской математики проверены 60 тем и 201 шаг.
- **Профильный ЕГЭ.** У производной есть касания и пересечения, включая работу с первообразной. У тригонометрии проверены значения на осях, дуги для неравенств и точки для равенств. У параметров сверены случаи вблизи касания. В методе интервалов можно исправить конкретную точку. По логарифмическим неравенствам пройдены все 48 заданий практикума. Все восемь уроков «Оценка плюс пример» пройдены с самопроверками.
- **Сохранённая подборка профиля.** Исправлены числовые ответы в функциях и двух входах Ященко, неверный зачёт в разности квадратов и доказательства существования разбиения в №19. Для планиметрии ответы 7600 генераций сверены по координатам. В финансовом маршруте независимо пересчитаны 442 шага. Проверки вероятности, прикладных задач и эксперта использованы для сверки предыдущей предметной приёмки.
- **Скачивание.** Семь комплектов обновлены из тех же исходников. Набор файлов каждого ZIP сохранён, извлечённый HTML совпадает с отдельной скачиваемой версией. В проверках ZIP открывается без сети на ширине 320 px, отдельный HTML — на 1280 px.

Этот отчёт фиксирует предметную и техническую проверку. Наблюдений за живыми занятиями для этой редакции не проводилось.
