## Goal / approved scope
Продолжить создание всех намеченных школьных курсов: расширить общие уроки алгебры 7–11 и вероятности, собрать последовательные маршруты 5–11, дать переходы к уже опубликованным геометрическим курсам. Использование GeoGebra необязательно по прямому решению владельца. Авторские модели используют существующий контракт модели/задачи/шага. Не выдавать общие маршруты за полное соответствие каждому параграфу 77 книг.
