# Математика по советским учебникам

60 тематических тренажёров, авторские упражнения и 60 MP4 без звука.
Это выбранная последовательность навыков, а не полный постраничный курс.
Источники и печатные страницы разделов находятся в `sources.js`.
Номер задачи можно добавлять только для упражнения, сверенного со сканом
соответствующего издания. Текущие упражнения авторские, `task: null`.

## Сохраняем старые материалы при расширении

Адрес темы `/soviet-math/#<topic-id>` и видео `media/<topic-id>.mp4`
постоянны. Новые темы получают новые ID; прежние ID не переиспользуются.
Добавляйте новую тему в соответствующий модуль, источник в `sources.js`
и сценарий для демонстрационного примера в `narration.json`.
При расширении запускайте запись только новых ID:

```sh
node tools/soviet-math-render.cjs --topics=new-topic-id
node tools/soviet-math-content.test.cjs
node tools/soviet-math.browser.cjs
node tools/soviet-math-render.cjs --check
```

Для записи нужны `@napi-rs/canvas`, FFmpeg и FFprobe; для браузерной проверки
Playwright (существующая фиксированная зависимость `video-worker`). `NODE_PATH`
может указывать на каталог установленных модулей. Проверка готовых MP4
не требует Canvas. Для реального проигрывания нужен Chrome с H.264:

```sh
node tools/soviet-math-video.browser.cjs
```

По умолчанию рендерер проверяет существующие файлы и их контрольные суммы,
не перезаписывая их. Изменение исходного задания требует явного `--replace`
для выбранного ID. Новый визуальный тип не требует перезаписи старых MP4:
версия рендерера записана отдельно от содержания задания в манифесте.
Сценарий имеет свою контрольную сумму. Продолжительность каждого объяснения
рассчитывается по его тексту: 120 слов в минуту с паузой на осмысление.

Нет ограничения каталога в 30 тем. Можно добавлять следующие выпуски по
10–20 тем до 100–200 и дальше, проверяя каждую порцию. Число вариантов
упражнения и число самостоятельных тренажёров — разные показатели.

## Непрерывная доска

`board.js` рисует и интерактивную доску, и кадры MP4. Основное решение
накапливается справа на постоянных местах; вспомогательные действия слева.
Локальное приближение сохраняет уголок видимым. В тренажёре движение можно
выключить; настройка уменьшенного движения браузера учитывается.

На телефоне две области расположены вертикально; текстовая запись решения
остаётся доступной. Подпись учебника видна над тренажёром и в самом MP4.

## Результаты

Изолированный ключ `mathExam.sovietMath.v1` хранит состояние только в текущем
браузере. Версия записи теперь 2: прежние результаты сохраняются, активные
попытки старых 30 тем остаются в `previousSessions`, обновлённый разбор
начинается с первого действия. Старое приложение при откате оставляет новую
запись нетронутой и блокирует сохранение до возвращения новой версии.
Учебные примеры и видео не начисляют самостоятельный результат.
Повтор определяется по реальному условию и рисунку, помощь и ошибки учитываются.
Повреждённая запись и конфликт другой вкладки блокируют перезапись. Результат
можно выгрузить текстом; автоматической синхронизации с кабинетами нет.


## Переработка и продолжение

Первые 30 тем переработаны по прямому замечанию автора сайта: меньше
механического переписывания, больше понятных действий с предметами, десятками
и равными частями целого. `revised-primary.js`, `revised-advanced.js` и
`revised-division.js` заменяют текущие планы, сохраняя адреса. Исходные
`primary.js` и `advanced.js` используются для проверки прежних попыток.
Перезапись первых 30 MP4 в этом выпуске выполнена намеренно; дальнейшее
добавление тем по умолчанию остаётся без перезаписи существующих роликов.

`extension-primary.js`, `extension-fractions.js`, `extension-applications.js`
добавляют ещё 30 тем, по 12 разных условий. В учебном разборе ребёнок сначала
открывает объяснение кнопкой, а в самостоятельном режиме решает сам.

Смешанные ответы (`checkKind: mixed-number`) требуют сокращённую правильную
дробную часть: `2 1/3`. Заданный знаменатель (`fraction-denominator`) проверяется
отдельно от равенства значений.

Дополнительно запускается `node tools/soviet-math-extension.test.cjs`: новые
и переработанные упражнения, перенос прежних результатов и неверные записи. Математические проверки не заменяют просмотр рисунков и
педагогическую оценку формулировок; опыт с реальными детьми отдельно не проводился.

## Пакеты для скачивания

После проверки всех записей:

```sh
python3 tools/soviet-math-package.py --out /absolute/output/directory
```

Сборщик сверяет содержание, сценарии и MP4 по контрольным суммам. По умолчанию
получаются архивы видео и DOCX партиями по 30, общий архив отдельных TXT/SRT.
Для следующей партии задайте `--first 61 --last 90`. Перед выдачей DOCX
необходимо проверить каждую страницу после рендера; существование файла
не означает, что его вёрстка проверена.
