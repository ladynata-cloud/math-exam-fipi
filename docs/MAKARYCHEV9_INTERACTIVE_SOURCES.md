# Interactive teaching references — Makarychev 9

Checked 2026-10-02 in response to the owner's request to draw on GeoGebra pedagogy.

- Thomas Gebbie, [Parabola — Vertex Form Matching](https://www.geogebra.org/m/nBvKvS5C): matching a target graph by changing a, h, k; keyboard control; new targets.
- GeoGebra Institute of MEI, [Quadratic inequalities](https://www.geogebra.org/m/PwXnVCSr): changing the quadratic by moving defining points.
- Simona Riva, [Quadratic Equations, Inequalities and Parabolas](https://www.geogebra.org/m/QvmhXbaB): connecting roots, graph height and solution intervals, explaining mistakes in another solution.

These public activity descriptions informed the instructional choices. We did not download, redistribute, embed or copy the applet code/assets. The site uses original SVG/JavaScript, original tasks and explanations. No claim to having run a full GeoGebra applet audit is made.

Implemented choices: live vertex dragging, keyboard/numeric equivalents, target-point matching and new missions, optional graph linked to interval sign selection, strict/non-strict endpoints, even roots and denominator exclusions, claim/error questions, and independent tasks after guided work. Lab exploration itself does not count as independent mastery.

Textbook edition and source provenance remain in `VILENKIN6_MAKARYCHEV9_SOURCES.md`. Source PDF/OCR stay outside the repository.
