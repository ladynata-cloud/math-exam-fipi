- Подсчёт целых чисел учитывает пустой промежуток.
- Карты задач на кольце завершаются проверкой заданных расстояний по найденной схеме.

- В тригонометрическом отношении сторон убрана нерелевантная операция деления на дробь; синус и косинус различены явно.

## Поведение и ограничения

Основные карты в task-first включены в самостоятельной учебной странице. Управляемые занятия, iframe доски, экзамены и отдельные проверки сохраняют свои контроллеры без новой учебной карты. Ранние модули показывают собственные карты только в обучении/практике. Их результаты не смешиваются с результатами основных семейств.

Предварительные упражнения открываются в новой вкладке с видимым пояснением и rel=noopener, чтобы сохранить исходную задачу. Для 17 целей невозможно обещать единый обратный переход через старый returnTo: существующий код поддерживает лишь часть адресов. Поэтому не изменяются чужие тренажёры ОГЭ.
