# Положение GIF в первом задании профильного ЕГЭ

## Задача

- Основа: `main` на `5bf401d4bbf3cbefe01002db1255a35b33ce0f9f`
- Ветка: `codex/fix-profile-geometry-gif-placement-20261112`
- Уровень проверки: `SMALL`
- Разрешение: продолжение работ по курсам и [порядок выпуска](../OWNER_RELEASE_AUTHORIZATION.md)

На первом экране шириной 320 пикселей ученик должен видеть условие и
чертёж. После #560 переходы и два GIF появились перед заданием.
Браузерная проверка #555 обнаружила, что чертёж начинается ниже экрана.

## Изменение и критерии

- Поместить переходы и оба раскрываемых GIF после учебного блока первого
  задания. Условие, чертёж, ответ и обратная связь сохраняют свой порядок.
- При смене задания связанные блоки добавляются только на подходящем
  экране и не дублируются после перерисовки.
- Изменение навигатора запускает существующую проверку геометрии на
  ширинах 320, 390 и 1280 пикселей.

## Проверки и выпуск

Проверить порядок элементов в DOM, затем выполнить существующие
браузерные проверки профильного ЕГЭ и GIF. Внешняя консультация не
проводилась, учебные материалы и сохранённое состояние не меняются.
После публикации проверить задание по публичному адресу.
