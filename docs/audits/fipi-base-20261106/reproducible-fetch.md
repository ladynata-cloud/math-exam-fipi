# Как повторить

1. На [странице демоверсий](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory) проверить, как ФИПИ называет документы 2027 года. В [открытых вариантах](https://fipi.ru/ege/otkrytyy-bank-zadaniy-ege/otkrytyye-varianty-kim-ege) выбрать математику. В `sources-manifest.json` зафиксированы точные официальные URL, UTC, HTTP, Content-Type, размеры, оригинальные имена PDF и хеши. Хранить скачанные архивы отдельно от репозитория; их копии в этот PR не добавлялись.
2. Скачать оба ZIP по HTTPS с проверкой сертификата. Проверить сигнатуру PK, все CRC (`python -m zipfile -t FILE.zip`) и `sha256sum FILE.zip`. Посчитать SHA-256 распакованных вложений. Сверить три PDF именно базового уровня с `ege-baza/sources/{demo-2027,spec-2027,open-2026}.pdf`, число страниц и постраничный JSONL. Не заменять оценку официального банка набором PDF.
3. Из корня репозитория: `node docs/audits/fipi-base-20261106/build-matrix.cjs --check`; `node tools/ege-baza-153.test.cjs`; `node tools/ege-baza-practice.test.cjs`. Для обновления CSV запустить первую команду без `--check` и просмотреть разницу. Список модулей берётся из действующего HTML маршрута; подготовительные уроки с позициями вне 1–21 исключены. Не превращать новые семейства в задним числом подтверждённые официальные подтипы.
4. Открыть [штатный банк](https://ege.fipi.ru/bank/) через [страницу ФИПИ](https://fipi.ru/ege/otkrytyy-bank-zadaniy-ege). Во время этого аудита получен 503: не было реестра, курсора или подтверждённой записи. Пустой records.jsonl не выдаётся за выгрузку. При восстановлении доступа сохранять реально показанные ID, ссылки, ответы (или факт отсутствия), изображения и границы страниц. Перед продолжением сверить последний официальный ID, чтобы не дублировать страницу; при отказе сохранить прогресс и остановиться. Скрытые API не использовались.
