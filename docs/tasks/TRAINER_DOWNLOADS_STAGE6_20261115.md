## Goal

Продолжить скачивания MathExam четырьмя тренажёрами по темам профильного ЕГЭ. Ученик может открыть HTML из ZIP без сети. Преподаватель может изменить копию по примеру в инструкции и проверить её ответы.

## Context and evidence

Пятый этап уже включает шесть тренажёров профиля, в том числе START с основами векторов. Все 14 проверок PR #605 успешны на указанном SHA. Публичный каталог скачиваний показывает этап 1 и 17 записей. Удалённая main при старте — `0a375390859437359427aaf1befac3d12754e837`.

## Approved scope

| --- | --- |
| Основы и методы · атлас функций | 11 тем, 44 навыка, 25 графиков и учебная модель сечения координатно-параметрической плоскости |

В каждой панели есть отдельный HTML, промпт и ZIP. В ZIP также есть инструкция и GIF с кадрами. На странице профиля добавлен сворачиваемый список из 10 подготовленных комплектов двух этапов. Для финансовой задачи подготовлен GIF о замене пяти дней просрочки на четыре. В атласе локальные переходы работают при открытии из файловой системы.

За пределами этапа остаются изменение проверки чисел в тренажёрах этапа 5, авторизация, общая доска, большая модель 3D-сечений, сверка нумерации экзамена и выпуск на сайт.

## Checks and gates

- В браузере открыть четыре отдельные копии и четыре HTML из ZIP на ширинах 320 и 1280 px. Проверить задачи, модели, подсказки и локальные переходы. В атласе открыть выколотую точку, сравнить два уровня горизонтали и восстановить черновик упражнения после перезагрузки.
- Открыть изменённую копию финансовой задачи. Исходные пени февраля равны 60 тыс. ₽, новые — 48 тыс. ₽. Сверить таблицу, объяснение и проверку ответа. В новой копии 375,1 отклоняется, 363,1 принимается.
- Сверить работу панелей, GIF, списка ZIP и текстовой инструкции без JavaScript. Проверить общий ZIP, сохранность 47 ранних записей, воспроизводимость сборки, математические регрессии и привязки навигатора.
- Итоговый маркер — `TRAINER_DOWNLOAD_STAGE6_OK`. Итоговые прогоны и GitHub CI фиксируются в PR по точному SHA.
- Внешняя консультация, апробация с учениками и запуск непосредственно в Windows отсутствуют в этом этапе.

## Review plan and rollback

Использованы действующие учебные страницы и их модели. Независимо пересчитаны ответы примера финансового GIF, числа пересечений и ответ планиметрической задачи в браузере. Проверяется состав встроенных ресурсов и точная область изменений. Пользовательские данные и материалы кабинетов не входят в передачу. Откат — отмена коммитов этапа 6, с возвратом к каталогу этапа 5.
