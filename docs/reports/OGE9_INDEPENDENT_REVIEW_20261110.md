## Подтверждённые дефекты исходной версии и повторная проверка исправления

1. `stCanon` автоматически менял знаки пары коэффициентов при отрицательном коэффициенте x, не объясняя дополнительное умножение на −1. При вопросе «собери x слева, числа справа» показывал для AB4778 `5x=−2` вместо буквально получаемого `−5x=2`; для 4F57B2 — `10x=−9` вместо `−10x=9`; для two-brackets-2 — `4x=−26` вместо `−4x=26`. Равносильность не нарушена, но показанный шаг не соответствовал инструкции. Автоматическая смена знаков удалена; три регрессии проходят. Деление на отрицательное число работает.
2. `stFactorNC` принимал любые пропорциональные коэффициенты без пояснения. Например для `4x²−20x=0` ввод `1; −5` принимался как обычное вынесение x, хотя сначала выполнено деление уравнения на 4. Теперь ответ по-прежнему принимается и явно назван дополнительным равносильным преобразованием. Проверено.
3. `stRoots` называл корень с минусом перед √D корнем x₁, тогда как показ шага всегда называл x₁ меньший корень. При допустимом отрицательном a эти обозначения расходились. Теперь подсказка допускает любой порядок и поясняет, что при a<0 первая формула даёт больший корень. Проверено на эквивалентной форме `−2x²+3x−1=0` для демоверсии 2026.
4. `checkFinal` направлял к «кнопке ниже», хотя кнопка помощи стоит выше поля ответа. Из текста убрано неверное пространственное указание.

Это ошибки точности объяснения и сопровождения, не неправильные конечные ответы.

5. Уточнена метка «Проект демоверсии ФИПИ 2027». В существующем блоке «Об этом задании» добавлены ссылки и явное различие прямой сверки демоверсий, косвенной сверки банка и авторского аналога.
