# Макарычев, 8 класс. Корень и пересечения графиков

Печатная с. 259, страница 260 PDF учебника Макарычева 2024 года, ISBN 978-5-09-116445-9. Семь карточек, 21 шаг.

Для №1161 сохранены все пять заданных абсцисс. Ученик исследует отдельную подстановку и упорядочивает ординаты. Проверка различает убывание соседних чисел и ошибку в уже упорядоченном списке.

В №1162 отдельно разобраны четыре исходные прямые. Для каждой можно задать абсциссу и сравнить высоты, включая точное равенство для рациональных точек. Подходят первая, вторая и четвёртая прямые. Третья расположена ниже всей ветви корня.

В №1163 ученик строит гиперболу по собственным точкам двух ветвей с учётом исходного знаменателя. Выколотая точка имеет координаты (−3/4; −4/3). При изменении наклона модель считает и отмечает сохранившиеся пересечения. Единственная общая точка получается при k = 16/9.
