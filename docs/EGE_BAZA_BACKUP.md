# Резервная копия результатов базового ЕГЭ

Реализовано в черновике задачи `EGE_BAZA_COURSE_04_BACKUP`, 2026-10-01.
Это часть шага 4 общего плана, а не завершение всего контракта курса.

## Для ученика и преподавателя

В навигаторе откройте «Мой прогресс» → «Сохранить или восстановить работу».
Ссылка есть также в отчёте первого модуля. Скачайте JSON-файл. Он содержит
работу первого модуля: ответы, число попыток, подсказки, просмотр решений,
пропуски, завершение проверок и отметку обращения к обучению.

Для восстановления выберите файл. Сначала видны текущие результаты и то,
что появится после переноса. Нажатие «Отмена» ничего не меняет. Для записи
нужно отдельно отметить согласие на замену и нажать кнопку восстановления.
Перед этим можно скачать текущее сохранение. Если оно повреждено, доступна
его исходная текстовая копия для разбора.

Результаты заменяются только в первом модуле базового ЕГЭ. Работы разных
учеников не объединяются. Файлы обрабатываются локально в браузере; нет
автоматической отправки преподавателю, регистрации или серверной синхронизации.
TXT-отчёт нужен для чтения, JSON-копия — для восстановления.

Перед переносом закройте остальные вкладки с модулем. Если результат изменился
после предпросмотра, восстановление отменяется до нового выбора файла.
Сам модуль сравнивает сохранение перед действием/записью и обновляется после
изменений в другой вкладке; старый открытый ответ не должен затереть импорт.
Это проверка актуальности, не атомарная блокировка между вкладками.

## Формат версии 1

```json
{
  "format": "mathexam-ege-baza-backup",
  "version": 1,
  "exportedAt": "2026-10-01T00:00:00.000Z",
  "modules": {
    "m01": {
      "bankVersion": 1,
      "state": { "v": 1, "practice": {}, "runs": {} }
    }
  }
}
```

Это минимальный пример пустого состояния, не пример завершённого обучения.
Рабочий ключ остаётся `mathexam.ege-baza.foundation.v1`. Нового центрального
ключа и миграции нет. Файл задаёт общую оболочку для дальнейшего расширения,
но текущая версия принимает ровно `m01`; другие модули/версии отклоняются.
При добавлении новых модулей формат и его совместимость расширяются явно.

Проверяются размер (до 256 КБ UTF-8), структура и разрешённые поля, ID задач,
типы отметок помощи, число попыток, соответствие `done` фактическому ответу,
непрерывность проверочных ответов и время завершения. Неизвестные поля не
отбрасываются молча. Данные копируются в свежую структуру; ключ хранилища
не берётся из импортируемого файла. Готовые баллы не импортируются.

При экспорте порядок полей может измениться, их значения сохраняются.
Один вызов localStorage.setItem заменяет только состояние первого модуля.
Перед ним повторно проверяются данные и снимок текущего сохранения;
после него проверяется чтение записанного значения. Ошибка записи не
выдаётся за успешное восстановление. Защиты от намеренной подделки ответов
или системных часов нет; локальная копия не является экзаменационным протоколом.

## Проверки

```sh
node tools/ege-baza-backup.test.mjs
node tools/ege-baza-navigator.test.mjs
node tools/ege-baza-foundation.test.mjs
node tools/ege-baza-foundation.dom.mjs
node tools/ege-baza-backup.browser.mjs
python tools/build-ege-baza-preview.py /absolute/output/ege-baza-with-backup.zip
```

Для DOM-тестов нужен jsdom через NODE_PATH. Для браузерного теста нужен
Playwright; путь к Chromium при необходимости задаётся через
`NAVIGATOR_CHROMIUM_PATH`. Браузерный сценарий включает настоящий JSON-download,
загрузку файла, подтверждение, отмену, другую вкладку и ширину 360 пикселей.

Проверено автором: 69 сценариев резервной копии/конфликтов/DOM,
238 проверок навигатора, 81 проверка модуля и все 60 ответов.
Пакет просмотра содержит 10 файлов; проверяются целостность ZIP и ссылки.
Реальный браузерный сценарий в этой среде не выполнен: запуск Chromium
ранее завершился запретом socket. Это обязательный открытый пункт перед выпуском.

## Ревью и откат

Уровень HIGH: восстановление меняет данные ученика. Авторские тесты не
заменяют независимое/внешнее ревью. Его точные base/head и результат должны
быть записаны до выпуска; либо владелец отдельно принимает исключение
по действующей политике. Сейчас исключение и выпуск не запрашиваются.

Откат к предыдущему черновику удаляет интерфейс копирования и защиту актуальности.
Восстановленные данные остаются совместимыми с предыдущей версией первого
модуля, поскольку ключ и структура `v:1` сохранены. Для возврата содержимого
ученик использует отдельно скачанную предыдущую копию; откат кода не откатывает
учебную работу автоматически.

Следующие задачи: дополнительные проверочные формы с историей попыток,
учёт подготовительных навыков и новые содержательные модули. Эти функции
не объявляются готовыми только из-за появления оболочки резервной копии.
