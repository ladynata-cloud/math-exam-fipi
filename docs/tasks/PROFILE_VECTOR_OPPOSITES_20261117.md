# Противоположные векторы в начале маршрута №2

Уровень проверки SMALL. Ученик должен встретить определение противоположных векторов во второй теме, сразу после знакомства с направленным отрезком, до правил сложения. Карточка второй темы показывает это прямо в названии.

В справке второй темы вектор BA получается из AB перестановкой начала и конца. В прежней задаче о двух стрелках разбор сравнивает равные длины и противоположные направления. Разность (a-b) остаётся в своём уроке со своими условиями. Маршруты уроков, идентификаторы и ответы всех 54 задач сохраняются.

Проверить переход из официального №2 на узком экране, определение и разбор в прежней задаче, использование подсказки с клавиатуры, сохранённые ответы и автономный HTML внутри ZIP. Выпуск по [согласованному разрешению владельца](../OWNER_RELEASE_AUTHORIZATION.md).
