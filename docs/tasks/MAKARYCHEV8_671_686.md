# Макарычев, 8 класс. Уравнения с двумя переменными №671–686

Глава III, §10, пункт 28. Макарычев и др., под ред. С. А. Теляковского, «Просвещение», 17-е издание, 2024, электронный ISBN 978-5-09-116445-9. Сверены печатные страницы 157–160 (рисунки 26–29 и все подпункты) и стр. 310. SHA-256 выданного PDF: `356695f0f11a489090ed72428320a6d6cc343747eec02968b716c2204caaced8`.

Добавлены 50 карточек и 100 проверяемых шагов. Вместе с двумя прежними подпунктами №671а, б пункт содержит 52 исходные карточки. Для №672 принимаются три произвольные различные рациональные точки. Ученик самостоятельно строит каждую прямую по двум точкам, включая вертикальные прямые и графики из двух ветвей. В №679–680 допустимы раскрытые, переставленные и пропорциональные уравнения второй степени. Четыре рисунка воспроизведены своими координатными чертежами.

В ответах на стр. 310 есть два расхождения с условием на стр. 160. Для №686а непосредственное деление даёт (x−1)/(2x³), например 1/16 при x = 2. Выражение из ключа с 4x³ даёт 1/32. Для №686б из исходных множителей получается (48n²−3)/(8n²), например 45/8 при n = −1. Выражение из ключа с 8n³ даёт −45/8. Карточки объясняют эти расхождения и сохраняют ограничения исходных дробей.

Непрерывные решения охватывают №1–686. Далее следуют №687–695 об исследовании систем линейных уравнений.
