# Офлайн-комплект шестого урока стереометрии

- Задача: редактируемая автономная копия урока «Пирамиды и усечённые пирамиды».
- Основа: `main` на `beffcbe1895e45f8d243e12d250181ac2ce62e1a` ([PR #615](https://github.com/ladynata-cloud/math-exam-fipi/pull/615)).
- Ветка: `codex/college-stereometry-lesson-6-offline`.
- Уровень проверки: `MEDIUM`. Новый способ открыть существующий урок и адаптировать задачу.

## Состав

- Ссылка на ZIP в шапке урока 6.
- Автономный архив с локальными скриптами, стилями, инструкцией и GIF. Условие задачи, параметры чертежа, ответы и разбор редактируются в `content.js`.
- Сборка из действующих исходников с заменой навигации в офлайн-копии. Уроки 1–5, каталог курса и исходная логика урока 6 сохраняются.

## Приёмка

- Открытие распакованного `index.html` по `file://` в браузере с отключённой сетью.
- Исследование, изменение сечения, поворот, чертежи, числовые ответы и точные корни, подсказки, сохранение после перезагрузки и печать домашней работы.
- Проверка при ширине 320 и 390 пикселей.
- Воспроизведение инструкции на копии: исходные ответы 17 и 544 отклоняются, новые ответы 13 и 624 принимаются.
- Сверка производственного ZIP с исходниками и проверка отсутствия изменений в предыдущих пяти уроках.

Сборка и проверки из корня репозитория

```sh
python tools/college-stereometry-offline/build.py
python tools/college-stereometry-offline/build.py --check
node tools/college-stereometry-pyramids.test.cjs
python -B tools/college-stereometry-offline/verify.py
```

Для браузерной проверки нужен Python Playwright с установленным Chromium. Можно передать путь к уже установленному браузеру через `--chromium`.

## Риски и выпуск

При изменении задачи нужно согласовать условие, параметры модели и шаги решения. Инструкция показывает конкретный пример и рекомендует новый идентификатор для отделения сохранённых ответов. Для отката достаточно отменить этот PR. По запросу владельца открывается Draft PR. Для объединения и публикации требуется отдельное разрешение владельца.
