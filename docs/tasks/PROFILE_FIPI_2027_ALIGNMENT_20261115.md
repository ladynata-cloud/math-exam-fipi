## 5. Контракт совместимости

### 5.1. Разделение номера и идентичности

Предлагается один общий модуль соответствия `ege-profil/exam-map.js`. Он связывает:

- официальный номер и год;
- стабильную тему;
- действующие lesson/task IDs;
- прежний routing key;
- прежний storage key;
- актуальную подпись, связанные курсы и тип подготовки.

Не делать массовой замены чисел в данных. Не использовать отображаемый номер как новый ключ ученического результата.

### 5.2. Старые и новые ссылки

Старые `#exam/N`, `#calm/N`, query `exam=N` сохраняют прежнее содержательное назначение. На открытой старой теме показывается актуальный номер.

Примеры обязательной совместимости:

| Старый вход | Что он должен продолжать открывать |
|---|---|
| START #calm/13 и #exam/13 | Финансовую подготовку, теперь связанную с № 16 |
| START #exam/16 | Неравенства, теперь № 15 |
| Part Two #exam/14 | Уравнения, теперь № 13 |
| Part Two #exam/15 | Стереометрию, теперь № 14 |
| Part Two #exam/17 | Прежнюю дополнительную оптимизацию |
| Part Two #exam/19 | Параметры, теперь № 18 |
| Part Two #exam/20 | Числа и свойства, теперь № 19 |
| azbuka-metodov/?exam=19 | Прежний контекст параметров |

Для новых экзаменационных ссылок использовать отдельное однозначное пространство маршрутов; допустимый вариант — `#fipi/2027/N`. Дополнительные темы получать по стабильному topic ID. Окончательное написание и внутренний адаптер — частное техническое решение исполнителя; неизменность старого значения URL обязательна.

Глубокие `#lesson/<stableId>`, `#task/<stableId>/<mode>` и `#practice/<stableId>/<mode>` остаются работоспособны.
