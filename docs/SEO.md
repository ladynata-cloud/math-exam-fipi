# Поисковая видимость MathExam

Основная входная страница сайта посвящена подготовке к ОГЭ. Математические
основы помогают вернуться к пропущенным навыкам; остальные курсы сохраняют
свои адреса. Поисковая настройка не меняет прогресс ученика и работу кабинетов.

## Что проверять при добавлении публичной страницы

1. У страницы есть самостоятельный смысл: объяснение темы, учебный маршрут
   или работающий тренажёр. Не создавать копии ради разных поисковых фраз.
2. `title` точно называет тему. `description` кратко описывает содержание
   конкретной страницы. Не обещать возможности, которых на ней нет.
3. `canonical` указывает предпочтительный адрес на `https://mathexam.space/`.
   Для новых индексных страниц используем адрес каталога с `/`.
4. На страницу ведёт обычная HTML-ссылка из подходящего курса или каталога.
   Состояние приложения после `#` не считается самостоятельной страницей
   для карты сайта. Не переносить старые адреса тренажёров из книги.
5. Объяснение и основной переход доступны в исходном HTML. Взаимодействие
   внутри тренажёра может использовать JavaScript.
6. Для страниц, уже имеющих `noindex`, сохранить установленное ограничение,
   пока отдельно не принято решение об их открытии поисковикам.

Обновить и проверить карту сайта:

```bash
python3 tools/build-sitemap.py
python3 tools/build-sitemap.py --check
python3 tools/seo-sitemap.test.py
python3 tools/seo-check.py
git diff --check
```

Генератор берёт явно перечисленные входы из `tools/seo-public-pages.json` и
идёт по обычным ссылкам только внутри разрешённых публичных разделов. Если
новый раздел не охвачен этими правилами, добавить его после проверки
публичности. Не включать все HTML-файлы репозитория автоматически.

Карта исключает страницы с `noindex`, перенаправления, кабинеты, архивы,
служебные страницы, параметры запросов и фрагменты адресов. Наличие файла
в карте не гарантирует его индексирования поисковой системой.

`lastmod` пока не формируется: в старой карте стояли одинаковые устаревшие
даты, а время запуска генератора и дата неглубокого клонирования Git не
являются датой содержательного обновления страницы. Вернуть этот элемент
можно при наличии надёжного источника дат. `priority` и `changefreq` не нужны.

Проверка **Public SEO and sitemap** запускается для изменений HTML и
SEO-файлов в pull request. Если она сообщает об устаревшей карте, выполнить
генератор и включить обновлённый `sitemap.xml` в тот же PR.

## Входы по учебным темам

- `/topics/` — каталог разборов;
- `/topics/delenie-ugolkom/` — деление уголком и десятичный делитель;
- `/topics/obyknovennye-drobi/` — основные действия с дробями;
- `/topics/procenty/` — три типа задач через пропорции;
- `/topics/lineynye-uravneniya/` — равносильные преобразования и проверка;
- `/topics/oge-geometriya/` — свойства фигур и задания 15–19.

Эти страницы содержат статические примеры и ссылки на существующие
тренажёры. Все шаги видны одновременно. Новые тексты не подменяют банк задач.

## Google и Яндекс: действия владельца

Сначала посмотреть, добавлен ли сайт в существующие аккаунты:

- [Google Search Console](https://search.google.com/search-console/)
- [Яндекс Вебмастер](https://webmaster.yandex.ru/)

Отсутствие метатега в HTML не доказывает отсутствие подтверждения: сайт
может быть подтверждён через DNS или другим способом. Не создавать повторно
уже существующий ресурс и не удалять имеющиеся токены подтверждения.

Если подтверждения ещё нет, для Google можно добавить ресурс **с префиксом
URL** `https://mathexam.space/` и выбрать HTML-тег. Для доменного ресурса
Google нужен способ через DNS. Яндекс также поддерживает подтверждение
метатегом. Сервис выдаёт конкретное значение, которое владелец может передать
для установки в `<head>` главной. Пароли и коды входа для этого не нужны.

После подтверждения:

1. Отправить `https://mathexam.space/sitemap.xml` в обоих кабинетах.
2. Проверить главную, курс ОГЭ, математические основы и новые разборы.
3. Посмотреть причины исключения страниц и при необходимости запросить
   повторный обход изменённых входов.
4. Оценивать показы, переходы, поисковые запросы и входные страницы.
   Фраза `site:mathexam.space` не заменяет эти отчёты.

Подключение счётчика посещений — отдельный шаг с реальным идентификатором
счётчика. Не добавлять вымышленные идентификаторы или чужие коды аналитики.
