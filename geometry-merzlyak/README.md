# Мерзляк 7–9

Мерзляк–Полонский–Якир: 7 класс — 2015, 8 — 2013, 9 — 2022. Углубление: Мерзляк–Поляков, 2019/2022.

84 учебных узла и 149 пунктов карты. Авторские уроки и задачи, не полный задачник. Письменные доказательства оценивает преподаватель. Прогресс хранится локально, отдельно от других курсов; доступен экспорт и импорт.

Сборка: `python tools/merzlyak/build.py`. Для автономного запуска сохраняйте всю папку курса. Исходные учебники в публикацию не входят.
