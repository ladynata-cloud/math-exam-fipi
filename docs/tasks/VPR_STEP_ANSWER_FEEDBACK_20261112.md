# ВПР. Пояснение к итоговому ответу на промежуточном шаге

Владелец попросил пояснять ученику, когда введён ответ на другой вопрос.
В задаче про пирог итоговая дробь 5/8 верна, а первый шаг спрашивает
о количестве оставшихся кусков.

- База `main` `a30d60dfe5e828bf669a4f69065446457cc60ef7`.
- Ветка `fix/vpr-step-answer-feedback`.
- Уровень проверки `SMALL`.
- Выпуск после проверок по [действующему разрешению владельца](../OWNER_RELEASE_AUTHORIZATION.md).

## Приёмка

- В режиме «По шагам» проверка прежде всего оценивает ответ на текущий шаг.
- Если на промежуточном шаге со свободным вводом ученик вводит верный
  итоговый ответ задачи, тренажёр сообщает об этом и показывает вопрос шага.
  Ученик продолжает с этого шага, а счётчик ошибок учитывает неверные ответы.
- В примере первый шаг принимает 5, второй шаг и самостоятельный режим
  принимают 5/8. Эквивалентная десятичная запись 0,625 получает то же пояснение
  на первом шаге.

## Проверка и выпуск

- Проверить сценарий с пирогом, подсчёт ошибок и самостоятельный режим в DOM.
- Выполнить проверки ВПР и `git diff --check`. Сверить поведение на
  опубликованной странице. Результаты зафиксировать в PR.
- Для отката использовать штатный обратный коммит этой правки.
