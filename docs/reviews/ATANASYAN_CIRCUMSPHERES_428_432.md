# Правильные пирамиды и сферы. Задачи №428–432

Все десять подпунктов сверены по печатным страницам 114–115 двенадцатого издания 2024 года. Численные ответы и указание к №429 сопоставлены с печатной страницей 266. Условия изложены своими словами. Для каждой карточки подготовлены собственный чертёж, вопросы, подсказки, доказательства переходов и самостоятельная проверка.

Второй участник независимо проверил формулу боковой поверхности правильной квадратной пирамиды, ответ для угла 60°, свойства осевой касательной трапеции, положение центра описанной сферы и все три коэффициента площади в №432. В №428а явно определены обозначения q и l. В №431б пропорциональность расстояния до боковой плоскости доле пути по SK выведена из подобия прямоугольных треугольников. Для этого доказательства достаточно материала, изученного до введения объёмов.

| Номер | Содержание проверки |
| --- | --- |
| 428а, б | Модель касается каждой грани. Независимый расчёт по площадям треугольных граней и подстановка 89 острых углов подтверждают две формы одного ответа. |
| 429 | Проверены четыре точки касания в осевом сечении и равенство апофемы полусумме сторон оснований. |
| 430а, б | Все вершины призмы и пирамиды находятся на сфере. В модели низкой пирамиды центр лежит ниже основания. |
| 431а, б | В несимметричном тетраэдре раздельно проверены равноудалённость от четырёх вершин и касание каждой грани. Для вписанной сферы также проверено деление отрезка SK. |
| 432а, б, в | Площади всех граней независимо суммируются по координатам. Площадь поверхности, делённая на квадрат радиуса, даёт заявленный коэффициент во всех трёх моделях. |

Вместе с предыдущей частью получаются 708 проверенных карточек и полный основной ряд №1–432 из 870. Следующий основной номер — 433.
