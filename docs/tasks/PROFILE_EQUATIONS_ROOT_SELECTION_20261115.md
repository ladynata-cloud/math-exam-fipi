# Уравнения и отбор корней в задании №13 ЕГЭ

Рабочая спецификация H06 на основе [согласованного методического пакета](https://chatgpt.com/space/page_cf4723c67b3481918b87d58aa6e51fee). Реализация начата от принятого H05, `0bfbcab1108fddf162a4f738e28c8c5a36c9459c`. Ожидаемый результат этапа — отдельный проверенный Draft PR.

## Задания и обучение

Шесть действующих уроков сохраняют первые шесть задач, формулировки и идентификаторы. Два новых самостоятельных условия продолжают каждый урок. Четыре новых тригонометрических условия требуют написать полное общее решение и отобрать корни. В остальных восьми заданиях проверяется полное множество решений с учётом ОДЗ. Открытие двух содержательных подсказок и раскрытие полного разбора — отдельные действия. Написанное объяснение проверяется по критериям самопроверки H05.

Каждый урок даёт собственное исследование, связанное с методом. Ученик сначала отвечает на вопрос прогноза, затем меняет значение, видит и объясняет результат и проверяет вывод на другом примере. Состояние сохраняется для каждого урока. Историческое исследование `mathexam.profilePartTwoLab.v1.14` сохраняет свой маршрут и данные. Исследование само по себе не формирует попытку или зачёт задачи.

Ориентиры для тригонометрии, показательной замены, ОДЗ и граничных примеров закреплены по [демоверсии ФИПИ-2027](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory), [сборнику Ященко](https://ege314.ru/13-uravneniya/reshenie-6568/), [открытым вариантам Лысенко и Кулабухова](https://onvid.org/page/math/math273.htm) и [СтатГраду](https://math-ege.sdamgia.ru/problem?id=707184). В самостоятельных задачах использованы новые формулы, числа или границы отбора и отдельные письменные объяснения.

## Ввод и сохранение

Неизменные маршруты — `#fipi/2027/13`, `#exam/14`, `#lesson/p14-*`, `#task/p14-*`. Самостоятельная форма прежних заданий принимает точное множество решения. Круговой ввод для учебного уравнения `sin x = 1/2` принимает две серии и чередующуюся запись без прибавления самостоятельного результата. Прежние черновики чисел видны в своём исходном формате. Табличные или расчётные значения из пошаговой формы не считаются готовым ответом самостоятельной формы.

Сравнение множества корней выполняется точно. Непонятная форма ввода не считается математической ошибкой. Результаты общего решения и отбора сохраняются отдельно по версиям ввода. Верное общее решение может остаться проверенным при правке только отбора. Новый зачёт двухчастного условия требует верных ответов на обе части. При одновременной правке две вкладки используют существующую атомарную запись. Сохранения H05, старые ответы, попытки и помощь остаются доступны по прежним идентификаторам.

## Приёмка

- Сохранились 36 прежних условий №13 и остальные темы второй части. В шести уроках доступно 48 задач.
- Две равносильные формы записи `sin x = 1/2`, случаи с открытыми концами, пустым множеством и ОДЗ проверены независимо.
- Проверены ошибочный отбор при верном общем решении, восстановление черновика, две вкладки, нейтральный чек-лист H05, раскрытие подсказок и следующий самостоятельный пример.
- На узком экране читаются условия и конечные множества. Исследования управляются с клавиатуры и не требуют сети.
- Прежние маршруты и сохранения проходят профильные проверки. Автономные копии START и второй части собраны из актуальных источников, проверены HTML и содержимое ZIP.
