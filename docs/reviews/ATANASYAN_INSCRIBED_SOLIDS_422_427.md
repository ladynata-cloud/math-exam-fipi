# Задачи №422–427. Вписанные и описанные тела

Сверены условия, подпункты и величины по двенадцатому изданию учебника Атанасяна для 10–11 классов (2024), печатная страница 114, PDF-страница 116. Объяснения, схемы, обратная связь и задания для самостоятельной проверки написаны для сайта.

Второй участник независимо пересчитал все семь вычислительных ответов и прочитал три доказательства. После разбора уточнены обозначения в №422, запись радикалов в №423, перенос теоремы Пифагора на три разные усечённые пирамиды в №424 и переход от площади одной грани к полной поверхности в №427а. В №427б уточнено название правильного шестиугольника.

| Номер | Что проверено |
| --- | --- |
| 422 | Диаметр основания цилиндра, прямой вписанный угол и плоскость линейного угла. |
| 423 | Две различные апофемы прямоугольной пирамиды, образующая описанного конуса, отношение полных площадей. |
| 424а, б, в | Площади правильных усечённых пирамид с тремя, четырьмя и шестью сторонами основания. Расчёт через грани координатной модели независимо повторяет формулы через апофемы. |
| 425, 426 | Равные расстояния до граней призмы и пирамиды. В координатной модели проверена касательность к каждой грани. |
| 427а, б, в | Коэффициент при радиусе в квадрате в площади куба, правильной шестиугольной призмы и правильного тетраэдра. |

На ширинах 320, 390 и 1280 пикселей проверены вход по номеру, нейтральная модель, смена ракурса, все предусмотренные состояния рисунков, подсказки, объяснения и сохранение работы после перезагрузки. Для 14 полей шага проверены неверный и верный ответы на каждой ширине. Отдельно осмотрены изображения всех десяти моделей на экране телефона.

Доступны 698 проверенных учебных карточек. Основной ряд включает все номера 1–427 из 870. Следующий номер для наполнения — 428.
