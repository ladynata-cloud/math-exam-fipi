Что проверяет работа

Работа проверяет базовое решение квадратных уравнений с целыми корнями. В каждом варианте есть уравнения с двумя положительными, двумя отрицательными и разными по знаку корнями, а также квадрат двучлена с единственным корнем. Ученик может использовать дискриминант, разложение на множители или теорему Виета, если объясняет выбранный способ.

  • Находить оба целых корня приведённого квадратного уравнения.
  • Работать с разными знаками коэффициентов b и c.
  • Узнавать квадрат двучлена и уравнение с одним корнем.
  • В контрольной — сначала делить все члены уравнения на общий ненулевой множитель.
  • Проверять полученные значения подстановкой или связью суммы и произведения корней.

Что нужно знать перед проверкой

  • Приведение уравнения к виду ax² + bx + c = 0 и определение коэффициентов с их знаками.
  • Формула корней квадратного уравнения и вычисление дискриминанта.
  • Произведение, равное нулю; формула квадрата двучлена и проверка подстановкой.

Посмотрите задания перед скачиванием

Первые два задания самостоятельной, вариант 1. Полная работа с местом для решения — в PDF.

  1. Решите: x² − 3x + 2 = 0.

    Посмотреть решение

    Разложим: (x − 1)(x − 2) = 0. Корни 1 и 2.

    Ответ: x = 1; 2.

  2. Решите: x² + 3x + 2 = 0.

    Посмотреть решение

    Разложим: (x + 1)(x + 2) = 0. Корни −1 и −2.

    Ответ: x = −2; −1.

Как провести и проверить

  1. До проверки попросите учеников назвать a, b и c в одном уравнении, особенно выделив знак перед b.
  2. Предложите выбрать способ решения самостоятельно и записать его так, чтобы ход рассуждения можно было проверить.
  3. После работы разделите ошибки на три группы: вычисление дискриминанта, знак −b, потерянный второй корень. Каждой группе дайте короткое упражнение на её затруднение.
  4. Обсудите, почему у квадрата двучлена, равного нулю, один корень, хотя в формуле обычно стоят два знака.

Самостоятельная: 1 + 1 + 2 + 2 = 6 баллов. Контрольная: 5 заданий по 2 балла = 10 баллов. Подробные критерии и предлагаемая шкала отметок находятся в файлах с решениями. Время ориентировочное; его можно изменить с учётом класса.

Типичные ошибки и работа над ними

  • Вместо −b подставлен коэффициент b без смены знака.

    Сначала выпишите коэффициенты, затем отдельной строкой вычислите −b. Только после этого подставляйте числа в формулу.

  • После разложения на множители найден корень только одного множителя.

    Запишите два простых уравнения, по одному для каждого множителя, и проверьте оба найденных значения.

  • На общий множитель разделена только часть уравнения.

    Обведите каждый член и отметьте результат деления у каждого. Сравните корни исходного и упрощённого уравнений подстановкой.

Подготовка и разбор ошибок в тренажёрах

  • Квадратное уравнение по шагам
