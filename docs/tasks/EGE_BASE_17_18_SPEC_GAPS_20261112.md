## Связь со спецификацией

Приложение к проекту спецификации ФИПИ 2027, печатная страница 11, перечисляет тригонометрические уравнения для №17 и показательные и логарифмические неравенства для №18. Сохранённая [спецификация](../../ege-baza/sources/spec-2027.pdf) совпадает побайтно с PDF из [официального архива](https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2027/ma_11_2027.zip), повторно проверенного 12 ноября.

| Номер | Авторская практика | Что проверяет ученик |
|---|---|---|
| 17 | Синус и косинус на заданном обороте | Табличное значение, знак по четвертям, оба корня и выбор по вопросу |
| 18 | Показательное неравенство | Одинаковое основание, направление при возрастании и убывании, строгая граница, подсчёт целых решений |
| 18 | Логарифмическое неравенство | Положительность аргумента, переход к степеням, пересечение решения с ОДЗ и заданным диапазоном |

Каждое семейство использует отдельный идентификатор, карту навыков, подсказки по шагам, справочный лист и отдельный пример для самопроверки. Состав пробной работы и диагностики сохранён. Авторские условия привязаны к проверяемым умениям спецификации. Полное покрытие официальных подтипов остаётся неподтверждённым, публичный банк ФИПИ вернул HTTP 503.

## Приёмка

- Независимый перебор корней тригонометрического уравнения по целым градусам и целых решений обоих неравенств на 80 условиях каждого семейства.
- Проверка шага и окончательного ответа, связи с картой и справкой, самопроверки без начисления результатов курса.
- Проверка узкого экрана, доступности всех 21 номеров, сформированных каталогов для браузеров без JavaScript и согласованности каталога доски.
- Прежние идентификаторы и задания сохранены. При необходимости откат выполняется обратным коммитом, прежние результаты ученика сохраняются.
