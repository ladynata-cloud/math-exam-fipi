# Атанасян 7–9: задачи по номерам учебника

Целевое издание: базовый уровень, 14-е переработанное, 2023; PDF-страница
равна печатной странице +1. Родительский тематический курс, его маршруты
и сохранённые результаты продолжают работать.

## Состав сборки: главы I–III

403 карточки: 227 номеров учебника (309 частей задач), 30 пунктов теории и 64 вопроса
для повторения. Глава I содержит 173 карточки, глава II «Треугольники» — 163,
глава III «Параллельные прямые» — 67: все 43 части задач №191–227,
семь пунктов теории №24–30 и 17 вопросов. У каждой
карточки — собственная плоская модель. Дополнительные
построения появляются по шагам, разные случаи переключаются, вычисления
и объяснения остаются вне рисунка. Сборка сохраняет все 336 прежних карточек,
их идентификаторы, подтверждения проверки и ключи ученических записей.
Глава III подготовлена как отдельный этап; её наличие в ветке или PR
само по себе не означает выпуск на публичном сайте.

Подтверждение проверки каждой главы связано с хешами её материалов и общего
интерфейса: `release-review.json` относится только к главе I,
`release-review-chapter-02.json` — только к главе II,
`release-review-chapter-03.json` — только к главе III. Без совпадающего подтверждения
карточки соответствующей главы остаются `in-review`. Перед публикацией дополнительно
требуются проверки точного коммита и предусмотренное проектом разрешение
на выпуск. Наличие этой сборки само по себе не подтверждает публикацию.

Подготовлены три главы; все 1431 номера книги ещё не завершены. Полный реестр глав
сохраняется в `source-inventory.json` и `source-chapters.tsv`; страницы и части
всех дальнейших заданий ещё требуют поштучной сверки.

## Источники, проверки и сборка

- `preparation/chapter-01.json` — неизменяемая первоначальная подготовка 134
  частей; её проверка сохранена в `chapter-01-review.json`.
- `preparation/chapter-01-corrections.json` — независимо сверенные дополнения
  условий, вопросов и обозначений, включая ручной разбор вариантов № 9, 10, 44.
- `preparation/chapter-01-theory.json` — 13 пунктов и 26 вопросов с авторскими
  объяснениями и основаниями переходов.
- `preparation/chapter-02-a.json`, `chapter-02-b.json`, `chapter-02-c.json` —
  все132 части задач №92–190, независимо сверенные с точным изданием.
- `preparation/chapter-02-theory.json` — десять пунктов теории и21 вопрос;
  нумерация вопросов начинается заново, поэтому их ID включают главу.
- `preparation/chapter-03-a.json`, `chapter-03-b.json` — все 43 части задач
  №191–227, включая практические построения и разные положения фигур.
- `preparation/chapter-03-theory.json` — пункты №24–30 и 17 вопросов;
  признаки и свойства параллельности доказаны без круговых ссылок и без
  обращения к ещё не изученной сумме углов треугольника.
- `models/` — отдельные точные конфигурации, виды шагов, случаи и численно
  проверяемые геометрические утверждения.
- `data/course.json` — воспроизводимая сборка этих материалов.

Первоначальная проверка `chapter-01-review.json` относится к подготовке
134 частей без интерфейса, теории и исполняемых моделей. Её исторические
нулевые счётчики моделей не описывают текущую сборку. Последующие дополнения
и проверки зафиксированы отдельно в `docs/reviews/`.

Из корня репозитория:

```sh
python3 tools/geometry/check_textbook_preparation.py
python3 tools/geometry-textbook/build_course.py
python3 tools/geometry-textbook/review_scope_test.py
python3 tools/geometry-textbook/check_models.py
python3 tools/geometry-textbook/model_claims_test.py
node tools/geometry-textbook/check_course.cjs
node tools/geometry-textbook/runtime_check.cjs
node tools/geometry-textbook/reviewer_runtime_check.cjs
node tools/geometry-textbook/browser_check.js
```

Перед выпуском применяется также строгий режим
`node tools/geometry-textbook/check_course.cjs --require-reviewed`.

Для runtime-check нужен jsdom; для browser-check — Playwright и Chromium.
Облачный workflow `atanasyan-planimetry.yml` устанавливает зависимости
и сохраняет PNG начального и последнего состояния, а также отчёт всех видов.

## Публикация и работа ученика

Без успешного подтверждения своей главы, совпадающего с SHA256 её
материалов и реализации, карточки остаются `in-review` и не доступны в
публичном каталоге. Отсутствие подтверждения новой главы не отменяет проверку
неизменённой опубликованной главы. Изменение общего runtime требует повторной
проверки всех затронутых глав. Для выпуска `check_course.cjs --require-reviewed`
требует действующих подтверждений всех включённых глав.
Только инженерный тест явно включает просмотр кандидата
с соответствующей надписью; адрес страницы этот режим не включает.

Показ решения считается работой с помощью. Ответы и доказательства сохраняются
для обсуждения с учителем; произвольный текст не объявляется правильным.
Записи сохраняются в браузере под отдельными ключами издания. Серверная
синхронизация и новая самостоятельная вариативная практика пока не заявлены.
