# Первые векторы в пространстве, пункты 63–64 и №557–558

Глава VI начинается на печатной с. 142. Пункт 63 занимает с. 142–143, пункт 64 — с. 143, №557 и №558 — с. 144. PDF-страницы соответственно 144–146. Ответы обоих номеров находятся на печатной с. 268 (PDF 270) учебника Л. С. Атанасяна и соавторов «Геометрия. 10–11 классы», 12-е издание, 2024. | Карточка | Сверенный результат |

| П. 63 | Порядок точек задаёт направление. При обращении вектора длина сохраняется. Равное направление не означает равной длины. Совпадающие начало и конец задают нулевой вектор. |
| П. 64 | Перенос AB в заданное начало C определяет единственный конец D. В примере приращения (+3, +4, 0) сохраняются; противоположная стрелка той же длины не подходит. |
| 557а | Стрелки AB, BC, BD, NM, BN, NK по порядку имеют длины 3, 4, 5, 1,5, 2, 2,5 см. |
| 557б | Стрелки CB, BA, DB, NC, KN имеют длины 4, 3, 5, 2, 2,5 см. |
| 558а | CC₁, CB, CD имеют длины 12, 8, 9 см. |
| 558б | Диагональ боковой грани DC₁ равна 15 см; DB = √145 см; пространственная диагональ DB₁ равна 17 см. |
