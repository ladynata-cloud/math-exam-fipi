Ожидание и дисперсия суммы: что меняет зависимость?

После практикума «От исходов опыта к распределению». Здесь не нужно запоминать ещё одну формулу: сначала соберём распределение суммы из совместной таблицы и увидим, когда формулы работают.

1. Две величины — один опыт

Есть восемь равновероятных карточек. На каждой записана пара (X, Y); оба числа равны 0 или 1. В каждом столбце величины порознь нули и единицы встречаются по четыре раза.

Меняй ползунок от 0 до 4. Суммы строк и столбцов остаются равными 4.

2. Разобранный пример: k = 3

В совместной таблице количества (0,0), (0,1), (1,0), (1,1) равны 3, 1, 1, 3. Делим каждое на 8. Для суммы 1 подходят две разные пары — (0,1) и (1,0).

От пар к сумме
S012
P(S)3/81/43/8

Проверим нормировку: 3/8 + 1/4 + 3/8 = 1.

E(S) = 0 · 3/8 + 1 · 1/4 + 2 · 3/8 = 1.

D(S) = (0−1)² · 3/8 + (1−1)² · 1/4 + (2−1)² · 3/8 = 3/4.

При этом E(X) = E(Y) = 1/2, D(X) = D(Y) = 1/4. Сумма ожиданий равна 1; сумма дисперсий равна 1/2, а не 3/4. Причина — зависимость: P(X=1,Y=1) = 3/8 ≠ 1/4 = P(X=1)P(Y=1).

Правило и его границы

E(X+Y)=E(X)+E(Y) для любых X, Y с конечными ожиданиями, в том числе зависимых. При независимости и конечных дисперсиях D(X+Y)=D(X)+D(Y). Если величины зависимы, нельзя автоматически складывать дисперсии.

Для конечных распределений можно проверить общий случай: Cov(X,Y) = E(XY) − E(X)E(Y); D(X+Y) = D(X)+D(Y)+2Cov(X,Y). Нулевая ковариация достаточна для сложения дисперсий, но в общем случае не доказывает независимость. Для D(aX+bY) коэффициенты входят как квадраты a², b² и произведение 2ab в слагаемом ковариации.

3. Самостоятельная практика

Все четыре числа в условии идут в порядке (0,0), (0,1), (1,0), (1,1); это количества равновероятных карточек. Вводи целые числа, точные дроби (например, 3/8) или точные конечные десятичные дроби. В контрольных задачах 5–6 подсказок нет. Зачёт первой попытки и результат с помощью различаются; результаты хранятся только в этой вкладке до перезагрузки.
