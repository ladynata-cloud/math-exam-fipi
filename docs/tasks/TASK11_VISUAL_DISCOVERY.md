# Task 11: visual first success and help inside help

## Scope and owner direction

The owner requested on 2026-10-21 (Asia/Novosibirsk) that public task11 and
task19 trainers introduce her method through a useful first success. Task11
must offer help beside the individual function when the learner chooses its
graph, a small interactive graph laboratory, and further help inside that
laboratory. The later clarification is decisive: no arithmetic is required.
Learners observe, move, compare and choose; coordinates are computed by the
model. Public standalone trainers remain useful without registration.

One task, one branch, one PR, starting from the verified published task19 main.
The exact base/head will be recorded in the PR. Review level: HIGH, because the
matching help lifecycle, introductory selection and retained drafts change.
This extends the existing task11 laboratory and question-first UI; it introduces
no platform protocol, backend or new storage of personal information.

Included: task11 HTML, focused mathematical/state/accessibility/browser tests,
its workflow and project status. Preserve the three graphs/three functions,
ordinary generators, legacy modules, exam, downloads and existing course
progress contracts. A simple first ordinary exercise may use three distinct
forms; repeat/exam routes must not be intercepted. The normal question bank
remains available without completing an onboarding funnel.

Excluded: closing the full course, advertising publication, collecting contacts,
registration, payments, API integration, cabinet access policy, new learner
records, or modifications to other trainers. The owner's idea of a closed
working course is a future separately scoped access-control task.

## Acceptance

- The first ordinary visit has a clear, unambiguous visual matching exercise.
- Every function row has an accessible help button. Its dialog investigates
  that function, without displaying or selecting the matching answer number.
- A deeper optional step gives one observation; the next step highlights where
  to look. Neither requires computing a value or entering arithmetic.
- Parameter changes redraw a real graph; changed-formula status and reset to
  the task formula are explicit. Controls remain valid for all five families.
- Closing, Escape and reopening retain the three choices and separate help
  state for A/B/C. Focus returns to the invoking button. A new task resets help.
- Opening, exploring and closing help never records a solved task or overwrites
  the current matching draft. Existing assessment and persistence rules remain.
- 320/360/1280px layouts, keyboard operation, denied storage and downloadable
  standalone HTML remain usable. No duplicate IDs or conflicting lab instances.
