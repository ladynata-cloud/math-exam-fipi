Это изолированное продолжение оценки PR #399. Оно использует неизменённый адаптер
`7f4c054b9b8fb5b519dcab60e6fa4e461ed7c21f` и обработчики математического контекста и проверку ответов из PR429
`48474ad9c7e996767c5994add0b3aeaeb06923d6`. Это проверяемая композиция
черновиков, а не опубликованный помощник.
Производственные файлы и кабинеты не меняются. Эталоны не отправляются модели.

16 диалогов (32 запроса), 8 дополнительных проверок охвата, 24 эталона.
В 8 диалогах кабинета второй ход содержит реальный первый ответ модели;
в остальных передаются исходная задача, последняя попытка и отдельное поле
`followUpQuestion`. Уточняющий вопрос больше не добавляется к числовому ответу. История standalone
не поддерживается исходным контрактом — это зафиксированное ограничение.

## Проверка в облаке без расходов

Workflow `MathExam OpenAI quality — synthetic preflight` запускается на PR.
Он получает две закреплённые версии исходников, проверяет SHA-256, точную
арифметику, ошибки формата, передачу контекста, лимиты и сохранение резерва.
Не получает секретов. Прогон `dry-run` использует заглушки и не оценивает GPT.
Результаты сохраняются в Actions artifact на 14 дней; постоянный набор находится
в этой ветке.

Локально/в облачном терминале Node 24 и Python 3, без установки пакетов:

```bash
python3 tools/openai-quality-20261103/oracles.py
node --test tools/openai-quality-20261103/evaluation.test.mjs
node tools/openai-quality-20261103/evaluate.mjs audit
node tools/openai-quality-20261103/evaluate.mjs dry-run
```

Для запуска из checkout получить две закреплённые версии репозитория и указать абсолютные пути в переменных
`MATHEXAM_EVAL_CURRENT_ROOT` и `MATHEXAM_EVAL_ADAPTER_ROOT`; структура — как
в workflow. По умолчанию используются каталоги `sources/current` и `sources/pr399`.

## Реальная кампания

Сейчас НЕ выполнена. Условное разрешение владельца уже есть; остаются проверяемые
факты о доступе, остатке гранта, проекте и технической готовности запускателя.
Нельзя проставлять `true` в записи допуска без подтверждения. Письмо о гранте
не заменяет остаток Billing и не отменяет ограничения по странам.

Предел: $0.50, 32 последовательных обращения, 500 токенов выхода, 15 секунд на
запрос, 10 минут на кампанию, без повторов. Абсолютный резерв при максимальном
входе — $0.456. План с короткими заглушками истории — $0.219881; фактическая
история изменит эту оценку. Цены: $0.75/$4.50 за миллион токенов, проверены
2–3 ноября, допуск до 9 ноября 00:00 UTC. Сумма по токенам — оценка, не счёт.

`results/preflight.pending.json` содержит точный digest программы и набора.
После подтверждения фактов копируется в `preflight.local.json`. Эта запись,
ключ, идентификаторы проекта и журнал никогда не коммитятся. Нужен отдельный
проект организации mathexam, активный подходящий грант минимум $0.50,
отключённое автопополнение, подтверждение допустимого доступа и проверка кода.
Ключ передаётся через защищённый механизм среды в `MATHEXAM_OPENAI_TRIAL_KEY`,
не через переписку, argv, notebook или GitHub. Дополнительный переключатель:
`MATHEXAM_OPENAI_TRIAL_ALLOW=1`.

`MATHEXAM_EVAL_STATE_DIR` должен указывать на постоянный приватный каталог
ОДНОЙ кампании, общий для её запусков. Не удалять и не заменять SQLite для
повторного расходования. Без постоянного диска облачный live запуск не готов.
В GitHub Actions и обычном CI live запрещён, потому что новый runner потерял бы
счётчик предыдущего запуска. Облачная подготовка не является обходом географии.

```bash
node tools/openai-quality-20261103/evaluate.mjs live
```

Журнал резервирует стоимость до запроса, сохраняет принятый ответ и usage.
При первой ошибке кампания останавливается; резерв не возвращается. Не повторять
live после ошибки. Сохранить `campaign.sqlite` и `live.json` для разбора. При обрыве
до обновления JSON полная запись принятых ответов остаётся в SQLite; автоматическое
восстановление представления пока не реализовано. Не считать такой прогон полным.

## Предметная оценка

Каждый ответ сверяется со всеми переходами в эталоне, а не поиском числа.
В `review-template.json`: `math`, `clarity`, `feedback`, `hint`, `context`,
`honesty` оцениваются 0–2; неприменимые — `NA`. Для первого хода проверять
отсутствие решения во ВСЕХ четырёх полях. Второй ход кабинета оценивается с
первым ответом рядом. Отдельно отмечаются обязательные пункты и критические ошибки.
Критическая ошибка или утечка ответа не компенсируется средним баллом.

После заполнения `scores.json` рядом с `live.json`:

```bash
node tools/openai-quality-20261103/evaluate.mjs score
```

Порог: 32 проверенных ответа, минимум 29 зачтённых, 0 критических ошибок.
Этот небольшой набор не доказывает полноту курса, эффективность у реальных
учеников или готовность к включению кабинетов. Он не проверяет чертежи/изображения,
интерфейс, подсказку автоматически после двух ошибок, длинные диалоги или повторные
измерения стабильности. Ответы API не используются для обучения другой модели.

## Продолжение 6 ноября 2026

По запросу владельца «использовать бонусные API для обучения помощника» подготовлен
первый измеримый этап: испытание объяснений на прежних 16 синтетических диалогах.
Это оценка и последующая настройка инструкций; веса модели не обучаются.
Контрольный набор не превращается в обучающий материал. Прямой fine-tuning,
обучение Qwen, аренда GPU и включение ученических запросов не запускаются.

В каждом результате теперь есть бесплатный ответ для той же исходной задачи
и отдельной попытки. Для кабинета вызывается штатный `answerCabinetOffline`,
для standalone — `answerOffline`. Понимание бесплатным вариантом свободного
уточняющего вопроса не тестируется и явно помечено `NOT_TESTED`.

Ответ API проходит актуальную проверку размера UTF-8 до сохранения как принятого.
В отчёте математическая проверка остаётся отдельной от содержательной оценки.
`score` пересчитывает её по реальному тексту и доверенной задаче из контрольного
набора: обнаруженная ошибка, неверный формат или распознанный итог в первой
подсказке блокируют положительный результат. Нераспознанное объяснение требует
содержательной оценки, даже если итоговое число совпало. Сохранённому полю оценки
модели доверять нельзя. Синтетические заглушки по-прежнему нельзя оценить как GPT.

Зафиксированы SHA-256 всех 53 используемых и сопутствующих файлов двух исходных
версий, включая математический проверяющий код и его эталоны. План и запись
допуска изменились: старый preflight не разрешает этот запуск.

После продолжения настройки 6 ноября владелец сохранил защищённый секрет
Codespaces; подтверждены его подключение без вывода значения, постоянный приватный
каталог, сохранность после перезапуска, проект/модель и остаток гранта.
Независимый агент без доступа к ключу одобрил техническую часть ограниченного
испытания. Затем исправлено найденное ограничение: до принятия ответа кабинета
проверяется, поместится ли он в историю с учётом нормализации Unicode и места
для следующего вопроса. Текст решения не обрезается; неподходящий ответ приводит
к остановке с сохранением резерва, без повторов. Обе границы проверяются тестами.
Код и digest изменились; старый preflight недействителен. Подробности — в отчёте.
Условия допустимого доступа сейчас не выполнены; зарубежный регион среды сам
по себе их не устанавливает. Live выключен, ready-preflight не создан.
Подготовка сохранена в PR420; расходы и запросы API — ноль.
