# Макарычев, 8 класс. Нули функций по формулам

Базовый учебник, 2024, ISBN 978-5-09-116445-9, §13, п. 43, с. 248. Сверены четыре подпункта №1106, три подпункта №1107 и оба выражения №1108. Исходные адреса и записи ученика в двух ранее существовавших карточках №1106а, в сохранены.

| Номер | Содержание |
| --- | --- |
| 1106а–г | Ученик находит нули линейной функции, произведения и дроби с положительным знаменателем. Отдельно объясняет, почему дробь с постоянным числителем 6 не может иметь нулей. |
| 1107а–в | Проверяет существование нулей по формуле и записывает их точные значения. Для дроби отличает нуль числителя от запрета в знаменателе. |
| 1108а | Строит область допустимых аргументов корня и дроби, затем проверяет оба кандидата после возведения в квадрат. |
| 1108б | Из допустимого луча исключает только 1. Проверяет исходный знаменатель при −5/2, после чего находит оба нуля числителя. |

Новые девять карточек содержат 27 пошаговых заданий. К двум существующим карточкам добавлена подстановка собственного аргумента. Ученик видит, существует ли значение, и где находится проверенная точка относительно оси. Тренировка генерирует отдельные нуль и запрещённую точку у новой дроби. Прямой ряд — №1–1075 и №1077–1108.

Проверки математики находятся в test-formula-zeros.cjs. Обычный вход, восстановление шага и обратная связь проверяются в test-browser-formula-zeros.cjs.
