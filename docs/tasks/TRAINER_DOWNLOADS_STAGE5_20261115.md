## Approved scope

### In scope

- Шесть комплектов: START с основами векторов; векторы по существующему банку Ященко; производная по графику; прикладные и текстовые задачи; вероятность; функции и экстремумы.
- В каждом ZIP: автономный HTML, тематический промпт DeepSeek, README, GIF и PNG с кадрами. Инструкция сохранения копии в Windows с прежним началом имени и окончанием `-my.html`.
- Закрытая панель «Скачать и изменить» на шести исходных страницах; тематические проверяемые примеры изменения.
- Новый управляемый GIF производной: наклон касательной по двум точкам, согласование рисунка и ответа, сохранение изменённой копии и проверка прежнего/нового ответа.
- Точное встраивание зависимостей START в исходном порядке. В пяти отдельных тренажёрах сохранить собственную помощь, встроить карту навыков и исключить только заранее перечисленные сетевые дополнения, как в существующем комплекте векторов.
- Сохранить строгий контракт START для доски: после проверки полного источника навигатора удалять только точную проверенную панель скачивания существующим адаптером. Отрицательные проверки обязаны отвергать изменённую/дублированную панель и посторонние изменения исходника.
- Обновить необходимые привязки изменённых публичных страниц и проверки экспорта. Подготовить общий ZIP со стартовой страницей.

### Out of scope

- Новая учебная программа, изменение исходных генераторов и проверок ответа, переработка экзаменационной карты, сервер, кабинеты, синхронная доска и миграция результатов.
- Дополнительный дублирующий ZIP основ векторов, уже входящих в START; 3D-сечения и атлас параметров требуют отдельной проверки.
- Merge, auto-merge и deployment: правила владельца в текущем разговоре требуют отдельного явного разрешения и имеют приоритет над общей политикой репозитория.

- Учебный код шести источников после точного удаления панели; все исходные JS/CSS, математические значения и форматы результатов.
- Исторические контрольные значения, фиксированные книжные редакции и правила проверки доски.
