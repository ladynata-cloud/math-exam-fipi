# Треугольник: учитель видит «решено после подсказки» в кабинете

## Идентификация

- Задача: после #135 (`docs/tasks/RIGHTTRI_HINT_KEEPS_CREDIT.md`) тренажёр
  «Прямоугольный треугольник» пишет в запись темы `righttri-t1` поле
  `hinted` — сколько задач «Сам» решено после кнопки «С чего начать?».
  Решение 3 того документа: «ученику — фраза, учителю — число». Число

  `correct` и `solved`. Учитель, работающий по коду, числа не видел вовсе;
  `SITE-CHANGES.md:57` говорила «учитель видит его в сводке «Сдать учителю»».

## Цель

Учитель в кабинете `teacher.html` — и по своему браузеру, и по вставленному
коду ученика, и после «Загрузить в этот браузер» — видит в строке тренажёра
«Прямоугольный треугольник», сколько из решённых «Сам» задач решено после
«С чего начать?» — суммой по темам 1–5, теми же словами, что в сводке
«Сдать учителю» тренажёра (она печатает число по каждой теме отдельно,
включая разминку). Ученик на карте курса `index.html` этого счётчика не
видит: подпись «чистые серии: X из 15 · решено: Y» не меняется.

## Контекст и факты

Проверено по коду и запуском на базе `4c7d4fa`.

1. Тренажёр (`ege-profil/trainers/pryamougolny-treugolnik-trenazher.html`):
   `creditSolo` (2727–2731) увеличивает `hinted` только вместе с `solved` и
   только если подсказка была явно нажата, поэтому от самого тренажёра
   `hinted ≤ solved`. `loadStats` (2238) читает поле как
   `+v.hinted || 0`. Сводка `renderTeacherSummary` (3292): «решено
   самостоятельно: N (из них после «С чего начать?»: M)».
2. Адаптер `righttri` (`progress-adapters.js:184–196` на базе) обходит темы
   1–5 записи, считает `sum += min(3, correct)` и `solved += cnt(solved)`;
   разминка (тема 0) не в счёт. Подпись идёт через `bar()` →
   `textContent` (92–95): экранирование не требуется.
3. Адаптеры общие для `index.html` (карта курса, страница ученика:
   `PROGRESS.mount(document, liveStore())`, строка 562) и `teacher.html`
   (кабинет: `renderCards` → `PROGRESS.apply(host, view ?
   snapshotStore(view) : liveStore())`, строка 189 — единый путь для
   своего браузера, просмотра кода и вида после загрузки).
4. Кабинет без сервера работает от кода ученика (lede страницы);
   `progress-code.js` переносит объект как есть — `hinted` уже едет в коде
   MEP1, менять там нечего.
5. Правило мусора в шапке `progress-adapters.js`: мусор — «нет данных»,
   адаптер не падает и не выводит `NaN`/`undefined`/чужую строку; `cnt()`
   (43) даёт 0 для не-числа, отрицательного, `NaN`, `Infinity`, дробь —
   вниз. Прецедент отбрасывания несогласованного поля в том же файле:
   `planimetry` не верит `passed:true` при `best < 8` (137–150).
6. Правило кабинета «неполученный факт не пишется нулём»: `plan1y` и
   `vec2y` опускают «зачёт» при `best = 0`, `p18` — «дриллы», `stp` —
   «тест». Записи до #135 (в `main` с 28.09.2026) поля `hinted` не имеют:
   «0» утверждал бы то, чего мы не знаем.
7. Тесты на базе: `teacher-test.js` — 96 проверок, 0 отказов; полный
   `npm test` курса зелёный.

## Педагогические и технические решения (делегат владельца, модель Fable)

1. **Где показывать: только в кабинете.** Число печатается только в
   `teacher.html`, одинаково для своего браузера и для вставленного кода.
   На карте курса подпись прежняя. Выбирает не адаптер, а страница:
   адаптер `righttri` остаётся общим и дописывает фрагмент лишь тогда,
   когда узел `[data-progress]` помечен атрибутом `data-cabinet` — его
   ставит `teacher.html` в `renderCards` (для всех строк; остальные
   адаптеры его игнорируют), `index.html` не ставит. Обоснование: решение
   3 из #135 выведено из канона «Подсказки ничего не отнимают… это прямо
   сказано ученику в интерфейсе»; рядом со словом «чистые серии» третий
   счётчик «с подсказкой» на странице ученика читался бы как штрафная
   отметка. Канон «Помощь помечается только при явном обращении к ней»
   соблюдён: `hinted` растёт только по нажатию кнопки и только в момент
   зачёта, поэтому показывать его учителю допустимо. Отклонено: флаг
   «учитель» внутри store (источник данных — не «кто смотрит»); разбор
   записи в `teacher.html` (дрейф с адаптером); отдельное имя адаптера в
   `RV.CABINET` (лишняя правка реестра).
2. **Формулировка и формат.** К подписи после «решено: Y» дописывается
   « · из них после «С чего начать?»: N»: «чистые серии: 4 из 15 · решено:
   9 · из них после «С чего начать?»: 2». Слово в слово как в сводке
   «Сдать учителю» — учитель узнаёт ту же величину в обоих местах
   (тренажёр печатает её по темам, кабинет — суммой по темам 1–5);
   «после подсказки» без имени кнопки было бы неточно (в «Пошагово» свои
   «Подсказка»/«Показать ответ», в `hinted` они не считаются). «Из них»
   делает подмножество явным. N считается только по темам 1–5, как и
   «решено». При N = 0, без поля и в состояниях «не начат»/«в работе»
   фрагмента нет вовсе — ни «: 0», ни прочерка (факт 6). Отдельной
   строки, легенды и `title` нет: у других строк легенды нет, а учитель,
   открывавший тренажёр, кнопку знает.
3. **Мусор в `hinted`: отбрасывать по теме, скрывать при нуле.** Для темы
   k ∈ 1..5 (только объект): `h = cnt(tp[k].hinted)` — отсутствие, `null`,
   строка (в том числе «3»), отрицательное, `NaN`, `Infinity` дают 0,
   дробь — вниз; затем если `h > cnt(tp[k].solved)`, тема даёт 0 (её
   `hinted` — мусор). Сумма по темам; при 0 фрагмента нет. Клампить к
   `solved` нельзя: `hinted > solved` невозможен от самого тренажёра
   (факт 1), значит это порча; кламп изобрёл бы факт «все задачи решены
   после подсказки» — ошибка против ученика, чего канон не допускает;
   отбрасывание ошибается в безопасную сторону. По теме, а не по записи —
   как обход `if (!isObj(tp[k])) continue`: мусор в одной теме не гасит
   остальные.
4. **Карта курса и `SITE-CHANGES.md`.** `index.html` — без изменений ни в
   разметке, ни в подписи; это закреплено тестом в `site-test.js` (сид с
   `hinted` → на карте нет «С чего начать?»; узлов `data-cabinet` нет;
   тот же адаптер в узле с `data-cabinet` фрагмент дописывает).
   `SITE-CHANGES.md:57` уточнена минимально, без переписывания истории:
   «…его печатает сводка «Сдать учителю» в самом тренажёре (она строится
   на устройстве ученика); в кабинете учителя число появилось 28.09.2026 —
   см. раздел teacher.html»; новая запись в разделе `## teacher.html`;
   строка про `data-cabinet` в пункте 6 раздела `## index.html`.
