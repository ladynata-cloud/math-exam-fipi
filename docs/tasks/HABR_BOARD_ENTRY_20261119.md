# Первый опыт читателя статьи о зеркальной доске

Наталья попросила улучшить входы из опубликованной статьи на Хабре, выбрать выразительный подключённый тренажёр и проверить доску. База — `main` на `f4bf1a7048e0512c9b62dd996e50615248b5b17d`, ветка — `fix/habr-math-demo-entry`. Уровень проверки MEDIUM. Для выпуска этого PR по уточнённому поручению владельца от 19 ноября требуется подтвердить первичное разрешение и непосредственно перед слиянием сверить его базу с удалённой main. При дрейфе базы выполняется проверка виртуального объединения и запрашивается новое решение. [Постоянные правила проекта](../OWNER_RELEASE_AUTHORIZATION.md) дают контекст для этой проверки.

Ссылка ведёт в задачу о наклонном сечении куба. Учитель и ученик должны видеть одинаковое построение. В демонстрации листы сохраняются только в этой вкладке. У обычной доски сохраняется прежнее место для записей. До создания комнаты показывается действие для приглашения ученика. Реальные ошибки подключения и неподдерживаемые тренажёры сохраняют свой статус.

Внутри доски задание и модель предшествуют каталогу курса. Ссылка на синусоиду открывает вкладку и сам график. В объяснении синуса острого угла уточняется связь между углом и отношением длин сторон.

Для процентной сетки ссылка может выбирать первое задание из существующей таблицы процентов. Следующие примеры генерируются как обычно.

Проверка ученического окна выявила сбой при загрузке клиента связи с отдельного домена. Для сервера MathExam доска получает Socket.IO 4.8.4 с собственного сайта. Начальное соединение использует HTTP, затем может перейти на WebSocket. Пока комната не передала задание, ученик видит сообщение о подключении. После ошибки он может снова войти по той же ссылке.

Проверки включают сохранность обычного листа, создание комнаты после самостоятельной работы, связь модели с карточкой, построение и передачу хода. Публикация статьи и проверка действующих ссылок выполняются отдельно в интерфейсе Хабра. Для отката достаточно обычного отменяющего коммита. Серверный протокол и данные учеников не меняются.
