# Проверка первого модуля алгебры

Дата: 2026-10-02. База: `1b110e09b22562b163821e4024e9c4c3c463e530`.

## Реализовано

- Шесть уроков в существующей мастерской: рациональные числа, порядок действий, переменная, сравнение выражений, распределительное свойство, тождества и подобные слагаемые.
- В каждом — три смысловых объяснения, вопросы для устного ответа, исследовательская модель, пошаговая практика и существующая самостоятельная проверка.
- Соответствие пунктам 1–6 Макарычева, 7 класс, базовый уровень, 2024. Покрытие отмечено как частичное.
- Общая концепция дальнейших курсов в `docs/TEXTBOOK_COURSES.md`.

## Пройдено

- `node tools/textbook-algebra.test.cjs`: 1440 сгенерированных условий. Ключи сверяются с отдельным вычислением выражения из текста условия; преобразования проверяются подстановками, ошибочные тождества — контрпримером.
- `node tools/workshop-state.test.cjs`: прежняя проверка 7400 условий/шагов, зависимостей, оценивания, повторения, импорта и повреждённых данных.
- `node tools/textbook-algebra.dom.cjs` (нужен jsdom): шесть полных учебных сценариев, вопросы на понимание, кнопки модели, переход к предпосылке и возврат чернового ответа, различение самостоятельного успеха и помощи, прежняя модель дробей, сохранность постороннего ключа.
- Синтаксис JavaScript и `git diff --check`.

## Не пройдено / не выполнено

Реальный облачный браузер не открыл локальный HTTP-адрес: `net::ERR_BLOCKED_BY_CLIENT`. Поэтому визуальная проверка 360 px / планшет / компьютер, масштабирование, реальная клавиатурная навигация, экспорт скачиваемого файла в браузере и отсутствие визуальных наложений не подтверждены. Проверка jsdom не считается браузерной.

Внешнего и независимого ревью нет; опыт реальных учеников не проводился. Свободные устные ответы оценивает преподаватель, автоматической оценки объяснений нет. Привязка остальных глав и остальных учебников ещё не сделана. Дополнительные иллюстрации дробей с изменяемым знаменателем, модули неравенств и статистики — последующие этапы, не скрыто готовые разделы.
