# Планиметрия · задание 1 — тренажёр по Ященко-2026

Интерфейс поверх банка `bank-t1-planimetry.js` (19 генераторов YB1;
независимая верификация: 11 400 задач, расхождений 0 — фигуры
пересобираются численно от текста условия).

## Что внутри

**Темы → типы.** Девятнадцать типов разложены на четыре темы:
Треугольники (t1, t4, t6, t8, t10, t12), Параллелограмм и ромб (t2, t3,
t18), Трапеции (t7, t15, t16, t17), Окружность (t5, t9, t11, t13, t14,
t19). Чип темы показывает счётчик закрытых типов («2/6»), чип типа —
точки серии: три верных с первой попытки подряд закрывают тип. «Вся
тема» — микс внутри выбранной темы.

**Три режима.** «Разбор» — задача сразу с решением, для доски.
«Тренировка» — ответ числом, адресная диагностика из `traps` банка,
близкий ответ ловится как округление, разбор по кнопке. «Зачёт» —
10 задач разных типов из всех тем, одна попытка; разбор промахов после
финиша; сдан при 10 из 10, лучший результат сохраняется.

**Экосистема.** TID `ege-t1-yashchenko` в `mathExamCourseProgress.v1`;
журнал `all.mistakes["ege-t1-yashchenko|tN"]` (тренировка и зачёт);
`?mode=review` с баннером; «← Курс»; режим доски.

`index.html`: карточка «Планиметрия по Ященко-2026» (задание 1), третья
pill «Задание 1 по Ященко» в маршруте линии 1, адаптер `plan1y`
(«типов закрыто X из 19 · зачёт …», done при сданном зачёте и всех
закрытых типах). `review.html`: TRAINERS `ege-t1-yashchenko`
(review:true) + 19 имён типов с line:1.
