## Задача и границы

Шестиклассник может найти тему Виленкина по оглавлению. Из раздела тем можно попасть на смешанную тренировку десятичных дробей и при затруднении открыть сложение по разрядам. На странице линейных уравнений ученик может начать с весов, перейти к экзаменационному заданию №9 или прочитать разобранный пример.

Меняются четыре существующих документа и их браузерная проверка:

- `courses/vilenkin-6-part-1/textbook.html`
- `topics/index.html`
- `trainers/desyatichnye-drobi-level-1.html`
- `topics/lineynye-uravneniya/index.html`
- `tools/seo-entrypoints.browser.cjs`

Сохранить действующие URL, канонические адреса, фрагменты, карты, интерактивные упражнения, содержимое автономных сборок и результаты. Общий реестр навигатора находится в ведении координатора. Любая привязка обновляется отдельно по проверенному коммиту исходников. Публикация требует повторной проверки на итоговом кандидате. Внешняя модель и данные учеников для этих испытаний не нужны.

## Приёмка

1. В оглавлении присутствуют повторение, все 23 темы и авторское дополнение про НОК. Без JavaScript переход по пункту открывает правило. С JavaScript тот же фрагмент открывает соответствующий урок и сохраняется после обновления. В управляемом задании сохраняется предусмотренный режим навигации.
2. Из каталога обычной ссылкой открываются четыре действия с десятичными дробями. При отключённом JavaScript можно решить пример и раскрыть проверку. При включённом доступны все 12 исходных задач, новый набор, подсказки и ответы с точкой или запятой. Из тренажёра доступно сложение и вычитание по разрядам.
3. Обе кнопки на учебной странице уравнений различают практику на весах и ОГЭ №9. Сохраняются переход к примеру и проверка решения в исходном равенстве. На узком экране ссылки остаются доступными.
