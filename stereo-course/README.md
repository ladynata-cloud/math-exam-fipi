# Пространственная мастерская: Атанасян 10–11

Откройте `index.html` в браузере. Это автономный файл: соединение с интернетом и установка библиотек не требуются. Исходные модули и данные сохранены отдельно для доработки; после правок запускайте `python tools/stereo/build_site.py` из корня репозитория.

## Что входит

- Карта всех 99 нумерованных пунктов предоставленного учебника Атанасяна и др., «Геометрия. 10–11 классы. Базовый и углублённый уровни», 12-е стереотипное издание, 2024. Она объединена в 39 учебных узлов, включая дополнительные главы планиметрии.
- В каждом узле: авторское объяснение, исследование, задача с вычислительными шагами, самостоятельная попытка и письменное обоснование. Включены 19 цепочек аргументов; для остальных тем интерфейс прямо сообщает об отсутствии готовой цепочки.
- Координатные модели многогранников, цилиндра, конуса и сферы. Вращение, масштаб, изменение размеров, зависимые точки на рёбрах, плоскость через три точки, построение отрезков и перпендикуляра, измерение пространственных углов и расстояний.
- Сечения многогранников вычисляются по пересечениям с рёбрами; ученик сам соединяет вершины сечения, проверка учитывает смежность. Совпадающие точки имеют общую подпись. Полноэкранный режим помогает работать с моделью на небольшом экране.
- Локальное сохранение, экспорт и импорт прогресса; просмотр письменных работ учителем. При отказе записи в браузер актуальная работа остаётся в памяти вкладки и доступна для скачивания. Не меняются ключи прогресса других курсов.
- Одинаковое условие с тем же ответом не получает повторный самостоятельный зачёт, даже если открыто с новым номером варианта. Учитываются также условия, открытые в разборе с опорой. Незавершённая текущая попытка продолжается после перезагрузки. Прежние счётчики сохраняются; история открытых условий накапливается с этой версии.

## Границы готовности

Это работающая учебная версия с полной картой тем, а не разбор всех упражнений учебника. Разнообразие заданий неравномерно: расширены серии о многогранных углах, конических сечениях, теоремах Чевы и Менелая; многие остальные узлы пока тренируют одно основное семейство задач. Для полного курса требуется дальнейшее расширение заданий и математическая редактура всех объяснений. Исходный учебник в сборку не включён, авторские задачи не обозначаются его номерами. Страницы в карте — печатные страницы начала пунктов, сверенные с оглавлением издания 2024 года.

Динамическая модель не является доказательством. Результаты измерений округляются, а параллельная проекция искажает видимые углы и длины. Контуры сечений цилиндра и конуса приближены сеткой и обозначены знаком ≈; круг сечения сферы рассчитывается аналитически. Модель не заменяет все функции GeoGebra. В дополнительных темах планиметрии используется общий исследовательский инструмент; специализированные построения для каждой из них ещё не реализованы.

Письменное доказательство проверяет учитель. Автоматический прогон не заменяет работу с реальными учениками. Пока нет серверных групп, синхронизации зеркальной доски и защищённого журнала оценок. Файл прогресса нужен для переноса между браузерами. Ссылка на курс 7–9 работает, когда обе папки размещены рядом.

## Проверка

`node tools/stereo/check.js` — свойства 3D-вычислений и генерируемых задач.

`node tools/stereo/regression-check.js` — сохранение при переполнении хранилища, формула расстояния до плоскости, страницы источника и независимые проверки расширенных семейств задач.

`STEREO_CHROMIUM=/path/to/chromium node tools/stereo/browser-check.js` — прохождение всех 39 узлов, построение сечения, сохранение, мобильная вёрстка, обновление измерений при изменении геометрии и защита от повторного зачёта. Путь к Chromium задаётся для конкретной машины; при установленном Playwright можно не задавать переменную.
