# Макарычев, 8 класс. Свойства линейной функции

Базовый учебник, 2024, ISBN 978-5-09-116445-9, §14, п. 44. Сверены №1114–1117 на с. 250 и №1118 на с. 251. Существующие адреса №1118а, б сохранены. Их предметная модель подключается при открытии задания и сохраняет исходную запись в банке.

| Номера | Содержание |
| --- | --- |
| 1114а, б | Для двух прямых ученик сам выбирает точки построения и определяет области, нуль, знаки и монотонность. |
| 1115а, б | Строит два исходных графика. При исследовании общих свойств меняет коэффициент прямой пропорциональности с сохранением его знака. |
| 1116а, б | Схематически строит прямые по собственным точкам и находит точные границы положительных и отрицательных значений, включая 500 и −1/3. |
| 1117а, б | Сравнивает коэффициенты пяти функций и проверяет на выбранной прямой изменение ординаты при шаге на единицу. |
| 1118 | Находит нуль, оба промежутка строгого знака и направление изменения прямой. |

40 новых карточек, 80 шагов, всего для этих пяти номеров доступны 42 карточки. График отвечает на изменение двух введённых точек. Тренажёр различает повтор одной абсциссы и ошибочную ординату. В повторе меняются коэффициенты, точки построения выбирает ученик. Математические и браузерные проверки находятся в test-affine-study.cjs и test-browser-affine-study.cjs.
