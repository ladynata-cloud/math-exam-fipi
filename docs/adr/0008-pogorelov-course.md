# Погорелов: автономный курс

Status: Proposed

Дата: 2026-10-02.

Каталог и отдельные страницы уроков используют общие локальные JS/CSS. Для автономного запуска сохраняется вся папка курса. Локальный прогресс имеет отдельный ключ; исходные модули и JSON включены для редактирования и повторной сборки. Общие механики взяты из локально проверенной сборки Атанасяна, дерево 7f57f200ad157c0dd13400a0257407c4ba78615d; пространственный движок — дерево 5818809ef408331f76f6e95565a8cb4db14167c4. Обе зависимости скопированы в задачу и не требуют слияния других PR.

Новый способ упаковки и тематические модели требуют проверки перед выпуском. Пользовательские доказательства не получают автоматическую оценку.
