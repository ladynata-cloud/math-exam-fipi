# Преобразования рациональных выражений, №150–180

Издание Макарычева 2024 года, ISBN 978-5-09-116445-9, печатные страницы 41–45. Этот выпуск по разрешению автора сайта добавляет все номера пункта 7. Два прежних адреса №150г и 155г сохранены вместе с историей решений. Разборы охватывают равносильные преобразования, доказательства, область определения вложенной дроби, экстремумы, гармоническое среднее, совместную работу и составление уравнений по условию.

В №176 ученик строит прямую по точкам. В №177 и 178 прямая меняется при вводе коэффициентов. Задание на расположение прямой принимает разные правильные примеры. Личная и общая страницы загружают один банк заданий, скачиваемые варианты содержат те же материалы.

Проверка HIGH. Полный независимый перечень конечных ответов, проверки доказательств и моделей, проверка исходных номеров и страниц. Сверено 73 исходных случая с учётом четырёх вариантов свободных прямых, по каждому есть не менее двух шагов. Код опирается на существующие средства построения, проверки и сохранения. Указанный полный диапазон после выпуска — №1–180 и №268–509.
