Владелец поручил проверить ещё не просмотренные курсы по ссылкам из трёх экзаменационных направлений и внести учебные исправления. Для выпуска применяется [разрешение владельца](../OWNER_RELEASE_AUTHORIZATION.md).

## Как отбирались материалы

Исходные страницы — [ОГЭ](https://mathexam.space/oge/), [базовый ЕГЭ](https://mathexam.space/ege-baza/) и [профильный ЕГЭ](https://mathexam.space/ege-profil/). В область проверки входят отдельные учебные маршруты, явно названные на этих страницах, в том числе вход в учебники из меню базы и в практикумы через оглавление профиля. Охват прежних проверок сверялся по файлам и тематическим PR. Ссылка на пособие в каталоге сама по себе не означает, что по нему существует отдельный курс.

| Вход | Что проверяется в этой работе |
|---|---|

| ОГЭ → информатика №1–10 | Решение, повтор после ошибки, мини-вариант, переход между режимами, подсчёт запусков алгоритма. |

## Критерии учебной приёмки

- Из разбора Brilliant Local Extrema перенесён конкретный проверяемый вопрос. По одним нулям производной нельзя сосчитать экстремумы, если часть графиков касается оси. Число и объяснение независимо сверяются по значениям слева и справа.
- Из аудита моделей GeoGebra взята проверка особых значений одного параметра. Равенство на окружности, касание, нулевой и отрицательный пороги должны менять математический объект и ответ согласованно.
- По результатам проверки задач Образавра равносильные допустимые ответы должны давать один результат. Если задание проверяет именно форму записи, ученик должен понимать, что уже вычислил верно и какой шаг остался.
- Из изученных сценариев геймификации и практики мини-групп взята последовательность «попытка, помощь по запросу, исправление, новая задача». Просмотр решения и самостоятельная работа различаются в тех режимах, где ученик получает зачёт.

Содержательные изменения проверяются на обычном маршруте ученика и отдельными математическими примерами. Для изменённых скачиваемых тренажёров используется штатная сборка и проверка содержимого ZIP. Проверяются сохранённая работа, поведение повторного нажатия и узкий экран там, где менялся соответствующий интерфейс. Откат выполняется обычным revert коммита выпуска. Внешняя рецензия нового кода не заказывалась.
