Как скачать и адаптировать интерактивный тренажёр

Скачайте свою копию тренажёра, чтобы потренироваться без интернета или подготовить задания под свой класс. В новой серии промпт для DeepSeek помогает изменить одну задачу, подсказку или оформление.

1. Что можно скачать

Откройте «Скачать и изменить» внизу тренажёра. Возьмите HTML для запуска или ZIP, если нужны промпт, инструкция и GIF. В более ранних комплектах блок называется «Скачать и адаптировать». Для многостраничных комплектов берите ZIP.

Бесплатные тренажёры по математике без интернета

Выберите готовый комплект. Распакуйте ZIP и откройте HTML по инструкции. Для работы без сети используйте локальную копию; кабинет и общая доска остаются онлайн.

  • Деление столбиком (уголком) — скачать ZIP.
  • Округление чисел — скачать ZIP.
  • Простые уравнения — скачать ZIP.

2. Как открыть HTML-тренажёр

Распакуйте ZIP в папку. Откройте указанный в инструкции файл .html двойным щелчком. Если скачали автономный HTML отдельно, распаковка не нужна. Кабинет, общая доска и дополнительные материалы по ссылкам доступны на сайте.

3. Как дать тренажёр ученикам

Самый простой способ — отправить ссылку на страницу тренажёра на mathexam.space. Если нужно использовать свою изменённую версию, можно отправить ученикам HTML-файл или разместить его на своей странице, в электронном журнале, облаке или школьном ресурсе.

4. Как изменить скачанный тренажёр

Например, можно написать «Сделай текст задачи крупнее» или «Добавь две задачи на проценты». При изменении чисел проверьте, что подсказки, ответ и рисунок согласованы с новым условием.

Как изменить тренажёр за пять шагов

GIF можно посмотреть целиком или по кадрам.

  1. Открой «Скачать и изменить» и скачай HTML или комплект ZIP.
  2. Напиши одно изменение. Скопируй готовый промпт для DeepSeek.
  3. Вставь промпт в DeepSeek и приложи скачанный HTML.
  4. Сохрани полученный HTML под новым именем и открой в браузере.
  5. Проверь пустой, неверный и верный ответы на новом файле.
Как изменить числа и чертёж · пример с ромбом

GIF можно посмотреть целиком или по кадрам.

  1. Скачай HTML тренажёра №17. Выбери задачу на площадь ромба.
  2. Попроси добавить пример с диагоналями 12 и 8. Приложи HTML к запросу.
  3. Сохрани новую копию и сверь длины диагоналей в условии и на рисунке.
  4. Пересчитай ответ: половина произведения диагоналей равна 48.
  5. Открой копию без сети. Проверь, что 42 отклоняется, а 48 принимается.
Как изменить график и сохранить ограничения · ОГЭ №22

Учебная схема: GIF можно посмотреть целиком или по кадрам.

  1. Скачай HTML №22. Пример для сравнения: C = 3 и p = −1.
  2. Попроси добавить пример с C = 3 и p = −2, сохранив прежний банк.
  3. Сохрани копию с окончанием -my.html. После сокращения x ≠ 0 и x ≠ 2.
  4. Точка (2; 2,5) выколота. Прямые y = 3 и y = 2,5 не пересекают график.
  5. Открой без сети: пусто и «2 и 3» не подходят; «2,5 и 3» верно.

В примере y = 3 − (x − 2)/(x² − 2x). После сокращения остаётся y = 3 − 1/x, но точка с x = 2 по-прежнему исключена. Полное письменное объяснение проверьте отдельно от числовых ответов.

Как изменить задачу о производной · касательная по клеткам

Учебная схема: GIF можно посмотреть целиком или по кадрам.

  1. Скачай HTML тренажёра производной. Пример: A(1; −2), B(3; 2).
  2. Попроси добавить пример A(1; −2), B(3; 1), x₀ = 2. Приложи HTML.
  3. Сохрани ege-profil-derivative-my.html. Свой рисунок сверь с условием.
  4. Δy = 3, Δx = 2. Производная равна их отношению: f′(2) = 1,5.
  5. Открой копию без сети: пустой ответ и 2 не подходят; 1,5 — верно.

В новом примере касательная проходит через A(1; −2) и B(3; 1): k = (1 − (−2))/(3 − 1) = 1,5. При x₀ = 2 точка касания имеет координаты (2; −0,5). Сверьте координаты, одинаковый масштаб осей и шаги разбора. В поле ответа можно ввести 1,5 или 1.5.

Как изменить финансовую задачу · пени за задержку платежа

Учебная схема: GIF можно посмотреть целиком или по кадрам.

  1. Скачай HTML по финансовым задачам. Открой пример «Пени за задержку».
  2. Попроси заменить срок февральской просрочки с 5 на 4 дня. Приложи HTML.
  3. Сохрани свою копию. Сверь дату, строку таблицы и разбор за февраль.
  4. Сложи обязательные платежи и обе пени. Затем вычти сумму кредита.
  5. Без сети проверь: 375,1 отклоняется, 363,1 принимается. Ответ в тыс. ₽.

В новой копии февральские пени составляют 48 тыс. ₽. При сумме обязательных платежей 1280 тыс. ₽, майских пенях 35,1 тыс. ₽ и кредите 1000 тыс. ₽ переплата составляет 1280 + 48 + 35,1 − 1000 = 363,1 тыс. ₽.

Как изменить логарифмическое неравенство

Учебная схема: GIF можно посмотреть целиком или по кадрам.

  1. Скачай HTML практикума. Открой первый вариант «Знак логарифма».
  2. В HTML найди блок engine.js. Замени первое число в массиве с 6 на 8.
  3. Сохрани копию. Проверь условие x > 0, x ≠ 1 и новый аргумент.
  4. При x > 1 из (x+2)/8 ≤ 1 получаем x ≤ 6. Отметь (1; 6].
  5. Без сети проверь границу 6 и итог (1; 6]. Прежняя граница 4 отклоняется.

При x > 1 логарифм возрастает по аргументу, поэтому нужен аргумент не больше 1. При 0 < x < 1 аргумент (x+2)/8 меньше 1, и логарифм положителен. Основание 1 недопустимо.

Как изменить задачу на делимость

GIF можно посмотреть целиком или по кадрам.

  1. Скачай HTML. Открой «Число минус сумма его цифр».
  2. В задаче p1 замени 2025 на 2043 и 2026 на 2044. Обнови проверку и разбор.
  3. Сравни остатки N и S(N) при делении на 9. Число 2044 не делится на 9.
  4. После проверки границ реши 1998 + 9x = 2043. Цифра десятков равна 5.
  5. Без сети проверь пример 2050, невозможность в б) и максимум 2059.

Если N = 10q + y, где y — последняя цифра, то N − S(N) = 10q − S(q) ≥ 9q. При разности 2043 это даёт q ≤ 227 и N ≤ 2279. Поэтому N четырёхзначное, и из N = 2043 + S(N) получаем 2044 ≤ N ≤ 2079. Все решения имеют цифру десятков 5, цифра единиц любая.

5. Как передать запрос в DeepSeek

В поле «Что хотите изменить?» опишите одну правку, затем нажмите «Скопировать промпт для DeepSeek». Если браузер не копирует автоматически, выделите текст вручную или возьмите промпт из ZIP. Вставьте запрос в DeepSeek и вручную приложите HTML. Для этой правки достаточно копии тренажёра.

6. Что обязательно проверить перед использованием

Математику

Проверьте пустой ответ, ошибку и верный ответ. Возьмите контрольные примеры из инструкции к своему комплекту.

Подсказки

Подсказка должна направлять, а не сразу выдавать готовое решение.

Телефон

Откройте файл на маленьком экране: кнопки и текст не должны налезать друг на друга.

Нейросеть может помочь с кодом, но методическая логика остаётся за педагогом: именно вы решаете, какую ошибку тренировать, какую подсказку дать и когда навык можно считать освоенным.

7. Частые ошибки

Скачать только HTML, когда нужен архив

Если тренажёр зависит от файлов данных или внутренних страниц, один HTML может открыться неполно.

Не проверить генератор

После адаптации обязательно решите несколько серий как ученик: так быстро видны неверные варианты.

Сделать слишком много тем сразу

Лучше один тренажёр — один навык. Тогда ребёнку понятнее, что именно отрабатывается.
