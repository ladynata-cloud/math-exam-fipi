## Задача

В задаче про переливание подсказка предлагала «делить старую высоту на отношение площадей». По просьбе владельца проверены также другие задания трёх экзаменационных курсов, в которых ученик выбирает величину, порядок деления или основание для вычисления процентов.

Отметки глубины проходят от дна до поверхности. При радиусе в четыре раза больше второй шаг использует исходную глубину и делитель 16. |

## Проверка и выпуск

Математику, обратную связь при ошибке, оба направления изменения и восстановление задания проверяют тесты в `tools/ege-baza-concrete-hints.test.cjs`, `tools/ege-baza-stereo-figures.test.cjs`, `tools/oge-practical-tires-feedback.test.cjs` и `tools/profile-step-solutions.test.cjs`. Для скачиваемых комплектов проверяются HTML и содержимое ZIP. В архиве практических задач ОГЭ обновляется только страница шин.

Критерий выпуска — эти проверки, успешные применимые проверки PR и сверка опубликованных материалов. Откат выполняется обычным отменяющим коммитом. Задание охватывает перечисленные семейства. Индивидуальные работы учеников для проверки не требуются.

Проверка исторических редакций сверяет новые тексты о шинах по двум точным хэшам, затем сравнивает всю страницу с ранее утверждёнными байтами. Проверка сборщика учитывает точную версию публичного скрипта карты после PR #642. Ошибка ожидания его прежней версии воспроизводилась и на исходной ветке без правок подсказок.
