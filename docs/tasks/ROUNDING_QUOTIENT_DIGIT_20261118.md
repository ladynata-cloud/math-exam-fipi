## Что меняется

Ликбез, карта ОГЭ, опоры к задачам на деление в ЕГЭ базе и курс деления дают прямые входы в округление до десятков и сотен. После разминки ученик применяет округление к числу, которое делит на текущем шаге. Доступны два режима прикидки в прежнем тренажёре. В новом режиме есть примеры с двух- и трёхзначными делителями.

Цифра выбирается после проверки исходных чисел. Например, прикидка для 364 : 52 даёт 400 : 50 = 8. Проверка показывает, что 52 · 8 = 416 больше 364, поэтому нужно попробовать 7. Для окончательной цифры q должно выполняться d · q ≤ N < d · (q + 1), где d — делитель, N — текущее неполное делимое.

Основные этапы курса, прежние задачи и сохранения по их исходным генераторам сохраняются. Режим сотен использует отдельный генератор и хранит черновик отдельно в браузере. Книжные выпуски сайта `/b/` и `/book/`, файлы книг, доска и серверный контракт кабинета находятся за пределами задачи.
