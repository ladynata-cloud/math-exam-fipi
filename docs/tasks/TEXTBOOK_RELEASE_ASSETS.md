# Загрузка согласованной версии школьной мастерской

Дата: 2026-10-02. База: 8a60fe36871ad6081d59a1352f7be27705bce553.
Ветка: fix/textbook-release-assets. Уровень: SMALL, механическое исправление доставки статических файлов.

После PR #165 публичные файлы совпали с выпущенными SHA-256, но ранее открытый браузер продолжал использовать старый app.js вместе с новыми модулями. В результате отображался старый каталог без поиска. Добавлен параметр версии ко всем локальным CSS/JS на странице school/index.html, чтобы ссылка на обновлённый HTML вела к согласованным файлам. Код, схема данных и сервер не меняются.

Разрешение: входит в поручение владельца создать и опубликовать работающие курсы, исправляет обнаруженную при обязательной публичной проверке регрессию. Отдельное окончательное согласование ранее не требовалось. Защиты доступа не обходятся.

Проверки: реальный Chromium и существующая проверка 30 новых уроков; сборка архива и статические ссылки; git diff --check; после выпуска повторное открытие в том же публичном браузере, поиск, урок и сохранение.

Откат: вернуть только параметры URL, не менять состояние учеников. Риск отката — повторная загрузка старого интерфейса из кеша. Новых библиотек и постоянного хранилища нет. Внешнее ревью не проводилось и для SMALL не заявляется.
