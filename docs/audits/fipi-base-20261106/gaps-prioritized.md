# Базовый ЕГЭ: что подтверждено 6 ноября 2026 года

Проверена опубликованная основа курса на `8d7fdd8c`. В матрице 111 **семейств сайта** по всем 21 позициям. Из них 107 входят в обычную практику и четыре — дополнительные упражнения по уравнениям для позиции 17. Номер позиции и внутренний ID сайта не являются идентификатором задания ФИПИ.

**Первоисточники.** [Страница ФИПИ](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory) на дату проверки называет пакет ЕГЭ-2027 проектом. Оба официальных ZIP получены повторно. Для всех семи вложений сверены CRC и SHA-256; обе контрольные суммы архивов совпали с октябрьскими. Для сверки курса выбраны только три файла базового уровня: демоверсия (17 страниц), спецификация (6) и открытый вариант 2026 года (7). Их байты совпали с PDF в репозитории; у всех 30 страниц сохранены последовательные номера. Профильные PDF не включены в доказательство покрытия.
