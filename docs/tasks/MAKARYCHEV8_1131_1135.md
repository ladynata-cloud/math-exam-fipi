# Макарычев, 8 класс, №1131–1135

Источник — Ю. Н. Макарычев и др., «Алгебра. 8 класс», 17-е стереотипное издание, Просвещение, 2024, ISBN 978-5-09-116445-9. Все пять номеров сверены по печатной странице 254 (страница PDF 255).

В №1131 ученик строит обе ветви по своим дробным точкам и проверяет свойства при обоих знаках коэффициента. №1132 сопоставляет две гиперболы с алгебраическим доказательством. В №1133 ученик ищет абсциссы и проверяет решения неравенств по обе стороны от нуля. №1134 сопоставляет область определения с направлением изменения слагаемых. №1135 показывает на числовой оси решения двух строк и введённое учеником пересечение.

Блок содержит 14 карточек и 36 шагов. Четыре отдельные тренировки меняют коэффициенты, уровни и границы. Адреса ранее начатых заданий сохраняются. №1076 сохраняет пометку об авторской альтернативе.
