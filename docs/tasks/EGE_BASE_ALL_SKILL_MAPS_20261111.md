## Результат

Все 113 семейств базового ЕГЭ получают индивидуальные карты конкретных умений, ссылки на подготовительные упражнения, новые авторские задания для самопроверки с проверкой числа или дроби и объяснением по запросу. Материал №21 сохраняет пошаговые карты с проверкой каждого пройденного шага.

На странице экзаменационного номера навыки сгруппированы по типам задач. Ученик может открыть нужный тип и перейти к тренировке. В каждой задаче карта открывается по запросу и ведёт к текущему шагу существующего разбора. Для смешанных семейств проверяются отдельные математические действия. В задачах на среднюю скорость выделен весь путь, в совместной работе общий знаменатель стоит перед сложением производительностей, в неравенствах область определения предшествует выбору интервалов.

Карты используют редакционные данные и компонент подготовленного PR #555. В этой задаче применяется текущий опубликованный лендинг ЕГЭ. Сохранение результатов курса и правила самостоятельных попыток обслуживает прежний контроллер. Самопроверка внутри карты имеет отдельную обратную связь и не добавляет баллы в курс.

## Приёмка

- [ ] Точные ID всех 113 действующих семейств присутствуют по одному разу.
- [ ] Все 113 мини-заданий имеют формулировку, проверяемый ответ и математически верное объяснение.
- [ ] Все ссылки на практику и следующий шаг разрешаются в существующие семейства.
- [ ] Для каждого типа на странице остаётся одна карта.
- [ ] При открытии карты и самопроверке сохраняются исходное условие и черновик.
- [ ] Пройденные шаги относятся к текущему условию.
- [ ] Режимы пробного экзамена, диагностики и управляемой доски проходят действующие регрессии.
- [ ] Узкий и широкий экран проходят Chromium.
- [ ] CI проверяет фактический коммит и состав на актуальной main.
- [ ] После выпуска проверены реальные страницы №1–21.

## Проверки и сопровождение

Дополнены действующие проверки hints, DOM и Chromium всех семейств. Подготовительные числовые примеры независимо составлены и сверены несколькими внутренними проверяющими. Внешний аудит не проводился. Проверка с реальными учениками не проводилась.

Основные риски — неоднозначная формулировка мини-задания, неверная ссылка и потеря черновика при переходе. Откат выполняется обычным обратным коммитом. Изменение не содержит секретных данных или материалов учеников.
