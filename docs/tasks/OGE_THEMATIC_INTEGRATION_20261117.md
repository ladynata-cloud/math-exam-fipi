## Проверки

- Сохранить независимые проверки исходных веток и согласовать общие точные сравнения для объединённого дерева.
- Проверить обычную тренировку, вход в кабинет, повторное открытие старой заданной работы и автономные архивы актуальных тренажёров.
- В №18 чертёж берёт значения из текущего условия. В №19 остаются подсказки по текущей карточке и полный согласованный набор карточек.
- Для общих скриптов заново собрать затронутые комплекты. Проверить соответствие HTML и ZIP и повторяемость генерации.
- Прогнать математику, DOM, доску, входы и возвраты, сохранность фиксированных редакций и браузерные сценарии на узких и широких экранах.

Точный результат общих проверок фиксируется для итоговой версии ветки. При необходимости откат выпуска выполняется штатным revert согласованного коммита.

## Актуализация после #643

Опубликованный маршрут после пробника вошёл в `main` на `c76d2358b3f4511517a18269c9860c8338a94052`. Совмещены точные проверки содержимого страницы пробника и тематических движков. В проверке №18 используются неизменяемые, уже проверенные исходники №16 и №17 из #638. Книжный тест проверяет точный новый номер версии скрипта карты из #642 и прежние версии остальных трёх ресурсов.

На первоначальном совместном дереве браузерная проверка прошла 294 страницы с JavaScript и 134 без JavaScript. После актуализации пройдены 17 проверок №18, 16 проверок книжного генератора и статическая проверка 147 документов и 1 687 ссылок. Полные запуски относятся к точной итоговой версии в #644.
