# Мерзляк, геометрия 10 класса — базовый уровень, 2022

Отдельный курс по предоставленному учебнику Мерзляка, Номировского,
Полонского и Якира. Цель — все задачи, теория и индивидуальные модели.
Это первая подготовка; полный курс ещё не завершён и не опубликован.

## Фактический объём подготовки

- Реестр: 736 самостоятельных нумерованных упражнений — 723 в параграфах
  и 13 дополнительных. Отдельно учтены 19 теоретических параграфов,
  97 вопросов, 18 компьютерных блоков и 5 проектных тем.
- Подготовлены 83 карточки для всех 79 номеров §§1–3: 27 + 20 + 32.
  Задачи 3.7 и 3.9 разделены по разным конфигурациям.
- Подготовлены 19 обзорных уроков теории. Это не полные разборы всех
  доказательств, примеров и вопросов параграфа.
- Всего 102 авторские карточки. На этой стадии все имеют статус `draft`;
  доступных ученикам карточек — 0. Проверки содержания и визуального
  отображения фиксируются отдельно и не переводят статусы автоматически.

Не готовы остальные 657 нумерованных упражнений, вопросы самопроверки,
компьютерные задания, проекты и полные теоретические разборы.
`inventoryComplete:false` означает, что ещё нужна подробная проверка
подпунктов и вложенных компонентов всего источника.

## Как устроен материал

Крупная модель находится перед разбором. Шаги открываются постепенно,
предыдущие шаги и записи сохраняются. В доказательствах запись ученика
сохраняется для обсуждения, без ложной автоматической оценки правильности.
Используется существующий движок учебника Атанасяна с двумя изолированными
изменениями: `PDF = печатная страница + 1` и точный поиск номера `1.1`.
Другие курсы, кабинеты и сервер не меняются.

## Сборка и проверки

```bash
python3 tools/merzlyak-10-base/build.py
python3 tools/merzlyak-10-base/build.test.py
node tools/merzlyak-10-base/schema-runtime.test.cjs
node tools/stereo-textbook/model-geometry.test.cjs stereo-course/merzlyak-10-base/data/course.json
python3 tools/merzlyak-10-base/para01-models.test.py
python3 tools/merzlyak-10-base/para02-models.test.py
node tools/merzlyak-10-base/theory-models.test.cjs
```

DOM/схемам нужны `jsdom`, `ajv`, `ajv-formats`. Облачный workflow запускает
Chromium для всех авторских видов моделей при ширине 320 и 1280 пикселей.
Этот технический просмотр монтирует модели напрямую; он не меняет статус
черновиков, не имитирует математическую проверку и не открывает их ученикам.

Внешняя консультация ограничена одним запросом при создании PR и только
при наличии уже настроенного ключа. Отсутствие ключа или ошибка поставщика
явно фиксируются как отсутствие консультации. Консультация по нескольким
образцам не является проверкой всего учебника или разрешением публикации.

Скан, полный OCR, изображения страниц и данные учеников не включены.
SHA256 источника и точные ссылки на страницы находятся в реестре.
