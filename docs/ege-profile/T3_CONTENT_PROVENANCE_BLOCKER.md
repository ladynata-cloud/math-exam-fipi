# Блокер происхождения контента линии 3

## Статус

Заблокирован до проверки происхождения.

На base SHA найден существующий 3D-материал по стереометрии: 143 задачи, 9 тем. Сама существующая страница сообщает о происхождении задач из банка «Решу ЕГЭ». Phase A не проверяет и не переписывает эти формулировки.

## Ограничения Phase A

- Не удалять существующее упоминание источника.
- Не переписывать задачи автоматически.
- Не объявлять материал очищенным или допущенным.
- Не публиковать активную ссылку из нового навигатора или шлюза t3.
- Не добавлять материал в новые sitemap, каталог, главную или board manifest записи.
- Не менять существующий тренажёр.

## Что требуется для разблокирования

Phase B должна отдельно проверить все 143 задачи, зафиксировать происхождение и допустимость каждой формулировки и получить отдельное решение владельца. Только после этого можно решить вопрос о canonical-материале и opens-in-board без full mirror.
