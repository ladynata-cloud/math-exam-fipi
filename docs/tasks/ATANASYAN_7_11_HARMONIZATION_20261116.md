## Goal

Привести существующие тематические курсы Атанасяна к согласованному учебному циклу: **исследовать по теме → сформулировать наблюдение → понять → обосновать → решить с опорой → решить другое условие самостоятельно → записать своё рассуждение**. Исправить подтверждённые ошибки проверки ввода, тематические несоответствия и отсутствие нужных рисунков. Сохранить проверенные условия учебников, идентификаторы, незавершённую работу и действующие входы.

## Approved scope

### In scope

1. Все **63 темы атласа 7–9 и 39 тем мастерской 10–11**. Для каждой — конкретный вопрос, предварительный прогноз, доступное действие с моделью, наблюдаемая величина/связь, вывод и граница применимости. Один компонент можно использовать в нескольких темах только с собственным предметным сценарием каждой темы. Проект сценариев приведён ниже.
2. Новый последовательный маршрут с исследованием первым. Возврат к старой работе сохраняет смысл её этапа. Теория и доказательство открываются после возможности сделать свой прогноз; ученик сохраняет возможность осмысленного свободного перехода.
3. Понятное объяснение: определения объектов и обозначений, минимальные предпосылки, один вопрос за раз, дополнительные детали по запросу. Измерение и перемещение не объявляются доказательством общего случая.
4. Рисунок по условию и шагу. В атласе добавить недостающие тематические схемы, используя подходящие готовые рисунки #599. В стереометрии сохранить математически проверенные сцены; различать модель условия, дополнительные построения и свободное исследование. Исключить раскрытие искомого числа самим рисунком.
5. Согласованная практика. Проверить соответствие заданий всем 102 темам. В перечисленных бедных/ошибочно сопоставленных семействах добавить минимум три содержательно разные ситуации, включая контрпример или проверку условий применимости там, где это уместно. Одного изменения числа недостаточно для заявления о новом методическом типе. После разбора — другое условие; знакомое повторение явно отмечается.
6. Исправить G4, S4 и S5. Различать пустой ввод, незавершённую/нераспознанную запись, недопустимое выражение, неверный математический ответ и верный эквивалентный ответ. При ошибке формата не расходовать математическую попытку и не выдавать готовый результат. Первая содержательная ошибка даёт адресное замечание; после двух ошибок — предложение пошаговой помощи. Помощь по просьбе доступна раньше.
7. Сохранность состояния: старые числовые `stage` должны сохранить смысл; чертежи старого исследования не накладываются на несовместимую новую сцену. Сохраняются старые наблюдения, письменные решения, черновики, результаты, история помощи, самостоятельности и повторов. Новые поля вводятся совместимо, без очистки хранилища или повышения старых результатов задним числом.
8. Согласовать «Все темы», «На главную», переход к задачам учебника и возврат к исходной теме. Использовать существующие first-steps, literacy и маршрут ЕГЭ без независимых копий их карточек. Контракт общей доски не менять.
9. Пересобрать **63 автономных HTML атласа** и автономный `stereo-course/index.html` из исходников. Обновить существующий скачиваемый комплект геометрии и его описание: нынешняя запись «7 класс» не отражает 7–9. Сохранить редактируемость исходников, инструкцию и имеющиеся ссылки. Полная работа математического ядра проверяется без сети; перенос сохранений через файл проверяется отдельно от непереносимого между браузерами поведения `file://`.
10. Зафиксировать карту приёмки 102 тем: обследовано → изменено → математически проверено → интерфейс проверен → опубликовано. Состояние «опубликовано» возможно только после отдельного разрешения на выпуск и фактической проверки сайта.
