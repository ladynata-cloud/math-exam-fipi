# Навигатор базового ЕГЭ — рабочая версия

Дата: 2026-10-01. Задача: `EGE_BAZA_COURSE_03_NAVIGATOR`.
Зависит от Draft #148 (план) и #147 (первый модуль). Публикация всего курса
остаётся отложенной до готовности и отдельного разрешения владельца.

## Что собрано

Вход `/ege-baza/` объединяет экран «Сегодня», карту семи модулей, страницы
с целями уроков, подготовительные тренажёры, результаты первого модуля
и рекомендации преподавателю. Реестр содержит 32 темы: шесть уроков
первого модуля открываются, 26 тем обозначены как план без кнопки запуска.
Позиции 1–21 распределены по шести основным модулям; седьмой — смешанная
экзаменационная практика. Это ещё не завершённая матрица всех подтипов.

`ege-baza/registry.js` хранит стабильные ID, цели, предпосылки, статусы
и адреса. Зависимости уроков проверяются на неизвестные ID и циклы.
Существующие подготовительные тренажёры открываются в отдельной вкладке:
в навигаторе остаётся ссылка обратно в исходный модуль. Их прогресс
не прибавляется к показателям курса. Оценивание этих материалов не менялось.

## «Сегодня» и результаты

Навигатор только читает ключ первого модуля
`mathexam.ege-baza.foundation.v1`. Он не создаёт ключей, не мигрирует данные,
не отправляет запросов и не пишет в хранилище. Модуль остаётся источником
результатов. Снимок обновляется при возвращении на страницу, смене вкладки
и событии storage; в результатах есть ручная кнопка обновления.

Приоритет следующего действия:

1. Продолжить начатую проверку; повтор доступен только после суточной границы.
2. Если старт ещё не определён — перейти к диагностике первого модуля.
3. После итога — разбор, затем повторение не раньше чем через 24 часа.
4. Иначе продолжить начатую практику или открыть нужный урок.
5. После 24 тренировочных задач — итоговая проверка.

Для незавершённой проверки показывается только количество записанных ответов.
Диагностика не подтверждает освоение; подсказка, просмотр решения и исправление
не считаются первой самостоятельной попыткой. Общего процента освоения курса
и прогноза экзаменационной оценки нет. Повтор зависит от часов устройства,
как и в исходном модуле; защиты от ручного изменения данных не заявлено.

`foundation-reference.js` — минимальное зеркало ID/фазы/навыка/ответа из
первого модуля, нужное для проверки сохранённых записей. Gate сравнивает его
с исходным банком целиком. При изменении задач зеркало надо обновить вместе
с модулем. Это не второй независимо редактируемый банк.

Повреждённое или недоступное хранилище сопровождается предупреждением;
карта остаётся доступной. Никакие данные навигатор при этом не удаляет.
Нет переноса прогресса между браузерами и автоматического журнала группы.

## Полезные решения из проекта ОГЭ

Источник — сохранённые документы репозитория, прежде всего
[ADR 0003](adr/0003-oge-course.md), где прямо указано «подготовка — Claude»,
и [план ОГЭ](OGE_COURSE_PLAN.md). Запись решения не является доказательством
его реализации. Область ADR — ОГЭ; его группы 4–8 учеников и дорожки
по отметке не заменяют принятый для базового ЕГЭ формат мини-группы до трёх.

| Решение ОГЭ | Что полезно для базового ЕГЭ | Состояние в этом шаге |
| --- | --- | --- |
| Обёртка курса с сохранением адресов тренажёров, решение 1 | Единый вход при сохранении работающих материалов | Карта и действующие ссылки; главная пока не меняется |
| Ликбез и карта «линия → предпосылки», решение 24 | Повторять конкретный пробел, затем возвращаться в урок | Шесть подготовительных ресурсов и связи с уроками |
| Повторение ошибок и проверка освоения, решения 3 и 13 | Разделять тренировку, самостоятельную проверку и закрепление | Отображение уже существующих правил первого модуля |
| Домашнее задание ссылкой, решение 20 | Простое индивидуальное назначение для мини-группы | Пока только адреса уроков; назначения и учёт ДЗ не реализованы |
| Общий вариант и режим проектора, решение 22 | Совместное обсуждение и короткая пятиминутка | Идея для последующих задач, параметры seed/drill не добавлены |
| Серверная группа, решение 19 | Возможный будущий журнал преподавателя | В этой версии отсутствует; новый серверный контракт не принят |

Из старых материалов уже можно использовать объяснения дробей, десятичных
чисел, отрицательных чисел, порядка действий и пропорций. Следующий шаг
с прогрессом должен отдельно определить, как подтверждать освоение основы,
а не засчитывать открытие ссылки или чужой несовместимый счётчик.

## Проверки и просмотр

Из корня репозитория с зависимостями, установленными вне репозитория:

```sh
node tools/ege-baza-navigator.test.mjs
node tools/ege-baza-foundation.test.mjs
node tools/ege-baza-foundation.dom.mjs
node tools/ege-baza-navigator.browser.mjs
python tools/build-ege-baza-preview.py /absolute/output/ege-baza-preview.zip
```

DOM gate требует jsdom через NODE_PATH. Browser gate требует Playwright и
совместимый Chromium. `NAVIGATOR_CHROMIUM_PATH` задаёт путь к установленному
браузеру, `NAVIGATOR_SCREENSHOTS_DIR` — каталог снимков. Проверяются ширины
1280 и 360, отсутствие переполнения, клавиатурный переход, реальный урок,
возврат, история, недоступное сохранение и загрузка файлов с диска.

Пройдено: 238 проверок реестра, адаптера и DOM; 60 независимо вычисленных
ответов первого модуля; 81 регрессионная DOM-проверка первого модуля.
Реальный браузер не запустился из-за запрета socket в среде исполнения:
`Operation not permitted`. Поэтому визуальная проверка, настоящая клавиатура
и file:// остаются непроверенными; DOM gate их не заменяет.

Пакет для просмотра содержит две связанные локальные страницы с ресурсами.
Ссылки на остальные материалы в копии направлены на mathexam.space;
исходники от этой упаковки не меняются. После распаковки открывается
`ege-baza/index.html`. Сохранение между file://-страницами зависит от браузера;
пакет предназначен для просмотра, не для ведения группы.

## Риски и продолжение

Фокус ревью: согласованность зеркала, отсутствие записи в хранилище,
честность показателей и переходы к первому модулю. Выполнено авторское
ревью кода; независимое внешнее ревью здесь не заявляется. MEDIUM для этой
дельты не отменяет HIGH-ревью первого модуля и общего будущего контракта.

Следующая самостоятельная задача: общий формат прогресса, история помощи
и проверочных попыток, переносимая резервная копия, возвращение из основы
к основному уроку. До неё — закрыть браузерную проверку в доступной среде.
Откат этой дельты: убрать каталог навигатора и вернуть ссылку каталога
в шапке первого модуля. Данные учеников этой дельтой не изменяются.
