# Focused design brief

The learner should select a source section and difficulty, attempt an actual geometry task, then request a clue or a single justified step. Use the established Atanasyan/Merzlyak scene renderer and retained-step engine. Plane figures stay flat; spatial geometry may rotate. Each task has coordinate-true geometry; extra constructions appear in the relevant view. Small labels remain outside figures. Prior work remains visible. Numeric answers use exact conservative string normalization; proofs are retained but never auto-approved. Help use is sticky; a fresh other variant is needed to demonstrate independent transfer.

Prerequisites: fractions/proportions, angle facts, Pythagoras, areas, perpendicular projection. Typical errors: wrong segment ratio, confusing height and slant edge, surface area versus volume, radius versus diameter, deriving a fact by looking at a projection.

Questions for consultation: Are steps small enough and model views connected to the actual action? Does a model disclose the answer before a learner tries? Does proof feedback avoid automatic correctness claims? The source book has 990 task numbers / 1,980 intended variants. First release selects tasks across all 27 topics and labels remaining entries pending; never equate catalog presence with solved coverage.

Executor access check before implementation: no authorized Anthropic credential or Claude connector exposed. Consultation not run; no provider advice or release verdict. Independent source/math and technical review continue. External release review or explicit owner exception still required by repository policy.
