# Самостоятельная практика к двум пособиям Тюрина

Сопоставлены печатные оглавления из изданий МЦНМО 2011 года (7–9 классы) и 2014 года (10–11 классы). Проверенные SHA-256 и адреса опубликованных авторами PDF находятся в VERIFIED_BOOK_ROUTES_20261121.md. Публичный раздел использует исторические числовые данные о городах со с. 17 с указанием источника. Остальные учебные наблюдения и задания составлены для MathExam.

В младшем пособии добавлены 23 практикума, в старшем — 10. Ребёнок меняет данные разобранного примера, выполняет тренировку, затем три новых вопроса с разными математическими действиями. Проверка различает первую самостоятельную попытку, исправление и подсказку. Для зачёта требуется не менее двух первых самостоятельных ответов. Вопросы после повторения получают новые исходные данные. Сохранение текущего ввода и итогов действует на устройстве. Отдельные входы ведут к нужному месту в пособии, в соседний действующий тренажёр и на общую доску.

Общий охват карточек по темам теперь 67/67 и 29/29. Остальные 44 и 19 ссылок дают практику по отдельному навыку соответствующего пункта. Этот учёт относится к пунктам оглавлений. Указатель упражнений по номерам и разбор всех задач этих изданий в него не входят.

Тесты проверяют исходные страницы, все 33 привязки, математические примеры, три формы каждого вопроса, вход по URL, состояние при ошибке, подсказку, зачёт, сохранение, изоляцию личных ответов от общего состояния. Новая запись в реестре доски использует строгий обмен значениями состояния без HTML.
