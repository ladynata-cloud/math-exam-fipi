# Мерзляк, геометрия 10 класса — базовый уровень, 2022

Полный подготовленный курс по предоставленному учебнику Мерзляка,
Номировского, Полонского и Якира. В PR304 находятся 989 проверенных карточек.
Публикация на основном сайте требует отдельного решения владельца:
внешний review не получен.

## Объём курса

- Все 736 самостоятельных нумерованных упражнений: 723 в параграфах
  и 13 дополнительных. Их решения занимают 762 карточки, поскольку
  отдельные подпункты и конфигурации выделены для ясности моделей.
- 86 теоретических карточек: 19 обзоров, 54 подробных разбора основного
  материала и 13 дополнительных разборов статей. Учтены все пять
  дополнительных статей, определения, доказательства и разобранные примеры.
- 97 ответов на вопросы самопроверки.
- 39 карточек для всех 18 компьютерных блоков.
- 5 руководств к исследовательским проектам. Это руководства с примерами,
  а не выдаваемые за ученические работы готовые исследования.

Реестр содержит 875 исходных групп и 989 обязательных компонентов.
`inventoryComplete:true` установлен после сверки всех компонентов;
для каждой карточки имеются независимые проверки источника, математики
и объяснений. Выявленные противоречия и неоднозначности самого учебника
объясняются в соответствующих решениях. Номер 20.92 встречается только
в ответах: условие отсутствует, поэтому вымышленная задача не добавлена.

## Подтверждение проверки

Все 989 карточек имеют статус `reviewed`; сборка открывает 989 карточек.
21 исходный отчёт сохранён без подмены хешей. Манифест явно указывает
авторов, независимых проверяющих, области проверки и SHA256 отчётов.
`content-review-ledger.json` доказывает, что после проверки изменены только
`status` и `review`; учебное содержание сохранилось побайтно при восстановлении
исходного состояния. Поле `review.at` обозначает принятие полной проверки
при интеграции; имена проверяющих взяты из свидетельств каждой карточки.

Аудитор восстанавливает точный исходный JSON, проверяет все хеши и три
вердикта для каждого компонента. Сборщик сам не повышает статусы.
Проверка содержания не является разрешением на слияние или публикацию.

## Как устроен материал

Крупная модель находится перед разбором. Шаги открываются постепенно,
предыдущие шаги и записи сохраняются. В доказательствах запись ученика
сохраняется для обсуждения, без ложной автоматической оценки правильности.
Используется существующий движок учебника Атанасяна с двумя изолированными
изменениями: `PDF = печатная страница + 1` и точный поиск номера `1.1`.
Другие курсы, кабинеты и сервер не меняются.

## Сборка и проверки

```bash
python3 tools/merzlyak-10-base/audit-content-reviews.py --no-write
python3 tools/merzlyak-10-base/inventory-contract-review.test.py
python3 tools/merzlyak-10-base/build.py
python3 tools/merzlyak-10-base/build.test.py
node tools/merzlyak-10-base/schema-runtime.test.cjs
node tools/stereo-textbook/model-geometry.test.cjs stereo-course/merzlyak-10-base/data/course.json
```

Полный перечень математических, регрессионных и независимых проверок
находится в `.github/workflows/merzlyak-10-base-quality.yml`.
DOM/схемам нужны `jsdom`, `ajv`, `ajv-formats`; геометрии — `numpy`.
Облачный workflow запускает Chromium для каждого авторского вида модели
при ширине 320 и 1280 пикселей. Проверяются подписи, границы, переполнение,
конечность координат и ошибки JavaScript; сохраняются снимки нейтрального
и заключительного вида каждой модели. Runtime отдельно проверяет настоящие
доступные карточки и принудительно созданную отрицательную выборку черновиков.

Исторические облачные снимки 542 и 900 карточек зафиксированы отдельно
в `cloud-checkpoints.json`. Они не подменяют финальную проверку 989 карточек;
её точные commit, base, run и artifact указываются в PR304 после завершения CI.

Первый запрос внешней консультации выполнен в Actions run `39857930153`.
Провайдер вернул HTTP400; ответа и внешнего verdict нет. Повторные запросы
не выполнялись. Успех задания, сохранившего этот отчёт, не означает успех
самой консультации. Для выпуска нужно выполнить правило внешнего review
либо получить явное исключение владельца с обоснованием.

Скан, полный OCR, изображения страниц и данные учеников не включены.
SHA256 источника и точные ссылки на страницы находятся в реестре.
