Начать с простогоВыбрать старт по проверке

Можно начать с любого шага. Предварительная проверка необязательна.

Как заниматься
  1. Разбери один пример по шагам.
  2. Реши ещё несколько на новых числах.
  3. Попробуй без подсказок и проверь себя.
