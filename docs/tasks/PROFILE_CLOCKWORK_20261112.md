На лендинге ЕГЭ профиля нужна анимированная иллюстрация часового механизма. Гномики передвигаются по мосткам, а номера на циферблатах открывают задания.

## Критерии приёмки

- На двух циферблатах доступны №1–13 и №14–20 в нумерации курса 2027 года. Ссылки и названия берутся из списка тем. №2 открывает «Азбуку векторов».
- Шестерни движутся в зацеплении, маятник качается, стрелки показывают время браузера, три гномика ходят по мосткам. Номера остаются доступными во время движения.
- Анимацию можно поставить на паузу. Системная настройка уменьшенного движения включает неподвижный кадр по умолчанию. Вне экрана отрисовка приостанавливается.
- Циферблаты и ссылки работают при ширине 320 и 1280 px и доступны с клавиатуры. Список тем доступен без JavaScript.
- Привязка навигатора обновляется для изменённого лендинга, с сохранением записей о прочих страницах.

## Проверка и выпуск

- Проверка в браузере охватывает все 20 ссылок, открытие первой и второй части, работу с клавиатуры, остановку и запуск движения, узкий экран и вход без JavaScript.
- Применяются проверки входов ЕГЭ, навигатора и SEO. Результаты, фактические ревизии и проверка публикации фиксируются в PR.
- Работа запрошена владельцем. Выпуск после проверок по [действующему разрешению владельца](../OWNER_RELEASE_AUTHORIZATION.md). Для привязки навигатора исходный коммит должен остаться в истории. Откат выполняется обычным revert выпуска.
