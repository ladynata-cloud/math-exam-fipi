# №433–439. Вписанные и описанные сферы

Одиннадцать самостоятельных карточек завершают основной ряд главы IV. Условия сверены по печатной странице 115 учебника Атанасяна для 10–11 классов (2024), ответы — по странице 266. Для №436в дополнительно просмотрено изображение исходной строки: задан радиус основания √3 см. Тексты, модели, пояснения и контрольные вопросы подготовлены для сайта.

Второй участник независимо пересчитал оба радиуса №433, обе пары измерений №434, отношения площадей и угловые формулы №435–439. В №434 и №439в объяснено, почему допустимы два решения. В №433 одну модель можно повернуть, чтобы сопоставить разные центры и радиусы.

| Номер | Предметная проверка |
| --- | --- |
| 433 | Вписанная сфера касается четырёх плоскостей, описанная проходит через четыре вершины. Отдельно проверяются оба коэффициента при стороне основания. |
| 434 | Пары сторон и высот проверены подстановкой и в радиус 2, и в радиус 5. |
| 435 | Учитываются оба основания и боковая поверхность цилиндра. |
| 436, 437 | Касание проверяется расстоянием от центра сферы до образующей. Углы при основании и четверть угла при вершине взяты в соответствующих осевых сечениях. |
| 438 | Радиус сферы равен половине диагонали осевого квадрата, правильно выбран порядок деления площадей. |
| 439 | Радиус основания вычислен из хорды большого круга. Для радиусов в отношении 2:1 проверены высокий и низкий конусы. |

Проверка дополнительно сопоставляет формулы вписанной и описанной сфер на 540 семействах параметров конуса. При добавлении этого блока банк насчитывает 719 проверенных карточек, основной ряд охватывает №1–439 из 870. Следующий основной номер — 440, начало главы V.
