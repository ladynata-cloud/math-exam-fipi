# Математика по советским учебникам

30 тематических тренажёров, авторские упражнения и 30 немых MP4.
Это выбранная последовательность навыков, а не полный постраничный курс.
Источники и печатные страницы разделов находятся в `sources.js`.
Номер задачи можно добавлять только для упражнения, сверенного со сканом
соответствующего издания. Текущие упражнения авторские, `task: null`.

## Сохраняем старые материалы при расширении

Адрес темы `/soviet-math/#<topic-id>` и видео `media/<topic-id>.mp4`
постоянны. Новые темы получают новые ID; прежние ID не переиспользуются.
Добавляйте новую тему в соответствующий модуль, источник в `sources.js`
и запускайте запись только новых ID:

```sh
node tools/soviet-math-render.cjs --topics=new-topic-id
node tools/soviet-math-content.test.cjs
node tools/soviet-math.browser.cjs
node tools/soviet-math-render.cjs --check
```

Для записи нужны `@napi-rs/canvas`, FFmpeg и FFprobe; для браузерной проверки
Playwright (существующая фиксированная зависимость `video-worker`). `NODE_PATH`
может указывать на каталог установленных модулей. Проверка готовых MP4
не требует Canvas. Для реального проигрывания нужен Chrome с H.264:

```sh
node tools/soviet-math-video.browser.cjs
```

По умолчанию рендерер проверяет существующие файлы и их контрольные суммы,
не перезаписывая их. Изменение исходного задания требует явного `--replace`
для выбранного ID. Новый визуальный тип не требует перезаписи старых MP4:
версия рендерера записана отдельно от содержания задания в манифесте.

Нет ограничения каталога в 30 тем. Можно добавлять следующие выпуски по
10–20 тем до 100–200 и дальше, проверяя каждую порцию. Число вариантов
упражнения и число самостоятельных тренажёров — разные показатели.

## Непрерывная доска

`board.js` рисует и интерактивную доску, и кадры MP4. Основное решение
накапливается справа на постоянных местах; вспомогательные действия слева.
Локальное приближение сохраняет уголок видимым. В тренажёре движение можно
выключить; настройка уменьшенного движения браузера учитывается.

На телефоне две области расположены вертикально; текстовая запись решения
остаётся доступной. Подпись учебника видна над тренажёром и в самом MP4.

## Результаты

Изолированный ключ `mathExam.sovietMath.v1` хранит состояние только в текущем
браузере. Учебные примеры и видео не начисляют самостоятельный результат.
Повтор определяется по реальному условию и рисунку, помощь и ошибки учитываются.
Повреждённая запись и конфликт другой вкладки блокируют перезапись. Результат
можно выгрузить текстом; автоматической синхронизации с кабинетами нет.
