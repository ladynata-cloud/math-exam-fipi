## Состав пакета и проверка

- HTML включает код, данные, рисунки и необходимые стили. ZIP содержит тот же HTML, тематический промпт, `README.md`, GIF и статичные кадры. Кабинет, общая доска и дополнительные материалы по ссылкам открываются на MathExam. Векторы сохраняют локальный холст. Прогресс относится к экземпляру тренажёра и зависит от поддержки хранилища браузером.
- В конце тренажёра доступен свёрнутый блок скачивания. Поле пожелания подставляет текст в промпт. Передача файла в DeepSeek выполняется вручную. GIF показывает изменение размера текста и контроль пустого, неверного и верного ответа на примере ОГЭ №9. Анимация в инструкции запускается по кнопке, останавливается по запросу и поддерживает просмотр по кадрам.
- Проверить содержимое ZIP и идентичность отдельно скачиваемых файлов, запустить экспортированные HTML по `file://` с отключённой сетью, пройти типовое задание в каждом комплекте. Перед публикацией проверить публичную панель, переходы и сохранность первых 17 комплектов. Откат — отмена изменений этой ветки без переноса пользовательских данных.
