# Макарычев, 8 класс. Связи между корнями №764–782

В №764 проверяются сумма и произведение в том числе иррациональных корней. №766–768 содержат общие доказательства. №769, 771–772 и 778 допускают два значения неизвестного коэффициента. В №774 свободный член может быть нулём; в №775 по условию он ненулевой. Для новых корней в №782 необходимо ненулевое произведение исходных корней. После №782 начинаются упражнения к §8.
