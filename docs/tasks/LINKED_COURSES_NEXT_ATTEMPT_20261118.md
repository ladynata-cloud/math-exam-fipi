# Следующая самостоятельная попытка в дополнительных курсах ЕГЭ

18 ноября 2026. Продолжение [предметного аудита дополнительных курсов](LINKED_COURSES_AUDIT_20261118.md), PR #660. Наталья поручила продолжить проверку курсов и внести исправления. Выпуск проходит по [разрешению владельца](../OWNER_RELEASE_AUTHORIZATION.md). Исходная база продолжения `c30dbfe3384ae89e7fa91a087550de6bd5d3d227`. Уровень проверки MEDIUM.

## Что увидел ученик

- В базовом ЕГЭ после верного решения задачи на скидки ученик мог получить новую задачу того же типа только через возврат к модели. Во всех 20 вариантах на смеси вода удваивала массу раствора. Запомнив «подели процент пополам», можно было отвечать без чтения условия. В «Землекопах» переход к самостоятельному варианту уже доступен из результата.
- В курсе Мордковича ученик исправил ошибку в §5.6б, затем сам решил §5.6в. Экран завершения второго подпункта подтвердил самостоятельное решение. В общем итоге оказалась видна лишь оценка другого подпункта. Повторное открытие назначенного задания могло также скрыть в домашней работе факт, что ученик уже исправил и завершил его.
- Верхняя ссылка «Метод интервалов» ведёт в карту трёх навыков. После самостоятельной проверки с новым условием ученику предлагалось только повторить навык. К интерактивной числовой оси вёл отдельный вход через список материалов.

## Условия приёмки

- Ошибочный ответ в новой задаче на проценты можно исправить. После верного ответа ученик одним действием получает новое условие по тому же умению и пустое поле ответа. Возврат к модели остаётся доступным.
- После двух первых задач на закрепление встречается другой вопрос на тот же приём. В смесях, например, соотношение масс меняется, поэтому простое деление процента пополам больше не служит универсальным ответом. Подсказку и числовой ответ проверяют для каждого условия.
- Повторное подтверждение одного ответа не создаёт дополнительного результата. Самопроверка модели и итоговая диагностика сохраняют свою прежнюю семантику.
- В общем итоге тригонометрии ученик может сопоставить собственный результат с конкретным подпунктом. Примером для проверки служат §5.6б с исправлением и §5.6в, решённый самостоятельно. Результаты остаются различимыми после перезагрузки.
- После завершения навыка по методу интервалов можно продолжить обучение с экрана результата и по-прежнему повторить текущий навык. Интерактивная ось открывается из завершённого маршрута.
- Проверить обычные входы в браузере, мобильный размер, доступ с клавиатуры, существующие тесты соответствующих курсов и совместимость с уже сохранёнными результатами.

Из прежних внешних аудитов использованы приёмы переноса способа решения на новое условие и раздельного учёта попыток с помощью и без неё. Отдельной внешней рецензии и наблюдения на живом занятии для этой правки не проводилось. При необходимости обратного изменения используется обычный revert.

## Проверка учебных сценариев

- В шести моделях процентов проверены ответы всех 120 условий. После двух вводных задач в теме чередуются три типа вопросов. Для растворов отдельно пересчитаны масса соли и общая масса после добавления воды, испарения и смешивания. Есть отдельная проверка пути через неверный ответ, подсказку, исправление и следующую задачу с клавиатуры.
- В «Методе интервалов» пройден обычный вход из профиля, три новых условия и числовая ось. Проверен обратный порядок прохождения и сохранение результатов при повторном открытии. Прогон выполнен в Chromium на ширинах 320, 390 и 1280 пикселей.
- Для Мордковича проверены экран и текстовый отчёт, действительная ошибка и исправление в одном подпункте, самостоятельное решение другого, повтор, перезагрузка и чтение старого результата. Сверены подписи всех 295 упражнений с исходными названиями. Для домашней работы и раздела «После урока» отдельно проверены назначенный контрольный подпункт и соседний, за который результат не должен переноситься.
- В «Землекопах» после исправления ответа открывается новая задача. Пошаговый разбор сохраняет её числа, а кнопка «Самостоятельный вариант» выдаёт другой набор. Для этого маршрута дополнительной правки не потребовалось.
