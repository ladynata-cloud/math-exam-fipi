# Атанасян 7–9, задачи 842–853 о площадях

Продолжить сквозной задачник после №841. Для каждого номера ребёнок получает условие и чертёж, может записать доказательство, запросить первую подсказку, пройти обоснованные шаги и проверить новый численный пример. Рисунки используют точки и отношения из соответствующего условия. Задача №846 отмечает основание перпендикуляра квадратиком.

Сверены печатные страницы 215–216, страницы PDF 216–217 14-го издания 2023 года, ISBN 978-5-09-102538-5. Первые три авторские заготовки взяты из PR #562 и получили дополнительную практику. Следующие девять задач подготовлены по изданию. PDF остаётся у владельца. Проверки охватывают численные формулы, 320 и 1280 пикселей, запись доказательства, ошибочный/верный ответ, восстановление после перезагрузки, открытие по номеру. Данные прежних учебных карточек, их ключи и ранее проверенный пакет сохранены.

Новые уроки загружаются добавочным пакетом в обычный каталог. Если доступен только ранее выпущенный пакет, он открывается с сообщением о недоступности дополнения. Полный охват учебника ещё впереди. Откат — обратный коммит этого дополнения.
