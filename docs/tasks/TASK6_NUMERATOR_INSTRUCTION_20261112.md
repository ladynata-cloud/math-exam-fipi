# Подсказка к умножению дробей в ОГЭ №6

## Задача

Ученик видит дробь целиком и может ввести её вместо числа, которое требуется на текущем шаге. На шаге «Умножь числители» показываем пояснение «Введи только числитель.» перед полем в обеих версиях тренажёра.

- База `main` `21a3032aa8c812c2b685d36894de8bf92aff2bd5`.
- Ветка `fix/task6-numerator-instruction`.
- Уровень проверки `SMALL`.
- Запрос владельца в текущем разговоре — указать ученику, что вводить на шаге.
- Выпуск после проверок по [действующему разрешению владельца](../OWNER_RELEASE_AUTHORIZATION.md).

## Приёмка

- Пояснение видно до ввода ответа.
- Для \((3\cdot3)/(5\cdot1)\) ответ текущего шага равен 9, значение произведения равно 9/5.
- Существующие проверки банка, вычислений, ответов и сохранения прогресса проходят. Проверки исторических снимков учитывают ровно добавленное пояснение.
- Привязка навигатора обновляется для двух HTML по исходному коммиту `396efdd8670d060beec3fbe087bfb35ab7f0232a`.
