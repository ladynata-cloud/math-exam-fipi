MathExam — учебный цикл, версия 2 (кандидат)

Распакуйте весь ZIP. Откройте START.html, выберите тему. Домашние задания находятся в materials. Для ссылок на сайт нужен интернет, в самом уроке предусмотрены бумажные варианты. Не указывайте персональные данные. Ведите одну тему в одной вкладке.

Перед закрытием выгрузите резервный JSON. В версии 2 его можно восстановить: выберите соответствующую пустую тему, нажмите «Восстановить из резервного JSON». Существующая работа не заменяется автоматически. Старые записи версии 1 не удаляются и не переносятся автоматически: изменено условие геометрической самостоятельной задачи. Храните старые JSON отдельно как свидетельства прежних попыток.

При конфликте вкладок текущая работа остаётся в памяти, сохранённая запись не заменяется автоматически. Выгрузите JSON; только потом используйте кнопку загрузки сохранённой записи. Запись выполняется под эксклюзивной блокировкой Web Locks с повторной сверкой текущего значения. Если блокировки недоступны, сохранение в localStorage отключается, а экспорт JSON остаётся доступен. Старайтесь не вести одну тему в двух вкладках. Не удаляйте данные браузера до резервного копирования.

Кандидат пилота, без подтверждённой публикации и синхронизации с доской. Вход в существующие практикумы — внешняя ссылка. Свободный текст проверяет преподаватель. Сохранение в браузер зависит от разрешений; экспорт/импорт не является защищённым экзаменационным протоколом. Внешняя проверка, испытание с реальными учениками и нативный запуск с HTTP/file ещё не подтверждены.
