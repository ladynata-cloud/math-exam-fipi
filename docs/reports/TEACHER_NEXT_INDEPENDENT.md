Прочитаны все 22 новые фабрики: формулировки, выводы решений, ограничения и структура четырёх вариантов. После авторских исправлений проверка не обнаружила математических ошибок или неоднозначностей, блокирующих выпуск. Уровень остаётся базовым: небольшие числа, однотипные действия, в контрольной один дополнительный пункт. Полный годовой охват и апробация в классе не заявляются.

Отдельная воспроизводимая проверка `python3 tools/teacher-next-independent-check.py` прошла для **792 отображаемых заданий и ответов**: 576 по алгебре, 216 по вероятности. По 36 заданий на каждую из 22 тем. Скрипт не читает `task['check']`, не использует числовые параметры фабрик и не берёт из них ожидаемые значения: данные извлекаются из текста условия, опубликованный ответ разбирается отдельно. Неизвестная тема или изменившийся формат вызывает ошибку, а не пропуск проверки.

## Что проверяется независимо

- Числовые значения функций, разложения кубов, тригонометрические и логарифмические преобразования восстанавливаются из печатной формулы.
- Для дробных уравнений отдельно находятся запрещённые значения исходных знаменателей. После решения числителя они исключаются; ограничения, напечатанные в решении, сравниваются с полным множеством запретов. В частности, подтверждён случай, где единственный кандидат совпадает с запрещённым значением и решений нет.
- Квадратные текстовые задачи моделируются заново по площади, разности сторон или условию о числе. Проверяются положительность и требуемая величина — стороны либо периметр.
- Дробные, показательные и логарифмические неравенства проверяются как множества действительных решений. Учитываются строгие/нестрогие границы, изменение направления для основания между 0 и 1 и область определения логарифма.
- Для оценок выражений проверяются обе границы и знак; умножение границ применяется только к положительным величинам. Рекуррентные последовательности вычисляются последовательно, начиная с заданных начальных членов.
- Уравнение касательной проверяется двумя независимыми свойствами: прохождение через точку графика и равенство углового коэффициента значению производной. Дополнительно проверяется, что ответ действительно задаёт прямую.
- Площади вычисляются через интеграл модуля разности функций, без доверия утверждению о верхнем графике. Производная напечатанной первообразной сверяется с разностью функций.
- Частоты и дисперсии пересчитываются из чисел условия; комбинаторные задачи проверяются явным перебором произведений, перестановок и сочетаний. Геометрическая вероятность вычисляется из длин/площадей с проверкой расположения отрезков и размеров вложенных фигур.

## Чтение решений и границы проверки

Объяснения и эквивалентность вариантов проверены чтением всех новых фабрик; 792 — число автоматических сопоставлений **условие → ответ**, а не количество автоматически доказанных текстовых решений. Для решений автоматикой дополнительно охвачены ограничения дробных уравнений и первообразные площадей. Формулировка полосы теперь явно задаёт всю длину стороны, а условие изменения квадрата — сохранённую ширину и увеличенную длину. В кубических формулах используются небольшие параметры 1–5.

Постраничная вёрстка PDF, хэши файлов, соответствие конкретным изданиям, работа каталога и публикация проверяются отдельными участниками общего выпуска. Этот отчёт сам по себе не подтверждает публикацию.
