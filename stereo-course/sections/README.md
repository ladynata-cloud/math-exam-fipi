# «Сечения с нуля»

Самостоятельный курс: `/stereo-course/sections/`. Общий разбор на существующей
доске: `/trainers/sections-from-zero.html`, trainer ID `sections-from-zero`,
state schema version `1`.

## Происхождение и сохранность материала

Курс основан на переданном владельцем `Sections_Master_Course.html`, версия
`2026-10-25.3`. Подготовленная вводная редакция `Sections_From_Zero.html`, версия
`2026-11-06.1`, сохраняет все 186 идентификаторов карточек, 967 шагов построения,
81 шаг вычислений, пространственные модели, ответы и ссылки на пять комплектов
исходных материалов. В редакции сохранены 26 этапов маршрута, 24 вводные карточки,
24 переходные карточки, 12 тем практикума, 8 лабораторий и 5 контрольных наборов.
Подробные атрибуции находятся в `data/course.json` и доступны в разделе «Учителю».

По отношению к исходному Master изменены четыре поля карточек:

| Карточка | Поле | Уточнение |
| --- | --- | --- |
| `ii-self-9` | `goal` | Требуется прямая пересечения плоскостей, а не граница сечения. |
| `ii-self-7` | `goal` | То же уточнение для прямой пересечения плоскостей. |
| `ii-self-8` | `goal` | То же уточнение для прямой пересечения плоскостей. |
| `iii-self-5` | `steps[5].action` | Неоднозначная запись `a√[[frac:6\|2]]` заменена на `[[frac:a√6\|2]]`, то есть `a√6 / 2`. |

Модели и численные ответы не изменялись. Учебный маршрут начинается с названия
грани и принадлежности точек плоскости; подсказки и разобранные примеры остаются
доступны, а перенос на новый пример и объяснение на бумаге отмечаются отдельно.
Компактный вход и переход по ссылке сразу к нужной карточке относятся к интерфейсу.

## Канонические файлы и сборка

- `data/course.json` — полный исходный набор данных вводной редакции.
- `assets/app.js` и `assets/style.css` — общий интерфейс сайта и автономной версии.
- `index.html` — самостоятельный курс с поиском, маршрутом и практикой.
- `assets/board-session.js` — адаптер существующего `MathExamBoard` SDK.
- `assets/course-data.js` и `download/Sections_From_Zero.html` — результаты сборки.

Команды из корня репозитория:

```sh
python tools/sections-course-build.py
python tools/sections-course-build.py --check
```

Сборка детерминирована. Скачиваемый HTML содержит тот же JSON, CSS и JavaScript
внутри одного файла и не загружает сетевые зависимости. Самостоятельная версия
сохраняет прежние ключи прогресса `mathexam.sections.master.v1` и
`mathexam.sections.master.activities.v1`.

## Личный маршрут и результаты

Весь путь из 26 этапов показан открыто в исходном учебном порядке. Кнопка
продолжения возвращает к сохранённой карточке, ответам, построению и ракурсу.
Следующий пример выбирается с учётом незавершённых проверок; после помощи
предлагается отдельный резервный пример, когда он предусмотрен этапом.

Новые личные попытки различают ошибки, исправленные самостоятельно, и открытые
подсказки. При завершении всех выборов и предусмотренных проверок без помощи
сохраняется результат проверки выборов; последующий просмотр ответа для сравнения
его не отменяет. Это не автоматическая оценка собственного чертежа или полного
доказательства. Ручная самопроверка отображается отдельно.

Старые выполненные записи не переоцениваются. Старые пустые карточки каталога
получают новый учёт при фактическом начале работы. Личные поля
`attemptEvidenceVersion`, `mistakes`, `choiceEvidence` не входят в состояние доски.

На карте есть «Как заниматься»: три коротких показа начала, продолжения и
построения сечения. Показ запускается по кнопке, поддерживает паузу, повтор и
переход по кадрам; при уменьшении движения используются ручные кадры. Текстовые
шаги доступны отдельно. Геометрический показ использует собственный учебный куб
с треугольным сечением, а не ответ активной карточки. Просмотр не меняет работу
ученика; на общей доске показы не включены. Анимации отрисовываются локально и
работают в автономном HTML без видео, сетевых файлов и бесконечного мигания.

## Общая доска

Доска открывает все 186 карточек в режиме общего разбора. Участники видят одну
карточку, выбранный способ работы, построенные шаги, выбор плоскости и основания,
подсказки, вычисления, обратную связь, черновик, раскрытые пояснения, фильтры
каталога и одинаковый поворот модели. Ссылка `#lesson-id` задаёт начальную карточку.
Смена карточки начинает новую общую работу. Маршрут, практикум, лаборатории и
контрольные наборы доступны в самостоятельной версии.

Состояние доски хранится только в памяти. Адаптер не читает и не изменяет
`localStorage`, личный прогресс или результаты контрольных. Синхронизируется
ограниченное состояние текущей карточки, а не история всех заданий. Валидатор
проверяет точный набор полей, существующие идентификаторы, допустимые шаги,
выборы ответов, границы камеры, длины текста и размер JSON до 64 KiB. Применение
повторного состояния идемпотентно; события раскрытия пояснений после удалённого
обновления не создают обратную пересылку.

Интеграция сохраняет исходное математическое содержание. Изменения общего
интерфейса ограничены разделением хранилищ, восстановлением обратной связи при
обновлении, плотным массивом флажков самопроверки и доступностью полного
автономного скачивания.
