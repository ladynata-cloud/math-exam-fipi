Геометрия · 7–9 классы — атлас и задачи Атанасяна
==============================================

В атласе 63 тематических урока для 7–9 классов.
Каталог задачника показывает число доступных карточек.
Начальный маршрут включает 255 карточек. Сохранены 70 прежних тренажёров.
Начальный маршрут использует часть задачника; его карточки не являются
дополнительными независимыми задачами.

СТРУКТУРА (вложенность не менять):
  index.html        — главная: карта курса и прогресс
  atlas/*.html      — 63 самостоятельных тематических урока
  textbook/         — задачи и теория к учебнику с отдельными чертежами
  first-steps/      — начальный маршрут до построений включительно
  trainers/*.html   — 70 сохранённых прежних тренажёров
  teacher-atlas.html — работа учителя с файлами прогресса атласа
  assets/, data/    — редактируемые исходники атласа

АВТОНОМНЫЙ КОМПЛЕКТ:
  Скачайте ZIP целиком и распакуйте. Откройте index.html, затем нужную тему.
  Каждый файл atlas/*.html содержит собственные стили, данные и математическое
  ядро и работает без сети. В скачиваемой копии задачника и начального маршрута
  данные встроены в HTML, а общие скрипты находятся в папке _shared/.
  Отдельный geometry-course.html — оглавление; для его ссылок нужна вся папка.
  Другие курсы, кабинет и общая доска открываются на сайте и требуют сети.
  В исходной серверной версии задачник читает data/course.json по HTTP.
  Экспортированный ZIP собирается из этих исходников автоматически.

КАК ВЫЛОЖИТЬ:
  Загрузите всю папку geometry-course как есть на любой статический хостинг.
  Папка trainers/ должна лежать рядом с index.html (на уровень ниже).
  Ссылки внутри (открытие тренажёра, кнопка «к списку») — относительные, работают сами.

ПРОГРЕСС:
  Зелёные галочки хранятся в браузере ученика (localStorage), на его устройстве.
  Самостоятельная работа хранится на устройстве. Перед переносом в другой
  браузер, открытием другой локальной копии или очисткой данных скачайте файл
  прогресса через кнопку экспорта. Импортируйте файл в нужной копии курса.
  Поведение localStorage для file:// зависит от браузера: перенос файла HTML
  сам по себе не переносит сохранения. Очистка данных браузера удаляет их.

РЕДАКТИРОВАНИЕ:
  Исследования: assets/investigations.js; практика: assets/practice.js и tasks.js;
  рисунки: assets/proof-diagrams.js и task-diagrams.js; оболочка: assets/lesson.js.
  После изменения исходников HTML атласа пересобирают штатным генератором
  tools/geometry/build_site.py из полного репозитория. Старые сохранения и
  числовой смысл этапов нужно сохранять; свободное доказательство оценивает
  учитель, а не автоматическая проверка текста.

РЕЖИМ УЧИТЕЛЯ (кнопка справа вверху на главной):
  - метки типов и фильтр: Уроки / Практика / Зачёты / Построения;
  - отметь тренажёры галочкой -> внизу кнопка "Скопировать ссылки" даёт готовый
    список с прямыми URL — вставь в дневник/чат/LMS как набор на урок;
  - показываются коды тренажёров (ch4-p2-t8 и т.п.).
  Режим запоминается в этом браузере и на учеников не влияет (у них по умолчанию выкл).

СБОР ПРОГРЕССА КЛАССА (teacher.html):
  - Ученик на главной жмёт "Сдать прогресс", вводит имя -> получает короткий код,
    копирует и присылает учителю (чат/форма). Код ~80 символов, влезает в сообщение.
  - Учитель открывает teacher.html, вставляет коды (по одному в строке, можно пачкой)
    -> таблица класса: сколько пройдено у каждого, по главам, кто буксует. Экспорт CSV.
    Повторный код от ученика обновляет его строку. Данные класса хранятся в браузере учителя.
  - Необязательно: автосбор в Google-таблицу (Apps Script) — инструкция в самой teacher.html.
