# Рубин и Чулков, алгебра, 7 класс

Издательство «Баласс», 2015, ISBN 978-5-85939-921-5. Общий объём 224 страницы. На с. 221–223 сверены оглавление пяти глав, повторение и ответы. В каталоге учебника печатная страница соответствует номеру страницы PDF.

В §1.1 для №1–4 со с. 10–11, включая все 30 подпунктов, есть отдельные модели, авторские разборы, диагностика и самостоятельная попытка. Для №5–8 есть четыре отдельные таблицы: проверены все шесть печатных столбцов каждой, включая дробные и отрицательные аргументы. Следующее упражнение в этом издании — №9 на с. 11–12.
