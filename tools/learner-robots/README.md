# Роботы-ученики: деление, дроби, ОГЭ-15

Это воспроизводимые программные сценарии, а не настоящие ученики и не доказательство понятности объяснений детям. Роботы работают в новых браузерных профилях без ученических аккаунтов. Учебные страницы и данные пользователей не изменяются.

## Персонажи и проверки

| Робот | Поведение |
|---|---|
| Самостоятельный | Вычисляет ответ независимо по условию, проходит шаги без помощи. |
| Ошибающийся | Вводит неверное число, исправляет его; ошибка не должна стирать шаги или притворяться подсказкой. |
| Осторожный | Просит содержательную подсказку, продолжает решение; использование помощи должно быть различимо. |
| Смотрящий решение | Открывает ответ/шаг; показ не должен превращаться в самостоятельный зачёт. |
| Прерывающийся | Вводит черновик, обновляет страницу и возвращается к делению. |
| Повторяющий таблицу | Уходит из деления в таблицу умножения и возвращается с сохранённым шагом и черновиком. |

Дополнительно проверяются повторные нажатия, отсутствие горизонтального вылета страницы и 12 фиксированных задач кандидата ОГЭ-15. Каждое браузерное путешествие выполняется при ширине 1280 и 360 CSS px. Это не проверка физических мобильных устройств.

## Запуск

Из корня репозитория:

```sh
python tools/learner-robots/learner_robots.py --root . --math-only --out robot-evidence/math
```

Математический режим требует Python 3.11+ и Node 18+, без установки библиотек. Он независимо вычисляет 174 выражения текущего банка №6 из HTML условия и проверяет 576 задач деления точной рациональной арифметикой. Четыре записи SHA-256 в отчёте — идентификация файлов, а не дополнительные учебные тесты.

Браузерный режим требует отдельно установленный Playwright и Chromium:

```sh
python -m pip install playwright==1.55.0
python -m playwright install chromium
python tools/learner-robots/learner_robots.py --root . --out robot-evidence/journeys
```

Не отключайте политики безопасности браузера. При ERR_BLOCKED_BY_ADMINISTRATOR используйте штатный разрешённый CI-runner, а не обход ограничения.

Для проверки отдельного, неизменяемого кандидата №15:

```sh
python tools/learner-robots/learner_robots.py --root . --candidate /path/to/candidate-worktree --out robot-evidence/journeys
```

Кандидат, закреплённый в текущем workflow: PR #146, head `2069d21d96943602a03844ffb52f83d50b4700c9`. Его независимый решатель повторно используется для чтения условия и геометрического построения; ответы из генератора не используются как ответы робота. Debug API применяется для выбора прототипа и наблюдения прогресса, а не для записи правильного результата.

## Контрольный маршрут дробей

1. `/trainers/oge-basics/fraction-meaning.html`: диагностика, страница объяснения, три задания, итоговая проверка.
2. `/trainers/oge-basics/fraction-common-denominator.html`: тот же маршрут для общего знаменателя.
3. `/trainers/oge-task6-fractions.html`: три экзаменационных выражения; отдельные профили для ошибки и показа ответа.

Проверяется автономный режим страниц. Объяснение открывается и проверяется на наличие текста; робот не имитирует человеческое понимание и не утверждает, что прочёл и освоил все пояснения. Общие кабинеты, реальная синхронизация, доступность для скринридеров и работа живых учеников не входят в этот прогон.

## Отчёт и ограничения

`results.json` хранит отдельный статус каждого сценария; PNG сохраняются также при ошибках. Неудачный сценарий даёт ненулевой итоговый код, остальные продолжаются. Старые гейты №15 запускаются дополнительно и не заменяют новые проверки.

Известный предмет проверки: действующий контракт кандидата №15 допускает подсказки и затем надпись «Все шаги решены самостоятельно». Наш нормативный сценарий требует различать содержательную помощь. Его провал нужно классифицировать как разногласие педагогических контрактов, не как автоматически доказанную новую регрессию. Учебная логика в этом PR не исправляется.

Workflow имеет только `contents: read`, запускается лишь для этой тестовой ветки, не публикует сайт. Проверки старых PR #126/#129/#146 выполняются через read-only virtual merge; конфликты сохраняются в отчёт, чужие ветки не чинятся и не закрываются.
