# Макарычев, 8 класс. Квадратные корни и общая доска

Наталья разрешила завершить и опубликовать курсы с понятной самостоятельной работой, наглядностью и синхронизацией с доской. Этот выпуск переносит проверенные 242 номера главы II из PR #482 на действующий курс, включая современные правила записи числовых ответов и распознавание противоположных корней. Сохраняются 722 прежних карточки и адреса их подпунктов.

Самостоятельный режим работает в браузере ученика. Отдельный вход доски использует тот же банк и тот же движок. В комнате передаются маршрут, подсказки, введённые и принятые шаги, заметки, раскрытые разделы и параметры модели. Работа в комнате оценивается с помощью.

## Приёмка

Проверить независимые математические ответы, повторное открытие личного черновика, запись ответа вида ±a и новый адрес доски. Открыть одну карточку в двух экземплярах, проверить передачу записи, принятого шага и параметра модели, затем подключить третьего участника. Проверить страницу и HTML из автономного комплекта. Для покрытия всех 1340 номеров потребуется отдельная проверка оставшихся глав по тому же изданию 2024 года.

Уровень проверки HIGH. Откат выполняется обычной отменой опубликованного изменения с сохранением истории.
