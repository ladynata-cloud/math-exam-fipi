# Второй модуль: данные, графики и логика

Дата: 2026-10-01. Задача `EGE_BAZA_COURSE_05_DATA`, зависимая от Draft #150.
Рабочий адрес: `/trainers/ege-baza/data-course/`. Это прототип второго модуля,
а не готовность всего курса к выпуску. Публикация остаётся общей после подготовки
всех обязательных материалов и отдельного разрешения владельца.

## Учебное содержание

| Навык | Модель и действия | Связь с базовым ЕГЭ |
| --- | --- | --- |
| Таблицы и диаграммы | Изменить количество, сравнить столбцы, найти сумму, размах, учесть тысячи | Позиция 3 |
| Вероятность | Менять число красных шаров среди десяти, считать долю и дополнение до 1 | Позиция 5 |
| График рассказывает | Читать значения и изменения, различать высоту и наклон, считать производную по касательной | Позиция 7 |
| Логические выводы | Сравнивать, проверять направление условия, искать контрпример | Позиция 8 |

На каждый навык приходится четыре тренировочные задачи и по две задачи в
стартовой, итоговой и повторной проверке: всего 40 авторских заданий.
Тексты четырёх наборов разделены. Проверки не показывают решения до завершения.
Графики и таблицы сохраняются в разборе вместе с условиями. Это авторский банк;
он не выдаётся за задания официального открытого банка ФИПИ.

Используется сохранённый проект демоверсии, спецификации и кодификатора ФИПИ
2027. Диагностика основных действий не исчерпывает все подтипы этих позиций.
В частности, соответствия графиков и производных ещё нужно расширять, а новые
формы после неудачной проверки — добавить вместе с историей попыток.

## Прохождение и хранение

Использован уже существующий цикл первого модуля: объяснение → модель →
практика → отдельная проверка → повторение не раньше чем через сутки.
Подсказки, просмотр решения и исправления учитываются; обращение к обучению
во время проверки не выдаётся за самостоятельное подтверждение навыка.
В локальной версии время зависит от часов устройства.

Ключ второго модуля — `mathexam.ege-baza.data.v1`, структура состояния `v:1`.
Первый модуль и его банк в этой задаче не изменялись. Сброс и восстановление
действуют только на выбранный модуль. Общего журнала группы пока нет.

Навигатор теперь показывает десять доступных уроков из 32 запланированных.
На экранах «Сегодня», «Мой прогресс» и «Резервная копия» есть выбор модуля.
Показатели не смешиваются: у первого 24 тренировочные задачи и шесть навыков,
у второго 16 задач и четыре навыка. Старые адреса без выбора открывают первый.
Нет общего процента готовности к ЕГЭ или фиктивного прогресса будущих модулей.

`course-definitions.js` перечисляет только реализованные модули с фиксированными
ключами. `course-state.js` и `backup.js` создают отдельный адаптер для каждого.
`data-reference.js` — проверяемое зеркало ID/ответов канонического `content.js`.
Графика вынесена в `visuals.js`; используются точные SVG и HTML-таблицы.
Узкие экраны могут прокручивать график внутри области, сохраняя читаемость подписей.

Файл резервной копии версии 1 содержит ровно один выбранный модуль. Копия m01
по-прежнему совместима; копия другого модуля отклоняется до записи. Прежде чем
восстанавливать, ученик видит сравнение и явно подтверждает замену. Защита от
устаревшей записи остаётся проверкой актуальности, не межвкладочной транзакцией.

## Проверки автора и открытые условия выпуска

```sh
node tools/ege-baza-data.test.mjs
node tools/ege-baza-data.dom.mjs
node tools/ege-baza-multi-module.dom.mjs
node tools/ege-baza-navigator.test.mjs
node tools/ege-baza-backup.test.mjs
node tools/ege-baza-foundation.test.mjs
node tools/ege-baza-foundation.dom.mjs
node tools/ege-baza-2027-gate.mjs
python tools/build-ege-baza-preview.py /absolute/output/ege-baza-two-modules.zip
```

DOM-проверкам нужен jsdom 26.1 через NODE_PATH, установленный вне репозитория.
Результат: 234 проверки математики, стимулов, зеркала и изоляции; 78 DOM-проверок
учебного цикла; 26 проверок выбора модуля и импорта через FileReader.
Регрессия: 242 проверки навигатора, 69 резервных копий, 81 DOM-проверка первого
модуля, 60 его независимо вычисленных ответов и исходный gate ЕГЭ 2027.
Пакет просмотра содержит 15 файлов; целостность ZIP и внутренние ссылки проверены.

Реальный браузерный gate **не выполнен**: в текущей среде ранее подтверждён
запрет socket при запуске Chromium. DOM-тесты не доказывают правильность
визуального отображения, клавиатуры и настоящего скачивания/загрузки файлов.
В разрешённой среде с Playwright надо выполнить:

```sh
node tools/ege-baza-data.browser.mjs
node tools/ege-baza-navigator.browser.mjs
node tools/ege-baza-backup.browser.mjs
```

`NAVIGATOR_CHROMIUM_PATH` задаёт установленный Chromium;
`DATA_SCREENSHOTS_DIR` — место снимков 360/1280 для визуальной проверки.
Новый gate включает модели, клавиатуру, отсутствие переполнения страницы,
настоящий JSON-download и восстановление во втором браузерном контексте.

Уровень HIGH: нужны независимое/внешнее ревью точного head и выпускные проверки.
Проверки автора не считаются таким ревью. Исключение из политики не запрашивается.

## Откат и продолжение

Откатить только дельту этой задачи к Draft #150. m01 сохраняет прежний ключ,
банк и формат; новый ключ m02 остаётся на устройстве для совместимой будущей
сборки, не удаляется автоматически. Откат кода не возвращает прежние ответы.

Следующий содержательный блок — выражения и уравнения с картой подтипов и
повторным использованием существующих тренажёров. Дополнительные проверочные
формы, комплект преподавателя и общий путь мини-группы остаются условиями
готовности целого курса. Текущий прототип можно просматривать, но он не заменяет
законченный продукт для набора учеников.
