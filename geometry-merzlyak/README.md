# Мерзляк 7–9

Мерзляк–Полонский–Якир: 7 класс — 2015, 8 — 2013, 9 — 2022. Углубление: Мерзляк–Поляков, 2019/2022.

84 учебных узла и 149 пунктов карты: 25/30/29 узлов по классам, 68 основных и 16 углублённых. Авторские уроки и задачи, не полный задачник. Письменные доказательства оценивает преподаватель. Прогресс хранится локально, отдельно от других курсов; доступен экспорт и импорт.

## Исследование и продолжение работы

Новый урок начинает тематическое исследование из `assets/investigations.js`: вопрос, первый прогноз (включая «Пока не знаю»), изменение модели, собственное наблюдение и сопоставление с выводом. Все 84 узла имеют явную карту вопроса, действия, наблюдения, вывода и границ модели. Для вывода нужны минимум два разных положения и запись ученика. Измерение не заменяет доказательство; исследование не добавляет числового самостоятельного зачёта.

Основной маршрут: **Исследовать → Объяснить → Доказать → Решить с опорой → Самостоятельно → Своими словами**. Старые числовые этапы 0–5 сохраняют значение при восстановлении. Новое исследование хранится отдельно (`screen: "research"`, `research`, `routeVersion: 2`). Сохранённое прежнее построение доступно через раздел «Прежнее построение и записи». Старые условия, задачи, источники и доказательства остаются в `data/course.json`, `data/proofs.json` и прежних модулях.

Первый прогноз фиксируется; записи разных случаев, текущий черновик, старый рисунок и свободный чертёж к доказательству сохраняются раздельно. Если другую версию той же темы записала соседняя вкладка или импорт, устаревшая вкладка прекращает запись и предлагает скачать обе версии или открыть свежую. Работа в разных темах объединяется. Если сохранение браузера недоступно, текущая работа доступна для скачивания.

### Восстановление при одновременной записи

Совместимый снимок остаётся в `mathExamGeometry.merzlyak.v1`. Перед его обновлением браузер сохраняет отдельную ревизию под ключом `mathExamGeometry.merzlyak.v1.recovery.<revision>`. Формат записи: `{version: 1, id, unit, kind, parent, lineage, clock, state}`; `kind` — `snapshot` или `conflict`. Ревизия обозначается служебным полем `workRevision`. Экспорт v1 включает прежние `units` и необязательный массив `recovery`; импорт переносит обе ветви конфликта.

Разные темы объединяются из ревизий. Две записи с одним родителем сохраняются раздельно даже при одинаковом времени. Известные предки своей сохранённой ветви уплотняются; первоначальные развилки и конфликтные версии остаются. Поля ограничены прежней схемой; история причинности — 128 ревизий, журнал — 2048 записей. При отказе или заполнении хранилища прежние записи не удаляются, а последнюю работу можно скачать. Несовпадающий импорт с уже занятым идентификатором отклоняется до изменения данных.

При конфликте помощи и ответа к одному условию неподтверждённый новый самостоятельный результат относится к работе с помощью или к знакомому повтору. Ранее подтверждённые счётчики сохраняются. Исходные ветви доступны отдельно, включая их прежние числовые поля. Обычное раскрытие помощи после уже заработанного результата не отнимает этот результат.

## Сборка и автономное открытие

Для воспроизводимой сборки только 84 atlas-страниц:

```sh
python tools/merzlyak/build.py --lessons-only
```

Этот режим сохраняет `index.html`, `teacher.html` и README. Канонические адреса, навигационные подключения и полная встроенная конфигурация урока остаются в atlas. Схема средней линии в уроке 8.7 встраивается как точная копия существующего `geometry-course/assets/midline-diagram.js`; общий исходник не изменяется.

Для автономного запуска сохраняйте **всю папку `geometry-merzlyak`**, затем открывайте `index.html` или atlas-страницу. Модели исследования, прежние задания, построения и схема 8.7 работают из локальной папки. Исходные учебники в публикацию не входят.

## Проверки

```sh
node tools/merzlyak/check.cjs
node tools/merzlyak/trainer-feedback.test.cjs
node tools/merzlyak/similarity.test.cjs
node tools/merzlyak-learning-path.test.cjs
node tools/merzlyak/investigations.test.cjs
node tools/merzlyak/harmonization.test.cjs
node tools/merzlyak/browser.cjs
node tools/merzlyak-learning-path.browser.cjs
node tools/merzlyak/harmonization.browser.cjs
```

`harmonization.test.cjs` проверяет неизменность прежнего банка, точную генерацию, все 84 новых входа, все 504 сочетания старой темы/стадии, чертежи, доказательства, восстановление, импорт и конкурентную запись. `harmonization.browser.cjs` проходит все 84 исследования в настоящем браузере, все 84 автономные страницы без соседних папок, две вкладки, карту, экспорт/импорт и восстановление рисунков. Изображения и машинный отчёт сохраняются в `artifacts/merzlyak-h27/`; CI запускает эти проверки в workflow `merzlyak-learning-path.yml`.
