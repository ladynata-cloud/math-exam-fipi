# Разборы первой части Петерсона и самостоятельный практикум

Номера соответствуют первой части учебника Г. В. Дорофеева и Л. Г. Петерсон, 6 класс, БИНОМ, 2019. Материалы для подбора заданий и расчётов перенесены из #367. Рабочая тетрадь дополняет тематический курс из #469 и отдельный маршрут с задачами на движение и проценты. У каждого курса сохраняется свой журнал.

| Упражнения | Учебные записи |
| --- | ---: |
| № 1–175 | 884 |
| № 176–339 | 675 |
| № 340–497 | 608 |
| Всего | 2167 |

Число записей учитывает отдельные ячейки таблиц и варианты ответа. Для 431 выражения, 795 числовых заданий и 81 вопроса с выбором работает автоматическая проверка. В 860 письменных заданиях ученик сохраняет объяснение для преподавателя. Список содержит все 497 номеров.

Основное условие полностью приведено для 467 записей. Для остальных 1700 указан номер и печатная страница. Эти разделы рассчитаны на работу по своему экземпляру учебника. В 60 номерах полностью доступны все основные условия, в 28 — часть условий, ещё в 409 предлагается свериться с книгой. Собственный PDF ученик может открыть локально. Опубликованные материалы содержат авторские математические схемы, ссылки на страницы и разборы. Изображения страниц в раздачу не входят.

Самостоятельно можно вычислить 431 выражение либо выбрать авторский пример с собственным условием. Для 755 записей предложен конкретный отрабатываемый навык, ещё для 981 — упражнение по теме. У 576 записей в диапазоне № 340–497, ранее зависевших от изображения страницы, есть адресный пример с новым условием. Правильный ответ в нём сохраняется отдельно от ответа на номер учебника. Общий практикум включает 37 навыков, по три уровня. Для повторения открывается новый вариант.

№ 185(4) проверяется по значению 40% от 1/2, то есть 1/5. В № 186(1) сохранён напечатанный знак минус, ответ равен 20. В № 240 предложена авторская схема углов и обсуждение точности измерения. В № 293 квадрат и шестиконечная звезда построены геометрически. В № 497 отдельно разбираются 6200 рублей при простых процентах и 6298,56 при ежегодной капитализации.

Проверки охватывают все номера, письменную работу, 431 дерево вычислений, 123 опорных ответа, 3330 вариантов по 37 навыкам и 576 адресных примеров с тремя вариантами каждый. Проверяются перенос старых записей, работа с первой ошибкой, помощь и возврат к исходной задаче. Уровень проверки HIGH.
