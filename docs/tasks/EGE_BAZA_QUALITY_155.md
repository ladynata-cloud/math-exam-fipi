# Дополнение #155: адресная помощь и облачные проверки

Владелец 02.10.2026 после публикации #160 запросила виртуальных учеников, учителей и тестировщиков, которые регулярно проверяют курс, и переходы в прежние тренажёры при характерных ошибках. Это продолжение текущей работы над качеством курса. База: `a325f74909fd3ba322089702a8954bcfd300e5cb`.

## Состав

- Детерминированные рекомендации по ошибке/теме в новом маршруте и тренажёре землекопов; предположение, а не психологическая диагностика.
- Сохранённый шаг → прежний тренажёр → явный возврат. Старые результаты и ключи не изменяются.
- Ограниченный GitHub Actions прогон при изменении курса и один раз в сутки: математические ключи («учитель»), учебные сценарии («ученик»), браузер/данные/ссылки («тестировщик»).
- Эти роли — автоматические симуляции. Не заявлять опыт реальных учеников или свободную педагогическую экспертизу ИИ. Не использовать API языковых моделей, не создавать бесконечные процессы, не менять настройки аккаунта или платные тарифы.
- Только чтение исходников в проверках; отчёт — в Actions Summary и артефактах. Без автоматического исправления сайта или рассылок третьим лицам.

## Проверки и выпуск

Проверить характерные ошибки, точные ссылки, возврат на тот же шаг, сохранение черновика и отсутствие ложного зачёта. Проверить защиту returnTo от внешнего адреса. Прогнать три роли локально, затем фактический облачный запуск. До облачного PASS не утверждать, что облачные проверки работают. Публикация продолжает действующее разрешение владельца для #155; глобальные правила и защиту ветки не менять. Новое явное поручение владельца о регулярных проверках определяет этот ограниченный график, отдельные ChatGPT-автоматизации не создаются.
