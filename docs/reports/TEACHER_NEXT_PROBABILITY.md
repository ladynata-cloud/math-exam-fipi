## Проверка

- Все 216 отображаемых ответов пересчитаны из текста условий отдельным
  проверяющим кодом, без чтения `check` и без использования параметров
  фабрик. Комбинаторные задачи проверены полным перебором упорядоченных
  и неупорядоченных выборок; дисперсии — по фактическим числовым наборам;
  частоты и геометрические вероятности — по данным условий.
- У каждого из шести комплектов четыре различных набора условий для каждого
  типа работы, одинаковая последовательность баллов. В контрольных изменены
  числа относительно одноимённых вариантов самостоятельной.
- Прочитаны все шаблоны условий, ответов и решений; проверены смысл
  равномерного выбора, деление на n при дисперсии данных и отличие частоты
  от теоретической вероятности. Площадь полосы следует из явно указанной
  полной длины стороны. Во всех вероятностных задачах результаты лежат
  в [0;1].
- Устранены согласование числительных и неоднозначность ширины полосы.
- Все задания прежних восьми комплектов совпадают с опубликованным банком.
