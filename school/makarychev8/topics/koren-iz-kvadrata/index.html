Сначала возведи −5 в квадрат, затем возьми арифметический квадратный корень.

Посмотреть наглядный разбор
Кадр 1 / 5
  1. x = −5: x² = 25.
  2. √25 = 5: корень неотрицателен.
  3. x = 0: √0 = 0.
  4. x = 5: √25 = 5.
  5. Для любого действительного x: √(x²) = |x|.
