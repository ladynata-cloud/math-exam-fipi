## Содержание

Добавить два авторских семейства заданий с устойчивыми ID, по 240 условий на семейство. В задачах о грибах ученик ищет группу из одного вида, находит две верхние границы и сверяет их сумму с общим числом грибов. В задачах о вазах он проверяет крайние места, сравнивает сумму двух групп с целым, выбирает порядок и проверяет найденные количества по исходным условиям.

Для всех семи типов №21 показать карту проверяемых шагов рядом с задачей. Она ведёт к первому незавершённому шагу текущего условия. Открытие карты учитывается как помощь. Счётчик самостоятельных решений использует действующее правило для нового условия и первой попытки. Учебные задания доступны на карте №21 и в каталоге тренажёров доски. Состав экзамена и диагностики сохраняется, чтобы их действующие условия по seed не изменились.

## Проверка

- Сверить по всем 480 условиям существование и единственность решения. Для ваз перебрать все шесть порядков и целые количества роз, для грибов перебрать разбиения общего количества на два вида.
- Проверить конкретные подсказки, варианты ответов на промежуточных шагах, сохранение черновика и сохранение позиции при перезагрузке. Проверить новый самостоятельный ответ после разбора.
- Прогнать действующие математические, DOM- и браузерные проверки ЕГЭ, включая мобильную ширину 320 пикселей. Отдельно проверить отсутствие карт в экзаменационном и управляемом режимах.
- После зелёного CI сверить актуальные base/head, выпустить через GitHub Pages и проверить публичные страницы №21.
- Внешняя консультация не выполнялась. Действует разрешение владельца на выпуск после внутренних проверок.
