Сверка страницы означает начало темы в печатном издании. Например, у Мерзляка §§19–24 начинаются на с. 157, 164, 172, 182, 188, 197. HTML-распознавание другой пагинации сайта-источника давало иные номера. Использованы номера из проверенного файла. Три карточки теперь дают 87 тематических входов. Было 36. Совпадение темы подтверждает доступность указанного навыка. Полный разбор каждого упражнения и каждого случая параграфа проверка не устанавливает.

## Поведение и проверка

У тематических упражнений мастерской сохраняются штатные модель, шаги и практика. Для заданий с вариантами, например медианы или размаха, выбран конкретный разбор соответствующего типа. В таблице Мерзляка открываются подходящие занятия по алгебре 8 или по базовым навыкам с пояснением для ученика о тематическом заимствовании. Для 25 связей с профильным курсом есть отдельный вход в зарегистрированную зеркальную версию того же урока по вероятности. Остальные кнопки открывают соответствующую авторскую практику. Охват синхронизацией указан только для подтверждённых ссылок.

`node tools/verified-book-routes.test.cjs` с jsdom проверяет распечатанную пагинацию, отображение всех карточек, существование урока или модели, точность маршрута и наличие зеркальной версии в реестре. Существующие независимые проверки — tools/textbook-secondary.test.cjs, tools/textbook-core.test.cjs и tools/profile-probability.test.cjs. Расширение не меняет схему сохранения, файлы источников, прогресс прежних уроков и сервер. Для отката можно убрать новую проекцию карточек, сохранив прежний реестр источников.
