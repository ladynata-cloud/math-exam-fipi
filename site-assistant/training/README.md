# Подготовленные материалы трёх помощников

90 авторских диалогов: по 30 для MathExam, «Узла тоски по миру» и «Каббалы и Таро». В каждом две реплики посетителя и два ответа. Подготовлены также 42 предметных контрольных ситуации и 6 отдельных проверок выбора сайта. Обучение модели и вызовы внешних API не выполняются этими файлами и скриптами.

## Состав

- `train-math.jsonl`, `train-reader.jsonl`, `train-tarot.jsonl`: UTF-8, один объект `messages` на строку, без служебных полей внутри учебного примера.
- `provenance.jsonl`: постоянный ID, номер строки, семейство ситуации, источник, репозиторий, ревизия, относительные пути и идентификаторы записей.
- `provenance-sources.json`: исторические файлы прочитаны из названных Git-объектов; записаны Git blob ID и SHA-256. Это подтверждение происхождения примеров, а не заявление, что нынешний runtime равен старой версии.
- `source-pins.json`: версии текущих снимков и их статус публикации. `supplemental-sources.json`: дополнительные страницы третьего сайта, которые не входят в его маленький runtime-каталог.
- `roles/`: инструкции ролей для будущего испытания. В контрольных входах роль и доступный контекст уже приложены; эталоны в них не подставляются.
- `evaluation/`: отдельные входы, рубрики, сопоставление с возможностями нынешнего сервера и инструкция оценки. Подробнее: [evaluation/README.md](evaluation/README.md).
- `routing-holdout.jsonl`: шесть проверок границ сайтов. `expected_active_site` означает сайт текущей беседы; `other_site` — предложение посетителю перейти самостоятельно, без пересылки истории.
- `manifest.json`: точные числа и контрольные суммы данных, знаний и инструментов.
- [DATASET_CARD.md](DATASET_CARD.md): охват и ограничения. [HANDOFF.md](HANDOFF.md): порядок передачи и будущего эксперимента.

## Проверка и сборка пакета

Из корня MathExam или из `offline-toolkit/` внутри готового пакета, с Node.js 22 или новее:

```sh
npm --prefix site-assistant test
npm --prefix site-assistant run training:check
npm --prefix site-assistant run training:prepare -- --output prepared/handoff-v1
```

Установка npm-зависимостей и доступ в интернет для этих команд не нужны. Выходной путь отсчитывается от `site-assistant/`. Каталог `prepared/` не включается в Git и в повторную сборку пакета. Уже существующий каталог не перезаписывается; для новой версии укажите новое имя.

Сборка выдаёт `upload-training/`, `evaluation-inputs/`, `review-only/`, `knowledge/`, самостоятельный `offline-toolkit/` и общий `bundle-manifest.json`. Для будущего обучения берут **только выбранные train-файлы из `upload-training/`**, а не весь архив.

Если редактор меняет источник или пример, он сначала проверяет изменение, обновляет соответствующие сведения о происхождении и выполняет:

```sh
npm --prefix site-assistant run training:manifest
npm --prefix site-assistant test
npm --prefix site-assistant run training:check
```

Команда manifest не утверждает содержание автоматически. Изменённая ревизия должна присутствовать в проверенном inventory; изменённый runtime-снимок — соответствовать обновлённым source-pins. Нормализация ловит буквальные совпадения вопросов между обучением и проверкой, но не доказывает отсутствие смысловых парафразов. Для этого нужен редакторский просмотр.

## Честная исходная точка

```sh
npm --prefix site-assistant run evaluation:baseline -- --output prepared/offline-baseline-v1
npm --prefix site-assistant run evaluation:score -- --predictions prepared/offline-baseline-v1/predictions.jsonl --kind runtime --label offline-rules --output prepared/offline-baseline-v1/report.json
```

Это ответы действующих программных правил, не результаты языковой модели. Нынешняя предметная математическая помощь ограничена делением; остальные математические сценарии помечаются `unsupported`, а не заполняются выдуманными ответами. У runtime полный локальный каталог, у контрольного модельного запроса только явно приложенный контекст. Поэтому runtime служит описанием текущих возможностей; контролируемое сравнение моделей проводится отдельно на одинаковых `evaluation/inputs.jsonl`.

Отчёт разделяет автоматические флаги и ручную смысловую оценку. Даже при всех успешных автоматических проверках `qualityVerdict` остаётся `not_established`, пока не проведён содержательный анализ. Правильный формат и разрешённая ссылка не доказывают правильность объяснения.

## Происхождение и пределы

Реплики синтетические, не взяты из переписки посетителей. Числовые условия составлены для упражнения; ссылка на тренажёр подтверждает маршрут и способ работы, а не присутствие именно этих чисел на странице. Литературные ответы и трактовки символов — учебные формулировки, не цитаты писателя или исторического автора.

Контрольные задания лежат в открытом репозитории и предназначены для редакционно отделённого пилота. После использования их для исправления поведения они становятся регрессиями. Новое итоговое сравнение требует свежих вопросов. Ни 90 диалогов, ни этот контрольный набор не покрывают все темы трёх сайтов и не измеряют образовательный эффект на детях.
