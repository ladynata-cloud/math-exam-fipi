# Погорелов 7–9

Погорелов, Геометрия 7–9, 11-е стереотипное издание, 2022.

88 учебных узла и 136 пунктов карты. Авторские уроки и задачи, не полный задачник. Письменные доказательства оценивает преподаватель. Прогресс хранится локально, отдельно от других курсов; доступен экспорт и импорт.

Сборка: `python tools/pogorelov/build.py`. Для автономного запуска сохраняйте всю папку курса. Исходные учебники в публикацию не входят.
