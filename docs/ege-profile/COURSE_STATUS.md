# Статус курса профильной математики ЕГЭ

Phase A создаёт технический фундамент постоянных URL. Курс остаётся beta и закрыт от индексации.

## Фактическое состояние

| Линия | Статус | Действие Phase A |
| --- | --- | --- |
| 1. Планиметрия | Доступен | Переиспользуются обучающий тренажёр и генератор |
| 2. Векторы | Доступен | Переиспользуются тренажёр, PDF-домашняя работа и версия для занятия/доски |
| 3. Стереометрия | Заблокирован до проверки происхождения | Активная ссылка не публикуется |
| 4–15 | Тренажёр готовится | Зарезервированы честные страницы без фиктивных CTA |
| 16. Финансовая математика | Материалы собраны частично | Единый вход к трём существующим материалам; полный аудит ещё не выполнен |
| 17–19 | Тренажёр готовится | Зарезервированы честные страницы без фиктивных CTA |

В книжном ZIP обнаружены 25 Markdown-файлов и 6 Python-скриптов проверки, но 0 HTML, 0 CSS и 0 JavaScript-файлов веб-курса. Архив книги является источником требований, а не готовым веб-пакетом.

После учёта найденных активов линий 1–3 и финансовых материалов остаётся 17 уникальных underlying-модулей содержания. Актив линии 3 не уменьшает provenance-блокер и не получает публичного продвижения до Phase B.

## Известные расхождения

- В книге конфликтуют старые пути expert.html и trainers/expert.html. Постоянный сервисный адрес зарезервирован как /ege-profile/expert/, но в Phase A физическая страница не создаётся.
- README книги ошибочно предлагает сверять методы задания 18 с inequalities.html. Неравенства относятся к линии 15; линия 18 должна сверяться с параметрическими материалами.
- Старые рабочие имена книги не подтверждают наличие одноимённых веб-файлов.
- QR-коды запрещены до полного production gate.

## Discovery

Phase A намеренно не меняет главную, каталог, sitemap, board manifest или server registry. Все новые HTML содержат noindex, nofollow.
