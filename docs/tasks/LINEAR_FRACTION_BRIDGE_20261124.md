## Pedagogical design and evidence
Consultation: Fable v4 questions 1,2,6,7,12 and previous series recommendations. The file excerpts call for separated hypotheses/evidence and a reversible path from fractions to equations and back to a possible gap, followed by new transfer. Fable reviewed a supplied snapshot, not this exact code; this is implementation of selected advice, not a provider verdict.
- Eight original equations x/d+b=c with positive integer x, and eight word-transfer conditions with distinct parameters and representations. Check numerical answer, invite written reasoning and substitution on paper, do not grade free prose.
- Three separate possible-remediation probes per pair: rebuilding the whole from a unit fraction, inverse subtraction, equal operation on both sides. They have independent numbers, no automatic diagnosis. After the fraction probe a simple model lets the learner assemble equal parts before showing the complete numerical relation.
- Help is only available after an initial answer or explicit unknown. Opening a probe records help for that original problem; resource links use existing public stable IDs and open separately. The exact original condition and draft remain; returning does not create a new first attempt. Only one submitted response to each probe, at most five original attempts, one transfer submission. A new pair is distinct; no silent repetition after the finite bank.
