PDF содержит 352 страницы, SHA-256 `3673e0c373ede390ba966c168beb2ffef1aed709cb3b33268729052adfd884fa`. Печатные с. 168–169 повторно отсканированы на страницах PDF 169–170. Для всех 49 нумерованных параграфов и вводного повторения сверены точные начальные страницы. У повторения отдельная нумерация 1–123. Сделаны 23 разбора №1–7 по печатной с. 4 (страница PDF 3). У №2 одна задача с четырьмя утверждениями, у №5 два доказательства. В каждой из остальных пяти задач четыре части. В самостоятельной работе ребёнок применяет признаки числовых множеств, ищет контрпример к включению, проверяет делимость, подбирает парные множители, выносит общую степень и определяет остаток по младшим разрядам. Для каждого номера есть отдельный адрес занятия и совместной доски.

Учебник 2013 года относится к другому изданию. Например, числовая окружность в нём начинается с §4; в этом задачнике ей отведён §11 (печатная с. 80). Индивидуальные страницы §§1–49 пока ведут к заданиям в книге. Следующие авторские разборы в вводном разделе начинаются с №8.
