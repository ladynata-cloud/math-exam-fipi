# Девять открытых карточек для учёбы и чтения

Подборка от 20 ноября 2026 года для MathExam и «Узла тоски по миру».

## Что внутри

Пять математических карточек и четыре читательские. Это подготовленные
учебные ситуации, а не переписка учеников. В каждой карточке шесть ветвей
разговора, по четыре последовательные подсказки и вопрос для проверки
понимания. Файлы сохранены в исходном публичном JSON-формате.

| Карточка | Условие или текст |
| --- | --- |
| `kb-math-decimal_divide-d2` | 11,1 : 0,4 |
| `kb-math-fraction_add-d1` | 1/6 + 2/6 |
| `kb-math-inequality-d4` | −5x + 12 ≤ −3 |
| `kb-math-quadratic-d3` | x² + 2x − 24 = 0 |
| `kb-math-vector-d1` | A(4; 5), B(12; 20), координаты вектора AB |
| `kb-reader-student-opening-before` | Первое предложение «Студента» А. П. Чехова |
| `kb-reader-vorona-full-during` | Начало «Вороны и Лисицы» И. А. Крылова |
| `kb-reader-doctor-opening-after` | Выбранное начало «Чудесного доктора» А. И. Куприна |
| `kb-reader-shinel-opening-after` | Выбранное начало «Шинели» Н. В. Гоголя |

Файл `public/retrieval_manifest.json` перечисляет девять карточек, имена
файлов и их SHA-256. Пути внутри manifest указаны относительно каталога
`public/`. Карточки в ZIP и на странице материалов совпадают побайтово.

## Как использовать на занятии

1. Прочитайте условие (`anchor_text`) и цель (`learning_goal`).
2. Дайте ученику или читателю сделать первую попытку.
3. Найдите подходящую ситуацию в `branches`. Поле `trigger` описывает
   реплику, а `cause_hypothesis` — лишь возможную причину затруднения. Это
   основание для уточняющего вопроса, не диагноз.
4. Предлагайте подсказки из `hints` по одной, дожидаясь действия после каждой.
5. В конце задайте `understanding_check.question` и попросите обоснование.

Математические карточки привязаны к указанным числам. При переносе на другое
условие проверьте каждую подсказку заново. Они не являются универсальным
решателем и не подключены ко всем тренажёрам MathExam.

Для литературной карточки сначала сверяйте `read_mode` и `source_scope`.
Материал относится только к названному объёму текста. Ссылки `links` и
сведения `quotes` помогают вернуться к первоисточнику. Новые события и
цитаты за пределами этого фрагмента автоматически не подтверждаются.

## Границы комплекта

- В ZIP входят только эта инструкция, девять публичных JSON-карточек и
  исходный публичный manifest.
- Закрытый набор эталонных ответов и критериев оценки, а также записи личных
  разговоров не включены.
- Архив не запускает API, не требует ключа, не подключает внешнюю модель и
  не меняет настройки сайта.
- Карточки сами по себе не являются дообученной моделью. Проверка структуры
  и контрольных сумм не измеряет эффективность обучения на реальных занятиях.
