## Объём

Восстановить 101 тематический комплект из незавершённой рабочей копии. В каждом самостоятельная (4 задания) и контрольная (5 заданий), обе по 4 варианта, отдельные ответы/решения/критерии. 404 PDF, 1616 страниц; ZIP каждого комплекта и общий архив. Каталог по классу, учебнику и теме. Дополнительные привязки допускаются только по прочитанному оглавлению конкретного издания; наличие базовой темы не означает полный годовой комплект.

Приложенные издательские PDF служат для сверки формата и не публикуются. Время 15/40 минут — ориентир для базовой работы, без апробации в классе. Не заявляем полного покрытия всех тем/углублённых разделов всех книг. Не меняем тренажёры, кабинеты и сохранённые данные.

## Приёмка

- Независимое чтение арифметики, алгебры, вероятности и геометрии; пересчёт ответов.
- Четыре разных набора условий на каждую самостоятельную и контрольную; равная структура и баллы.
- PDF открываются, четыре страницы/варианта, корректные символы, границы текста, место для решения, сетки для построений.
- Проверенные SHA-256 каждого PDF и совпадение содержимого ZIP.
- Класс учитывает выбранный учебник, включая отличия Погорелова/Тюрина.
- Browser CI: 320/390/1280, все учебники и их сочетания с классами, поиск/сброс/пустое состояние, загрузка PDF/ZIP.
- `pedagogam-textbook-pdfs-check.py`, `pedagogam-materials.test.py`, sitemap/SEO, `git diff --check`, relevant CI.

## Риски и возврат

Главные риски — ошибки содержания и привязки издания, неверное ожидание полноты или длительности. Границы подборки указаны в каталоге, проверка содержания и PDF выполнена отдельно. Возврат: обычный revert коммита этого выпуска, сохраняя другие изменения main; пользовательские данные не затрагиваются.

Внешний аудит и апробация на учениках не проводились. Финальный коммит, CI, merge, Pages и проверка опубликованных байтов фиксируются в PR/отчёте; эта спецификация не является доказательством публикации.
