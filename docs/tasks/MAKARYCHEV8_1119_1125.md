# Макарычев, 8 класс. График прямой и алгебраическое повторение

Базовый учебник, 2024, ISBN 978-5-09-116445-9, §14, п. 44, с. 251. Проверены рис. 69 и все подпункты №1119–1125. Отдельный блок завершает порядковые номера п. 44.

| Номера | Содержание |
| --- | --- |
| 1119, 1120 | Проверка четырёх утверждений по рисунку и самостоятельное решение двойного неравенства с включёнными концами. |
| 1121, 1122 | Открытые четверти при трёх знаках наклона и пять собственных построений. При изменении одной координаты коэффициентов прямая перестраивается. |
| 1123 | Четыре уравнения. Ученик проверяет нулевой корень, оба противоположных корня, дробный корень и отсутствие действительных решений. |
| 1124 | Для трёх формул ученик сравнивает значения при 2 и −2 и проверяет выбранные им противоположные аргументы. |
| 1125 | Три многочлена. Принимаются перестановки множителей, разложения с переменной без скобок и степени повторяющихся множителей. Проверяется математическое равенство и полнота разложения. |

20 карточек, 52 шага. Повтор меняет коэффициенты, ограничения на положение прямой и исходные аргументы. Математические проверки — test-line-position.cjs, браузерные — test-browser-line-position.cjs.
