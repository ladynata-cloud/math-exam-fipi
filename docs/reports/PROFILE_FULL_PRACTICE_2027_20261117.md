# Сверка тренировочного варианта ЕГЭ 2027

## Первая часть

Двенадцать фиксированных задач с кратким ответом. За каждый верный ответ начисляется один первичный балл. Для полного пробника из 19 задач спецификация отводит 235 минут. Первая часть даёт до 12 первичных баллов, полный пробник — до 32. Шкала перевода зависит от года её утверждения. В этом наборе шкалы перевода нет.
