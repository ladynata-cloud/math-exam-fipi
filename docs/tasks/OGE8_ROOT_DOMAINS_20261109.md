# ОГЭ №8 · условия для свойств корней

- База: main, ac0fdfa68f3e6a79f5b08ae2ef43c16dc138c1f8.
- Ветка: fix/oge8-root-domains-20261109.
- Уровень проверки: SMALL.

Уточнить условия применения свойств корней в разделе «Учимся». Прежде у
произведения и частного арифметических корней не было ограничений. При
a = b = −1 выражение √(ab) определено, а √a · √b — нет. Для равенства
√(aⁿ) = aⁿ/² указать a ≥ 0 и натуральный показатель n. Для произведения
указать a ≥ 0, b ≥ 0, для частного — a ≥ 0, b > 0.

Сохранить задания, вычисления и интерфейс, исторические копии книг и историю
привязок навигатора. Проверить текст, скрипты и существующие навигационные
защиты. Изменение не затрагивает сохранения учеников. Откат выполняется
совместно для страницы и соответствующей привязки.
