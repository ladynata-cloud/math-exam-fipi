## Сверка собственных задач

Каждому условию сопоставить умение, ожидаемый ход решения и формат ответа. Самостоятельно написать условие и выбрать числовые данные. Для графиков, чертежей и таблиц также менять исходные данные и их представление. Проверять близкие совпадения текста, совпадения значимых чисел, пересчитанные комплектами пропорциональные копии и условия, в которых при изменённом сюжете сохранился тот же набор чисел источника.

Для №2, №7 и №18 сохранить порядок соответствий. Для №8 учитывать правило о любом порядке цифр. Для №6 читать инструкцию конкретного задания, поскольку возможен ответ одним числом или последовательностью номеров. Для №19 принимать любое подходящее число, если так сформулирован вопрос.
