# ВПР-2027: интерактивная подготовка

Авторский банк MathExam: 82 урока, 492 задания, 1284 проверяемых шага.
Материал общей основы используется в нескольких маршрутах с неизменными ID.

| Маршрут | Темы | Задания |
| --- | ---: | ---: |
| `g5` · 5 класс | 12 | 72 |
| `g6` · 6 класс | 12 | 72 |
| `g7` · 7 класс, базовый | 18 | 108 |
| `g7u` · 7 класс, углублённый | 22 | 132 |
| `g8` · 8 класс, базовый | 16 | 96 |
| `g8u` · 8 класс, углублённый | 20 | 120 |
| `g10` · 10 класс | 17 | 102 |

## Источник и границы

`content/full_data.json` — единственный источник учебного банка, официальных
ссылок и независимых вычислительных выражений для проверок. `build.py` удаляет
тестовые поля и создаёт `data.js`; браузер использует только этот результат.
Задания составлены заново по навыкам семи официальных описаний ВПР-2027, а не
скопированы или слегка переработаны из Решу ЕГЭ / Решу ВПР.

`content/coverage.json` связывает 118 категорий официальных описаний с уроками и
заданиями, фиксирует ограничения отдельных подтипов и SHA исходного банка.
Покрытие категорий не означает воспроизведение любого возможного подтипа или
полного официального варианта. Диагностика считает итоговые ответы; свободные
доказательства, письменные решения и качество чертежа оценивает преподаватель.

## Открытие и назначение

Каталог: `/vpr/`. Страница курса: `/trainers/vpr-math/index.html?route=g7`.
Необязательные параметры `lesson`, `task`, `mode=learn|solo` выбирают точную
задачу. Приоритет у явного hash-маршрута; некорректные ID возвращают к доступному
маршруту. Переходы внутри приложения сохраняют адрес выбранной задачи.

Семь записей `vpr-g5` … `vpr-g10` в `learning/course-program.js` доступны в
существующем мастере программы ученика. Создание записей каталога не назначает
курсы реальным ученикам. Кабинет сообщает, что результаты этой практики
сохраняются в браузере, отдельно от серверной истории работ.

## Личный прогресс и общая комната

Личный режим сохраняет отдельные попытки «По шагам» и «Самостоятельно», записи,
достижения, историю ошибок и незавершённые диагностики каждого маршрута.
Ключ `mathexam.vpr2027.offline.v1` и формат экспорта версии 1 совместимы с
подготовленным автономным комплектом. Перенос между устройствами — через JSON
в разделе «Мой прогресс»; автоматического облачного переноса этого курса нет.

`board-mode.js` определяет общий режим до чтения личного сохранения.
`board.js` регистрирует `vpr-math` через существующий `MathExamBoard` и проверяет
точную схему выбранного публичного задания. Общий снимок содержит вид, текущую
попытку, работу по ранее открытым задачам этой ВПР, сообщение проверки и раскрытые
панели. Ответы, пройденные шаги, ошибки, подсказки, точки графика и записи каждой
попытки возвращаются при выборе прежней задачи, в том числе после передачи
управления и перезагрузки страницы в действующей комнате. Режимы «По шагам» и
«Самостоятельно» хранятся отдельно. Личный журнал ошибок, диагностики и достижения
в снимок не входят. Общая комната не читает и не меняет личный ключ прогресса.

Снимок остаётся ограничен 64 КиБ действующего протокола. Непосещённые и пустые
задачи не занимают место в архиве; старые выполненные задачи не вытесняются.
Если новое изменение превышает предел, целиком восстанавливается последнее
допустимое состояние и появляется предупреждение. Можно сократить записи и
продолжить. При обычной передаче управления или его добровольном возврате host
сначала запрашивает и отправляет последний снимок, затем меняет ведущего. Если
снимок не получен, передача не выполняется и интерфейс сообщает об этом.

Это история работы внутри открытой ВПР в живой комнате, а не постоянный архив
кабинета. Переключение на другой тренажёр через внешний каталог доски, перезапуск
сервера и несинхронизированный ввод при потере связи или принудительном отзыве
управления не покрываются этой гарантией. Рукописные штрихи хранятся отдельно существующим host
доски; переключение задач внутри ВПР их не очищает.

Ссылка «На общую доску» сохраняет маршрут, тему, задачу и режим. Создание комнаты
переносит проверенный снимок уже открытой ВПР через существующий механизм host;
записи и ответы не попадают в URL. Старые комнаты и переподключения используют
актуальное состояние сервера.

## Проверки

Требуются Node 24, Python 3 и `jsdom@26.1.0`; для браузерного сценария —
`playwright@1.62.1` с Chromium. Зависимости сервера устанавливаются его lockfile.

```sh
python3 trainers/vpr-math/build.py --check
python3 trainers/vpr-math/content-gate.py
node --test trainers/vpr-math/*.test.cjs
node --test tools/vpr-*.test.cjs
node --test board-server/test/trainer-registry.test.js board-server/test/server-registry.integration.test.js board-server/test/learning-onboarding.test.js
node trainers/vpr-math/browser.cjs
python3 tools/build-sitemap.py --check
git diff --check
```

Полный сценарий CI: `.github/workflows/vpr-interactive.yml`. Он проверяет
математику, личные учебные действия, реальную передачу состояния через сервер,
смену управления, переподключение и экраны 320, 390 и 1280 px. DOM-проверки
не заменяют просмотр реальных скриншотов.
