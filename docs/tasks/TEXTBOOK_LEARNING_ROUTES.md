- Уровень проверки: MEDIUM. Изменяется содержание и ограниченная навигация существующей Workshop, используются её контракты заданий, SVG-модели и существующий механизм результатов. Новых протоколов, хранилищ, авторизации, серверных API или инфраструктуры выпуска нет.

## Реализуемая часть большого запроса

1. Реестр всех 77 фактически скачанных книг алгебры и вероятности; проверка SHA-256 относительно исходного реестра. PDF не включаются в публичный сайт.
2. Интеграция шести авторских уроков из PR #163 без переноса его устаревшего дерева сайта.
3. 24 дополнительных блока: понятие, три объяснения, вопросы, изменяемая модель, три ветви генератора, промежуточные шаги, самостоятельная практика.
4. Выбор издания, поиск автора/класса/года, общие навыки по уровню, точные частичные связи для прочитанных оглавлений. Различать прочитанный источник, полученный файл, покрытый навык и завершённый пункт.
5. Сохранить 74 прежних блока, состояние и журнал. Подсказка, повтор условия или исправление не считаются независимым успехом. Возврат к предпосылке сохраняет введённый ответ.

Это этап, а не полное выполнение исходного многолетнего объёма. Нельзя объявлять все книги завершёнными. Разрывы фиксируются в отчёте.

## Приёмка и проверки

- Независимый арифметический расчёт ключей из текста 5760 новых условий плюс 1440 условий перенесённого модуля.
- Реальный Chromium: 30 новых для production уроков, шаги, модели, 360/768/1280, клавиатура, уменьшение движения, возврат, сохранение.
- Существующие проверки Workshop: математика, прежние ключи, повреждённые записи, журнал.
- `git diff --check`, сборка preview, точность ссылок и проверка публикации.
- Проверки автоматические, не эксперимент с реальными учениками. Внешнее ревью не заявляется.

## Риски и откат

Основные риски: математическая ошибка, неверная связь с параграфом, появление впечатления полного курса. Проверяются отдельным расчётом, явными отметками частичного покрытия и браузером. Учебные результаты сохраняются прежней схемой. Нельзя откатывать на старую версию валидатора поверх новых идентификаторов навыков: он заблокирует запись. При дефекте отключать вход в проблемный урок, сохраняя реестр идентификаторов, обработчик состояния и возможность экспорта; не очищать localStorage.
