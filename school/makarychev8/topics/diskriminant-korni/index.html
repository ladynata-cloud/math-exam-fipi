Дискриминант и число корней

Для ax² + bx + c = 0 при a ≠ 0 дискриминант D = b² − 4ac определяет число действительных корней.

Сразу к задачам курса →

Сначала попробуй самостоятельно

Введи значение D, только число.

Нужна небольшая подсказка

Здесь a = 1, b = −5, c = 6. Возводи в квадрат весь коэффициент b вместе со знаком.

Посмотреть наглядный разбор
Кадр 1 / 5
  1. x² − 5x + 6 = 0: a = 1, b = −5, c = 6.
  2. D = (−5)² − 4 · 1 · 6 = 1.
  3. x₁ = (5 − 1)2 = 2; x₂ = (5 + 1)2 = 3.
  4. Парабола пересекает ось x в точках 2 и 3.
  5. Проверка: 4 − 10 + 6 = 0; 9 − 15 + 6 = 0.

Это разобранный пример. После него реши новое условие ниже.

Теперь другой пример

Введи число или дробь — ответ на новый вопрос.

Сверить ответ и объяснение

Один различный корень x = 3. Парабола касается оси x. При D < 0 действительных корней нет; при a = 0 уравнение уже не квадратное.
