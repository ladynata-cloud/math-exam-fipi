Неравенства и промежутки

У каждого неравенства есть своё множество решений. Чтобы найти его среди предложенных промежутков, выясни, где проходит граница, с какой стороны лежат подходящие числа и входит ли сама граница в ответ.

С какой стороны от единицы?

Для каких x выполняется (½)x < ½? Подставь по очереди 0, 1 и 2. Где знак «меньше» верен?

Сверить три подстановки

Получаются 1, ½ и ¼. Из трёх чисел подходит только x = 2. С ростом показателя степень с основанием ½ убывает. Подходят все x > 1. При x = 1 получилось бы равенство.

Два разбора по шагам

Степень с основанием больше единицы

3x + 1 ≥ 81

  1. Запиши 81 с тем же основанием. Получится 3x + 1 ≥ 34.
  2. Степень с основанием 3 возрастает. Чтобы её значение было не меньше 34, нужен показатель не меньше 4. Значит, x + 1 ≥ 4, откуда x ≥ 3.
  3. Подставь границу. При x = 3 обе стороны равны 81. Тройка входит, а все большие значения подходят. Ответ [3; +∞).

Логарифм с дробным основанием

log½(x + 4) > −2

  1. Аргумент должен быть положительным. Из x + 4 > 0 получаем область допустимых значений (ОДЗ) x > −4.
  2. При каком аргументе логарифм равен −2? Поскольку (½)−2 = 4, граница достигается при x + 4 = 4, то есть при x = 0.
  3. С ростом аргумента этот логарифм убывает. Для значения больше −2 нужен аргумент меньше 4. Совмести оба условия: 0 < x + 4 < 4. Ответ (−4; 0).

Проверка: при x = −3 аргумент равен 1 и логарифм равен 0. Точка −4 запрещена областью определения, а при нуле получается равенство, хотя знак строгий.

Как собрать из четырёх решений экзаменационный ответ?

Пусть А и Б — два примера выше. В строке В дано (2x − 1)/(x − 4) < 0, в строке Г — 4x + 5 ≤ 7. Предложены четыре промежутка.

  1. (−∞; 0,5]
  2. (−4; 0)
  3. [3; +∞)
  4. (0,5; 4)

Для А получили [3; +∞), это номер 3. Для Б получили (−4; 0), это номер 2.

В строке В дробь отрицательна, когда у числителя и знаменателя разные знаки. Между 0,5 и 4 числитель положителен, а знаменатель отрицателен. Снаружи знаки совпадают. При 0,5 дробь равна нулю, при 4 она не определена. Подходит номер 4.

В строке Г вычтем 5 и разделим обе части на 4. Получим x ≤ 0,5, то есть номер 1. Читаем номера в порядке букв А, Б, В, Г и записываем 3241.

Проверь число на оси

Исследуй loga(x − 1) ≤ 1. При основании 2 попробуй x = 1, 2 и 3. Какая точка запрещена, а в какой обе стороны равны? Оставь x = 2 и смени основание на ½. Затем проверь x = 1,25 при каждом основании.

Толстая линия показывает решения. Закрашенная точка входит в ответ, пустая исключена. Стрелка сверху отмечает выбранное число.

Сопоставь четыре неравенства

Реши каждую строку и запиши рядом номер её промежутка. В поле ответа перенеси четыре номера подряд в порядке А, Б, В, Г.

В каждом третьем варианте встретятся все четыре вида неравенств из разбора.

Если два промежутка кажутся одинаково подходящими

Где поставить круглую или квадратную скобку?

Подставь границу в исходное неравенство. Если обе части определены и знак допускает равенство, точка входит. При строгом знаке точку равенства исключают. У бесконечности всегда ставят круглую скобку.

Почему одного сравнения показателей или аргументов мало?

Посмотри на основание. При основании больше 1 порядок сохраняется, а при основании между 0 и 1 обращается. Для логарифма отдельно проверь, что аргумент положителен. Удобно подставить одно число внутри выбранного промежутка и одно снаружи.
