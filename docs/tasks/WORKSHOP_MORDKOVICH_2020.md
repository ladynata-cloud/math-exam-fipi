Для всех 49 нумерованных параграфов и вводного повторения сверены точные начальные страницы. У повторения отдельная нумерация 1–123. Сделаны 59 разборов №1–17 по печатным с. 4–5 (страницы PDF 3–4). У №2 одна задача с четырьмя утверждениями, у №5 два доказательства. В оставшихся пяти задачах на с. 4 по четыре части. На с. 5 у №14–15 по две части, у №8–13 и №16–17 — по четыре. В самостоятельной работе ребёнок применяет признаки числовых множеств, ищет контрпример к включению, проверяет делимость, подбирает парные множители, выносит общую степень и определяет остаток по младшим разрядам. Для каждого номера есть отдельный адрес занятия и совместной доски.

Учебник 2013 года относится к другому изданию. Например, числовая окружность в нём начинается с §4; в этом задачнике ей отведён §11 (печатная с. 80). Индивидуальные страницы §§1–49 пока ведут к заданиям в книге. На с. 5 дополнительно разобраны открытые интервалы для кратных, целые значения рациональных выражений, простые множители, остатки, пропущенные цифры и НОД двух или трёх чисел. Следующие авторские разборы в вводном разделе начинаются с №18.
