Отдельный внутренний review проверил shared renderer и root/task-first hooks: раскрытие карты отмечает помощь через существующий контроллер; поля ответа и шага не заменяются. Отметка самостоятельного решения привязана к названному упражнению и не означает освоения каждого микронавыка. Новые компоненты не записывают прогресс самостоятельно.

Звёздная карта имеет 21 кнопку, стандартные карточки курса сохраняются. Pure-JS проверки подтвердили экранирование, отсутствие записи хранилищ, навигацию, начальную паузу при reduced motion, прекращение кадров при скрытии/выходе за экран и очистку обработчиков/наблюдателей. Эти проверки не заменяют реальный браузер.

## Исправленные находки

- Canvas вызывается только при поддерживаемом CanvasRenderingContext2D; в среде без canvas остаётся статическая навигация. Старые JSDOM gates не ослаблены.
- Возврат из проверки в геометрическую лабораторию восстанавливает карту.
- Порядок действий уточняет выполнение действий одной ступени слева направо.
- Сложение разных знаков явно включает вычитание модулей и нулевой результат при равенстве.
- Подсчёт целых чисел учитывает пустой промежуток.
- Карты задач на кольце завершаются проверкой заданных расстояний по найденной схеме.
- Соотношения единиц включают дециметр.
- В тригонометрическом отношении сторон убрана нерелевантная операция деления на дробь; синус и косинус различены явно.
- Умение считать геометрические грани не получает отметку от задачи на суммарную площадь исходных квадратов.
- Цель обратного процентного расчёта описывает существующую задачу о скидке; новые варианты повышения не заявлены.

## Поведение и ограничения

Основные карты в task-first включены в самостоятельной учебной странице. Управляемые занятия, iframe доски, экзамены и отдельные проверки сохраняют свои контроллеры без новой учебной карты. Ранние модули показывают собственные карты только в обучении/практике. Их результаты не смешиваются с результатами основных семейств.

Предварительные упражнения открываются в новой вкладке с видимым пояснением и rel=noopener, чтобы сохранить исходную задачу. Для 17 целей невозможно обещать единый обратный переход через старый returnTo: существующий код поддерживает лишь часть адресов. Поэтому не изменяются чужие тренажёры ОГЭ.

## Техническая приёмка

Обязательны существующие применимые CI, новые data/DOM/browser gates и проверка публичного выпуска. В PR фиксируются точные base/head, результаты, изменения основы, проверенный merge и Pages. На момент подготовки этого файла браузерные/CI результаты ещё не объявлены пройденными.

Локальная shell-среда недоступна; фактический checkout, diff-check и браузерные сценарии выполняются в GitHub Actions. Проверка публичного выпуска сравнивает 22 ресурса побайтово с выпущенным checkout и проходит пользовательские сценарии в Chromium при 320 и 1280 пикселях.

Внешний Claude/provider audit не запрашивался и не выполнялся по действующей политике владельца. Внутренние агенты не представлены как внешнее одобрение. Новых форматов сохранения, миграций или изменений серверного протокола нет.
