# ЕГЭ база №21. Сколько строк в таблице

Ученик восстанавливает число строк по суммам столбцов и ограничениям на сумму одной строки. Он находит общую сумму, отсеивает неподходящие количества строк и проверяет оставшееся число на таблице из положительных целых чисел. После разбора он применяет тот же способ к новой задаче без подсказок.

## Математическая проверка

Пусть в таблице $k$ столбцов с известными положительными целыми суммами $C_1,\ldots,C_k$. В каждой клетке не меньше одной единицы. Для каждой строки заданы строгие **целые** границы $a<s<b$. Сложим суммы столбцов и обозначим результат через $S$. При возможном числе строк $n$ эта же сумма получается сложением $n$ строк.

Минимальная сумма строки равна $L=\max(a+1,k)$, максимальная — $U=b-1$. Если $L>U$, допустимых строк нет. В остальных случаях $nL\le S\le nU$. Дополнительно в каждом столбце должно хватить хотя бы по единице на каждую строку, поэтому $n\le C_j$ для каждого $j$. Полный диапазон допустимых количеств строк задают границы

$$
\left\lceil \frac{S}{U}\right\rceil
\le n \le \min\left(\left\lfloor \frac{S}{L}\right\rfloor,C_1,\ldots,C_k\right).
$$

Если границы совпали, ответ единственный. Если нижняя выше верхней, построить такую таблицу нельзя. При нескольких целых кандидатах задание с требованием единственного числа не выдаётся. Когда деление точное, частное уже целое и округление его сохраняет.

**Почему каждый оставшийся кандидат работает.** Запланируем сумму $L$ в каждой из $n$ строк. Оставшиеся $S-nL$ единиц распределим между строками, добавляя не более $U-L$ в каждую. Места заведомо хватит, так как $S\le nU$. Теперь заполним все клетки единицами. Для столбца $j$ осталось распределить $C_j-n$ единиц, а потребность каждой строки — её запланированная сумма за вычетом $k$. Эти количества неотрицательны, и сумма всех потребностей строк равна сумме всех остатков столбцов. Можно по очереди добавлять столько единиц в очередную клетку, сколько одновременно осталось в её строке и столбце. На каждом шаге закроется хотя бы одна строка или один столбец. Полученная таблица удовлетворяет исходным условиям.

## Учебный маршрут и приёмка

Из задания `#lesson=practice-whole-count` ученик может воспользоваться справкой. На полном листе `#sheet=reasoning` доступен переход к `ege-baza/reference/index.html#row-sums`. Ученик может вернуться к листу или к привычному упражнению. В объяснении и модели общая сумма имеет один смысл при подсчёте по строкам и по столбцам.

1. В пошаговом примере ученик различает число столбцов, общую сумму и число строк. Модель позволяет выбрать число строк, сопоставить минимальную и максимальную возможные суммы с заданной, увидеть причину отказа или пример таблицы.
2. Практика рассматривает ошибки на конкретных числах. Если ученик включил запрещённую границу, проверяется возможная сумма одной строки. Если округлил не в ту сторону, проверяются соседние количества строк. Если назвал общую сумму, вопрос возвращает к единице ответа — числу строк. Для столбца с малой суммой проверяется, хватит ли в нём по единице на строку.
3. Самостоятельная проверка даёт новое условие без разбора и модели ответа. Ранее решённый вариант с подсказкой и повтор отправленного ответа не могут подтвердить самостоятельное решение нового задания.
4. Математические тесты независимо перечисляют допустимые количества строк, проверяют крайние условия и пересчитывают каждую сумму в предъявленной таблице. Браузерная проверка проходит обычный путь из справки, взаимодействие с моделью, ошибочный и верный ответы, контроль без подсказок и обратный переход, в том числе на узком экране.
5. Регрессия охватывает прежний вход в №18, доступность старого семейства `whole-count` и сохранность исходной записи ученика при переходе. Проверки и обнаруженные ограничения указываются в PR на точном проверенном кандидате.
