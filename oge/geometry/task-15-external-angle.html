ОГЭ №15 · пример с разбором

Внешний угол

Найди угол

В треугольнике ABC угол C равен 142°. Найдите внешний угол при вершине C. Ответ дайте в градусах.

Хочешь подсказку?

Сколько градусов осталось от 180°, если один из углов равен 142°?

142° + ? = 180°
Посмотреть решение
  1. Внешний угол при вершине C смежный с внутренним углом при этой же вершине.
  2. Сумма смежных углов равна 180°.
  3. Вычитаем известный угол: 180° − 142° = 38°.

Ответ: 38°.

Не перепутай внутренний и внешний углы: число 142° дано для внутреннего. Он тупой, поэтому смежный с ним внешний угол должен быть острым.

Для проверки продолжи AC за C: искомый угол находится между CB и CD.
