# Последние задачи главы V «Объёмы тел», №551–556

Сверены условия на печатной с. 141 (PDF 143), ключ на с. 268 (PDF 270) и наличие двух подпунктов №556. Учебник Л. С. Атанасяна и соавторов «Геометрия. 10–11 классы», 12-е издание 2024 г. SHA-256 PDF равен `bead97a383e438b32b9caaff72d61d27e8fa6cd20c6b86a5f234bc4cdb629770`.

| Номер | Что проверено |
| --- | --- |
| 551 | При горизонтальном радиусе r и высоте H координата центра относительно основания z = (H²−r²)/(2H) может быть отрицательной. Радиус R = (H²+r²)/(2H). Отдельно получаются площадь 4πR² и объём 4πR³/3. |
| 552 | Основание высоты — середина гипотенузы. Горизонтальный радиус равен 1 см, радиус описанной сферы равен 1/sin(2α) см. |
| 553 | Горизонтальный радиус равен половине диагонали прямоугольника, то есть 5 см. Радиус описанной сферы равен 5/sin(2β) см. |
| 554 | При радиусе стыка 1,5 м и высоте крышки 0,5 м сферический радиус равен 2,5 м. Интегрирование площадей дисков одной крышки даёт 7π/12 м³. Для вместимости 50 м³ длина цилиндра равна 200/(9π)−14/27 ≈ 6,56 м. |
| 555 | При общей площади 6π объёмы возрастают от конуса (5,29) к кубу (5,57), цилиндру (6,28) и шару (7,70). Отношения сохраняются при подобии. У каждого тела повторно измерена его поверхность по координатам. |
| 556а | Для закрытой оболочки из меди плотности 8,9 г/см³ и внешнего радиуса 5 см толщина 0,2 см даёт среднюю плотность 1,0258496 г/см³. Масса оболочки превышает массу воды внешнего объёма. Шар тонет. |
| 556б | При толщине 0,15 см средняя плотность 0,7772103 г/см³. Закрытый шар плавает. В обоих расчётах масса воздуха пренебрежимо мала. |
