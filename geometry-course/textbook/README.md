# Полный курс по Атанасяну 7–9 — подготовка источников

## Сохранённые материалы

- `source-inventory.json` — проверенные границы глав и разделов, отдельные
  пространства нумерации и явные ограничения полноты сверки.
- `source-chapters.tsv` — компактная карта глав, страниц и номеров.
- `preparation/chapter-01.json` — авторские черновики № 1–91 с подпунктами,
  шагами и заданиями на рисунки; модели ещё не реализованы.
- `preparation/chapter-01-review.json` — независимая проверка другим ИИ-агентом,
  привязанная к SHA256 черновика; № 9, 10, 44 требуют уточнения трактовки.
- Проверка структуры: `python3 tools/geometry/check_textbook_preparation.py`
  из корня репозитория. Успех этой проверки не разрешает публикацию.

Учтены 1431 номер, 315 вопросов для повторения, 14 исследовательских задач,
14 тем рефератов, 6 комплексных заданий и 3 приложения. Диапазоны номеров
сверены; полнота всех подпунктов, примеров теории и заданий приложений пока
не подтверждена. Число подготовленных текстов не является числом готовых уроков.

Целевое издание: базовый уровень, 14-е переработанное, 2023. Действующий
тематический курс находится в родительской директории и продолжает работать.

Этот каталог пока **не является опубликованным курсом всех задач**. Здесь
сохраняются реестр исходника и авторские черновики для дальнейшего создания
проверенных интерактивных уроков. Счётчики подготовленных текстов, реализованных
моделей, проверенных карточек и опубликованных номеров должны быть раздельными.

Для каждой задачи требуется её собственный чертёж без лишних элементов внутри
фигуры; вспомогательные построения открываются по шагам. Разные случаи получают
отдельные виды. Текстовый план модели ещё не означает реализованную модель.

Область работ, критерии готовности и ограничения проверки описаны в
[`ATANASYAN_7_9_COMPLETE_COURSE.md`](../../docs/tasks/ATANASYAN_7_9_COMPLETE_COURSE.md).

Не размещать здесь исходный PDF, снимки страниц, полный распознанный текст,
приватные идентификаторы файлов или локальные абсолютные пути.
