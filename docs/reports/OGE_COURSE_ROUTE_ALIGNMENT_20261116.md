## Что меняется для ученика

На обеих страницах сначала доступно необязательное раскрытие «Исследовать модель — по желанию». В нём ровно четыре существующих тематических действия: вероятность на барабане, прямая через две точки, существование треугольника и площадь параллелограмма при наклоне. Каждая ссылка содержит точный `topic` и `route=task:...`; случайная сохранённая тема не заменяет её назначение.

Основной вход на `/oge/` теперь «Исследовать прямую», а заголовок — «Сначала — исследовать». Он открывает `n11-c1`. Обычный адрес `?topic=n11` остаётся в списке коротких тренировок вместе с остальными 25 входами.

Короткое занятие прямо обозначено как четыре задания на отдельные шаги. Для большего набора задач сохраняется основная карта №1–25. Для №20–25 отдельно сказано: проверка отдельных шагов не оценивает всё письменное обоснование. Длинные списки сначала свёрнуты; раскрытия и ссылки работают без JavaScript, а сама интерактивная модель требует уже существующего движка.

Широкие исследования, новые подсказки, честный native mastery и свободные письменные решения остаются предметными задачами.
