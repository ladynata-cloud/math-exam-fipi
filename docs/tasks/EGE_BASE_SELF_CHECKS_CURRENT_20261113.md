## Откат

До выпуска исходный сайт продолжает работать с `main`. После отдельного разрешения и выпуска для отмены используется обратный коммит выпуска с исходной привязкой навигатора. Для обычного merge-коммита используется `git revert -m 1 <merge-sha>`, для squash-коммита — `git revert <release-sha>`. Если к тому времени те же страницы менялись, привязка пересобирается по итоговым байтам.

У двух новых типов №21 записи хранятся в дополнительном поле `task21Practice` прежнего документа `mathexam.ege-baza.path.v1`. Предыдущий загрузчик проверяет привычный набор `lessons` и сохраняет дополнительное поле при обычной работе. При повторном включении задач их записи снова видны. Очистка хранилища ученика для отката не требуется.
