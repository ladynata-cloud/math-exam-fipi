# Курс-навигатор: профильный ЕГЭ

Отдельный раздел сайта: страница-маршрут по всем 19 заданиям, журнал работы
над ошибками, кабинет учителя и тренажёры к нему. Всё статическое, без
сборки и без сервера — как и остальной сайт.

> Раздел лежит в собственном каталоге и корневой `index.html` сайта
> mathexam.space не трогает.

## Что где лежит

```
ege-profil/
  index.html            маршрут по заданиям, карточки тренажёров, подвал
  review.html           журнал работы над ошибками
  teacher.html          кабинет учителя: сводка, код прогресса, доска и зеркало
  registry.js           TRAINERS, NAMES, CABINET — общий реестр курса
  progress-adapters.js  адаптеры прогресса для index.html и teacher.html
  progress-code.js      код прогресса MEP1.… — сборка, разбор, перенос
  qr.js                 собственный кодировщик QR (байтовый режим, уровень L)
  board-mirror.js       режим доски, зеркало, полный экран для страниц курса
  trainers/             самодостаточные тренажёры (один файл — один тренажёр)
  src/                  исходники и разборы, из которых собраны тренажёры
  tests/                проверки на jsdom и независимые верификации банков
```

`registry.js`, `progress-adapters.js`, `progress-code.js`, `qr.js` и
`board-mirror.js` — общий код **страниц курса**. Тренажёры их не подключают:
тренажёр обязан оставаться одним файлом, работающим по `file://`, поэтому
режим доски и зеркало у него написаны внутри.

## Как посмотреть

Страницы курса тянут соседние `.js` и по `file://` в Chrome работать не
обязаны — поднимите любой статический сервер из корня репозитория:

```bash
python3 -m http.server 8000
```

и откройте `http://localhost:8000/ege-profil/`. Отдельный тренажёр из
`trainers/` открывается и просто двойным щелчком с диска.

## Проверки

```bash
cd ege-profil && npm install
```

```bash
npm test
```

Что во что входит:

| Команда | Что проверяет |
| --- | --- |
| `node tests/site-test.js` | карточки, пилюли маршрута и адаптеры прогресса в `index.html`, реестр и кнопки «Повторить» в `review.html` |
| `node tests/teacher-test.js` | сводку кабинета, кодирование и разбор кода прогресса, отказ на битом коде, загрузку с резервной копией |
| `node tests/board-mirror-test.js` | `?board=1`, `?mirror=1`, их сочетание с `?mode=review`, кнопку полного экрана |
| `node tests/qr-test.js` | кодировщик QR: ёмкости, служебные узоры, сведения о формате, снятие данных обратно со змейки |
| `node tests/ui-plan-test.js trainers/planimetry-yashchenko-t1.html` | тренажёр планиметрии целиком: 19 типов, ловушки, зачёт, журнал |
| `node tests/verify-t1-planimetry.js` | независимый пересчёт банка планиметрии: фигура строится в координатах, ответ измеряется, формулы генератора не используются |

## Код прогресса

Сайт без сервера, поэтому прогресс ученика приносит строка, а не аккаунт.

`MEP1.<base64url>`; внутри — один байт способа упаковки (`1` — `deflate-raw`
через `CompressionStream`, `0` — без сжатия) и дальше JSON объекта
`mathExamCourseProgress.v1` в UTF-8. Байт нужен, чтобы код, собранный в
браузере без `CompressionStream`, читался там, где он есть, и наоборот.

Ключ `mathExamCourseProgress.v1`, идентификаторы тренажёров и формат журнала
ошибок `all.mistakes["TID|тип"] = { w, r, lastWrong, last }` не меняются:
объект переносится целиком, как есть.

Тренажёры, которые хранятся под своими ключами (`stereo3.status`,
`ep_progress_v1`, `trig-stp-trainer-v2`, `profile-ege-course-v1`), в код
прогресса не входят — это сказано и в самом кабинете.

## Доска и зеркало

`?board=1` — крупный шрифт, `?mirror=1` — зеркальное изображение для
проекторов, которые переворачивают картинку. Параметры сочетаются друг с
другом и с `?mode=review`.

Зеркалится `body`, а не `<html>`: клики и ввод внутри `transform` работают,
координаты событий браузер пересчитывает сам. Режим доски сохраняется (это
настройка человека), зеркало — нет (это настройка проектора).
