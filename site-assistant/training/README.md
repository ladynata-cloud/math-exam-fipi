# Примеры для подготовки трёх помощников

В каждом train-*.jsonl лежит по 12 авторских учебных диалогов. В каждом диалоге две реплики посетителя и два ответа. Формат UTF-8, один объект messages на строку. Модели можно передать инструкцию роли, краткое описание текущей страницы и URL. Эти диалоги составлены для проекта. В них нет записей посетителей. Ответы показывают желаемое поведение будущей модели. Текущий автономный сервис поддерживает конкретные функции, перечисленные в его документации.

provenance.jsonl связывает номер строки каждого train-файла с постоянным идентификатором, URL и записью каталога или файлом в исходниках сайта. Числа в математических примерах выбраны для обучения. В литературных и символических примерах вопросы и ответы сформулированы для упражнения и не являются цитатами писателя, переводчика или автора колоды.

routing-holdout.jsonl содержит шесть независимых задач о границах сайтов. Оставьте их для проверки. Поле expected_active_site обозначает контекст текущей беседы. Действие other_site предлагает переход на другой сайт по выбору посетителя, без пересылки истории. Эти шесть записей не включены в train.

Для первого сравнения возьмите одинаковые вопросы и контекст для базовой и дообученной моделей. В MathExam отмечайте, учитывает ли подсказка последнюю попытку и остаётся ли следующий шаг ученику. В «Узле» проверяйте спойлеры до чтения, границы фрагмента и точность ссылки. В «Каббале и Таро» проверяйте источник и школу, различие изображения и интерпретации, сохранение неопределённости. Записывайте ошибки и решения по каждому случаю. Размер подборки позволяет разбирать отдельные ответы, но недостаточен для оценки качества на всех темах сайтов.
