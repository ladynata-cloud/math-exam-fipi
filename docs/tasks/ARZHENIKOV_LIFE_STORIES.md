# Карта маленьких дел

Владелец MathExam поручил доработать и опубликовать карту Арженикова по прежнему адресу. Ребёнок сначала решает несколько задач с предметами, затем соотносит свои действия с записью. Нужны разнообразные житейские ситуации и наглядная карта навыков.

Основа работы — игровая карта из PR #728. Ветка feat/arzhenikov-everyday-stories. Уровень проверки HIGH.

Восемь мест, в каждом два набора по три истории. В каждом наборе ребёнок делит поровну, комплектует группы заданного размера и считает общее количество. Ученик может ошибиться с раскладкой, исправить её и после перезагрузки продолжить с того же места. Первые три задачи проходят без показа формул. Дальше ученик выбирает запись для каждой собственной раскладки. Сюжеты и экранная последовательность разработаны для MathExam. Исходные входы в оранжерею и в восемь ступеней деления доступны по своим адресам.

Приёмка включает проверку арифметики, подсказок, сохранения, выбора места, двух смыслов деления, прохождения с клавиатуры, мобильного вида и прежних прямых ссылок. Публикация через GitHub Pages после проектных проверок. Для отката используется обычный revert изменения.
