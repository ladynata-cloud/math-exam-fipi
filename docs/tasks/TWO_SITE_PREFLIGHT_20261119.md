# Подготовка первой выборки для двух публичных помощников

19 ноября 2026 года. Владелец выбрал MathExam и «Узел тоски по миру» и поручил продолжить подготовку перед обучением. Основа — main `e97445d1ee23263570201a0a19dc5b78e5e231eb`, ветка `codex/two-site-training-preflight`. Уровень проверки MEDIUM: ограниченное изменение навигации и обновление публичной читательской базы в рамках существующего протокола. Архитектурное решение — [ADR 0011](../adr/0011-independent-assistant.md).

## Результат и проверки

- Выборка для двух ролей основана на математических и читательских примерах из [MathExam №682](https://github.com/ladynata-cloud/math-exam-fipi/pull/682). Для выбранных ролей проверяются адреса в репликах и источниках, привязка строки к источнику, порядок ролей и отсутствие совпадающих вопросов в отложенном наборе.
- На двухходовых разговорах проверить, что школьник получает ссылку на ВПР своего класса и выбранного уровня, в том числе при включении серверного режима после первого вопроса. Для отказа от прежней цели и неоднозначного ответа оставить отдельные регрессии.
- Читательскую базу воспроизвести из коммита `a6e127c0d20f3dd7dabce1369cd12e5abb19cf06` [литературного проекта](https://github.com/ladynata-cloud/uzel-toski-po-miru/pull/14). Проверить две ошибочные подстановки книг, неизвестное название, безопасную завязку и ссылку на источник в режиме обсуждения.
- Отложенные случаи проходят через диалоговую функцию с настоящим состоянием. В отдельном экспорте для внешнего сравнения отображаются только вопрос и разрешённый контекст. Результат программы по правилам и результаты будущих моделей учитываются отдельно.
- Приёмка включает тесты сервиса, регрессии навигатора, браузерный сценарий ВПР, ручную сверку учебных диалогов и контрольных ответов, проверку diff. Инструкция и результаты первого прогона находятся в [материалах подготовки](../../site-assistant/training/README.md).

Этап завершается передачей проверенных материалов в черновике. Обучение, вызовы моделей с оплатой и публикация сервера относятся к последующему этапу. Читательские ссылки на новые карточки зависят от выпуска соответствующего литературного каталога. Для отмены подготовки достаточно вернуться к предыдущей версии правил, каталога и учебных файлов. Миграций и персональных данных в поставке нет.

## Продолжение 20 ноября: полезная помощь без модели

Прямое поручение владельца — применить результаты проверок к действующим сайтам, чтобы они оставались полезны без обращения к модели. Это продолжение того же PR #683, а не новый демонстрационный сайт. Поручение является START для данного объёма; выпуск статических компонентов регулируется действующим решением владельца. Исполняющий агент готовит локальный коммит, а координатор проверяет его перед push и выпуском.

Уровень текущего продолжения **HIGH**: добавляется добровольное локальное сохранение вида объяснения и расширяется ограниченный контекст существующего сервиса. ADR 0011 принят; новый тип архитектуры, вызовы API, платный хостинг и изменение доски/кабинетов не требуются.

В MathExam изменяется только существующая помощь в двух входах деления уголком:

- Подсказка предлагает одно действие. При пробе цифры сначала предлагается умножение; сообщённый результат проверяется отдельно, затем сравнение и проверка ещё одной группы. Помощник не подставляет правильную цифру вместо пробы ученика.
- Когда деление уже начато и текущая часть меньше делителя, разрешено явно напомнить обязательный **0 на текущем месте частного**. Это поддержка сохранения разряда, а не обещание никогда не показывать ни одной цифры. Название разряда вычисляется из индекса текущего цикла реального плана; при неизвестном показателе используется нейтральное описание.
- Повторное «проще» после «почему» остаётся объяснением того же смысла. Проверка с остатком начинается с одного действия.
- По явному выбору сохраняется только категория удобного объяснения. Текст вопроса/ответа, числа, попытки и учебные результаты в новый ключ не записываются. Прежний прогресс принадлежит тренажёру и не изменяется. Сбои или повреждение localStorage не мешают помощи; выбор можно сбросить отдельно.
- Интерфейс честно называет подготовленные подсказки. Внешняя модель не включается; ненастроенный или недоступный дополнительный сервис не мешает локальному ответу.

Пять утверждённых математических карточек относятся к конкретным числовым условиям. Их буквальные подсказки не распространяются на другие задачи. Данный выпуск не заявляет покрытие всех тем MathExam.

База сверки: `ab6083cdb99f5124c1c4b6930cf19ae4b032d5da`. История PR сохранена обычным merge в `723e230fb71d555f41548f31e1405497f701d4e1`. Конкурентные выпуски меняли геометрию, учебные комплекты, переходы и цену занятий; на общей поверхности затронут `assets/assistant/page-rollout.json`, который сохранён. Исходники помощи и сервиса не конфликтовали.

Приёмка: HTTP-тесты обоих помощников; JSDOM-цепочки текущего шага, сохранения и недоступного storage; независимые числовые цепочки; неизменность native-прогресса; регрессии навигатора; синтаксис и diff. Независимый технический review обязателен; внешний провайдерский review не проводился. Точные результаты и ограничения фиксируются в отчёте этого продолжения.

Откат — обычный revert данного коммита; прежний ключ прогресса тренажёра не меняется. Новый ключ `mathexam.divisionHelp.preference.v1` хранит только обратимую настройку и может быть удалён отдельной кнопкой. Перед публикацией координатор повторно сверяет текущую main и PR head по правилам base drift.
