# Короткая практика и карта навыков внутри темы ОГЭ

Публичный вход: `/oge/skills/`. Раздел дополняет существующий курс ОГЭ
и открывается из `/trainers/oge-course/` и `/oge/`.

## Что получает ученик

1. Выбирает основы или любой номер №1–25 и сразу видит конкретное задание.
2. Решает четыре обзорных задания или открывает конечный короткий маршрут.
3. По желанию выбирает мастерскую: строит пример, проверяет утверждение,
   исследует график, сравнивает способы решения, ищет контрпример.
4. Раскрывает карту навыков, когда хочет понять связи внутри темы.
5. Может закончить обычную практику без прохождения всех мастерских.

Карта не блокирует задания. Мастерские не увеличивают знаменатель обычной
части; помощь не выдаётся за самостоятельное решение. Четыре обзорных
задания означают законченную небольшую работу, а не весь объём подготовки
к соответствующему номеру экзамена.

Подробное описание темы находится после задания в закрытом блоке
«Что разберём в этой теме». На первом экране приоритет у условия и ответа.

## Содержание

| Часть | Количество |
| --- | ---: |
| Темы: основы и №1–25 | 26 |
| Навыки | 177 |
| Фиксированные обычные задания | 180 |
| Фиксированные мастерские | 121 |
| Семейства генерируемых вариантов | 46 |
| Короткие маршруты | 64 |

Из 64 маршрутов 11 используют генераторы, 53 связывают фиксированные вход,
мастерскую и выход. В первых четырёх задачах темы не показываются все
180 задач сразу. Дополнительные обычные задачи открываются из маршрутов
и карты. Число генераций не равно числу разных учебных ситуаций.

Исходный набор 0.3.0 создан в разговоре с владельцем 11 ноября 2026 года.
Его шесть JSON-источников, генераторы, математические ID и подписи вариантов
сохранены без изменений. В версии данных 4 добавлены отдельные источники
практических задач, второй части и деления. Раздел охватывает все номера,
но не объявляется полным банком ФИПИ.
Эксперимент с реальными учениками и внешнее ревью Claude не проводились.

### Практические задачи и вторая часть

Для №1–5 представлены все восемь существующих сюжетов: дороги по клеткам,
схема дорог, шины, печки, участки, квартиры, тарифы и листы. Акценты коротких
подборок не задают универсальное содержание конкретного номера: вопросы
зависят от сюжета. Переходы в прежние тренажёры находятся после задания
в закрытом блоке «Сюжеты №1–5».

В №20–25 `assessment: "written-steps"` прямо обозначает учебные шаги.
Правильное число или собранная цепочка рассуждения не считаются проверкой
полного письменного решения. Сводка считает выполненные шаги, отдельное
напоминание предлагает записать и разобрать всё решение. Тренировка
записи краткого ответа в этих темах не показывается. Узлы полного решения
с `separateCheck: false` честно отмечают отсутствие отдельной автоматической
проверки. Все шесть тем ведут в соответствующие действующие тренажёры.

### Деление уголком

В основах и на `/trainers/oge-basics/multiplication-division/division-path.html`
доступны округление до десятков, сотен и тысяч, подбор цифры частного,
проверка произведения и остатка, исправление пробной цифры после прикидки.
Три разряда можно тренировать отдельно: сотни и тысячи не превращаются
в обязательное условие начала деления на двузначное число.

Карта на странице деления закрыта при входе. Она дополняет прежние восемь
ступеней, не увеличивает их знаменатель и не меняет сохранения. Ссылки
на действующие упражнения округления и подбора цифры открывают новую
вкладку с явной подписью; начатое деление остаётся на прежнем месте.

## Адреса и продолжение

- `/oge/skills/?topic=base` — основы.
- `/oge/skills/?topic=n1` — короткие практические задачи и восемь сюжетов.
- `/oge/skills/?topic=n9` — уравнения.
- `/oge/skills/?topic=n11` — графики.
- `/oge/skills/?topic=n24` — шаги доказательства и самостоятельная письменная работа.
- `?route=<известный ID>` — короткий маршрут из `series-catalog.json`.
- `?topic=n11&mode=creative` — мастерские выбранной темы.
- `?topic=n11&map=1` — раскрытая карта выбранной темы.

Действуют только известные темы, маршруты и разрешённые режимы. Маршрут
определяет свою тему. Его повторное открытие продолжает прежний вариант,
а новый вариант создаётся отдельным действием ученика. После смены темы
адрес отражает текущий экран. Служебные параметры кабинета не переносятся.

Ссылки «К курсу ОГЭ» и «Тренажёр» ведут в тот же сайт. «Кабинет» использует
действующий адрес кабинета курса. Полные названия доступны программе
чтения с экрана. Статическая навигация
остаётся доступной, когда JavaScript отключён. Новый TID не регистрируется.

## Данные и границы сохранения

Используются только собственные ключи:

- `mathexam.skillLab.v1` — результаты и использованная помощь.
- `mathexam.skillLab.session.v2` — выбранная тема, ответы, позиция,
  незавершённые маршруты и возврат к исходной задаче.

Сохранение относится к текущему браузеру и origin, не к аккаунту ученика.
История автономного файла не переносится на сайт автоматически. Общий
браузер разделяет эти данные между пользователями; синхронизации вкладок
и устройств нет. При недоступном хранилище занятие работает в текущей
открытой сессии. Старые ключи курса не читаются и не переписываются.
При отказе записи, включая переполнение хранилища, сообщение сразу
переключается на работу в открытой вкладке. Новые ссылки на дополнительные
упражнения открывают другую вкладку, чтобы не потерять единственный
черновик в памяти. Это не добавляет синхронизацию между вкладками.

После перезагрузки уже проверенный верный ответ позволяет сразу продолжить
занятие. Этот возврат не добавляет попытку или успешное решение. Изменение
ответа убирает прежнюю кнопку продолжения до новой проверки. При работе
с клавиатурой перерисовка сохраняет фокус на текущем действии; новое
задание получает фокус на условии.

Математическая идентичность отделена от порядка вариантов ответа.
Прочитанная подсказка, открытый разбор и направляющий комментарий после
ошибки учитываются как помощь. Повторное нажатие проверки не создаёт
ещё одно самостоятельное решение. Дополнительная запись ответа в формате
экзамена не меняет результат математической части.

## Сборка

```sh
python oge/skills/build.py
```

Сборка не использует сеть. Исходники — `topics-*.json`, `expansion-*.json`,
`series-*.js`, `exam-format.js`, `engine.js`, `styles.css`, `app-fragment.html`.
Готовые `index.html`, `course-data.json`, `series-catalog.json` коммитятся
вместе с ними. HTML не редактируют вручную.

Страница автономна: данные, CSS и код встроены в один HTML. Главная страница
курса загружает только компактный CSS своего дополнительного входа.
Это сохраняет привычный статический выпуск GitHub Pages и не добавляет
новый процесс сборки production-сервера.

## Проверки

Математические проверки:

```sh
node oge/skills/validate.js
node oge/skills/validate-series.js
node oge/skills/validate-expansion-arithmetic.js
node oge/skills/validate-expansion-functions.js
node oge/skills/validate-expansion-geometry.js
node oge/skills/validate-foundation-bridges.js
node oge/skills/validate-review-expansion-functions.js
node oge/skills/validate-practical.js
node oge/skills/validate-second-part.js
node oge/skills/validate-division-extension.js
```

DOM-проверки требуют `jsdom`; настоящий браузер — `playwright` и Chromium.
Зависимости устанавливаются изолированно в CI, как в существующих проверках
курса. `dom-harness.js` не делает сетевых запросов. Его искусственные размеры
не являются проверкой компоновки браузера.

```sh
node oge/skills/validate-ui.js
node oge/skills/validate-expansion-ui.js
node oge/skills/validate-answer-format.js
node --test tools/oge-skill-course.test.cjs
node --test tools/division-skill-map.test.cjs
node tools/oge-skill-course.browser.cjs
```

Workflow `OGE skill course` собирает страницу повторно и требует отсутствие
различий, проверяет математический набор, сохранение помощи, новые входы,
старые контракты курса и браузерные сценарии. Для обычного задания №9
проверяются условие, поле ответа и кнопка проверки целиком в первом экране
высотой 900 px при ширине 320, 390 и 1280 px, до прокрутки. Отчёты и снимки экрана
сохраняются в его артефакте, а не объявляются доказательством педагогической
эффективности. Отдельный файл задачи содержит разрешения и точный результат
проверки готового изменения.

Дополнительные браузерные сценарии при 320 и 1280 px проверяют планы,
выколотые точки, изменение параметра и вершины, сборку доказательства,
сохранение помощи и переходы из карты деления в три разряда округления.
Прежние математические источники защищены точными SHA-256 от проверенного
этапа; новые содержание и границы дополнительно пересчитываются независимыми
проверками. `OGE_COMPLETE_SKILL_MAPS_OK` означает прохождение этого gate,
а не публикацию на рабочем сайте.
