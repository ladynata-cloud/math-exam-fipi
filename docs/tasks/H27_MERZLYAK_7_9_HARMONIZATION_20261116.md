## Approved scope

### In scope

1. Составить проверяемую карту соответствия для всех 84 узлов: тема → первый вопрос → действие на модели → наблюдение → вывод → дальнейшая практика.
2. Для каждого узла обеспечить предметное первое исследование. Общая модель допустима для близких тем лишь с собственными параметрами, вопросом и проверяемым учебным выводом.
3. Первое действие доступно до раскрытия готового объяснения. Разрешить ответ «пока не знаю» и понятный переход к опыту; не требовать угадывания.
4. Для точек/прямых исследовать прямую через одну и две различные точки; явно обрабатывать совпадающие точки. Для признаков равенства сравнивать треугольники с заданными элементами; неполные данные допускают контрпример.
5. Развести наблюдение и доказательство: измерение одного рисунка не подтверждает общий случай. Сохранить имеющиеся доказательства и допустимые порядки независимых доводов.
6. Адресные пояснения к управлению моделью, последовательные подсказки по текущему действию и обратная связь на пустой/неразбираемый/ошибочный ответ.
7. Сохранить банк прежних задач, их идентичность и текущие правила помощи/повтора. Первое исследование не создаёт самостоятельного зачёта числовой задачи.
8. Сохранить смысл старых стадий, данные первого прогноза, наблюдений, рисунка, доказательства и черновика. При изменении структуры использовать совместимую адресную миграцию с сохранением исходных записей, а не очистку localStorage.
9. Перегенерировать 84 atlas-страницы из источников, обновить только необходимую локальную документацию, тесты, настройки применимого CI и адресные контрольные привязки.
10. Проверить автономное открытие существующей папки курса, экспорт/импорт прогресса и переходы с карты/в карту. Новый общий offline-продукт не создаётся.
11. В начале разрешённой работы сверить PROJECT_STATUS с доказательствами выпуска; запись в рамках этой задачи, без отдельного status-only PR.
