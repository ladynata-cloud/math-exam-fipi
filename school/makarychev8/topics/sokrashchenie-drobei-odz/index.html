Сначала попробуй самостоятельно

Введи значение выражения. Отдельно объясни себе, почему x = 2 запрещён.

Нужна небольшая подсказка

Разложи x² − 4 как разность квадратов. Перед сокращением выпиши ограничение знаменателя.

Посмотреть наглядный разбор
Кадр 1 / 5
  1. Исходная дробь: (x² − 4)(x − 2).
  2. Знаменатель не равен 0: x ≠ 2.
  3. x² − 4 = (x − 2)(x + 2).
  4. При x ≠ 2 дробь равна x + 2.
  5. График: прямая y = x + 2 без точки (2; 4).

Это разобранный пример. После него реши новое условие ниже.

Введи число или дробь — ответ на новый вопрос.

Сверить ответ и объяснение

Исходный знаменатель x − 3 обращается в ноль при x = 3. Сокращённая запись x + 3 действует только при x ≠ 3.
