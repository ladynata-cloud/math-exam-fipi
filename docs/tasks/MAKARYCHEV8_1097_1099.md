# Макарычев, 8 класс. Наблюдение изменений по графику

Базовый учебник 2024 года, ISBN 978-5-09-116445-9, пункт 43, печатные страницы 245–246. Все запросы №1097–1099 проверены по рисункам 61–63 в выданном PDF. В репозитории хранятся собственные формулировки, объяснения, рисунки и учебные данные.

| Номер | Что делает ученик |
| --- | --- |
| 1097а–в, с. 245 | Указывает на оси времени полные отрезки разгона, замедления и постоянной скорости. Варьирует время и читает скорость по модели. |
| 1098, с. 246 | Находит границы наблюдения, максимальную температуру и описывает нагревание и охлаждение. Самостоятельно проверяет показание в выбранный момент. Температуры между опорными отсчётами показаны приближённо. |
| 1099, с. 246 | Объясняет физический смысл трёх участков при непрерывном нагревании льда. Выбранная минута отображается на его температурном графике. |

Десять заданий и двадцать проверяемых шагов. Поле ответа сохраняет ученический отрезок. Если верны обе границы, но потеряны крайние моменты, обратная связь объясняет скобки. При смешении минут и градусов разбор направляет к нужной оси. Повтор создаёт другой скоростной график с новыми моментами и высотой. Два старых задания №1106 остаются по своим адресам. Полное прямое соответствие есть у №1–1075 и №1077–1099. Для №1076 выделено самостоятельное авторское упражнение.

Проверки темы находятся в test-observed-phases.cjs, test-exercises-1097-1099.py и test-browser-observed-phases.cjs рядом с исходными карточками.
